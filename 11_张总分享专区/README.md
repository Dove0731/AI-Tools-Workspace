# 11_张总分享专区

## 专区用途

本专区专门收集、整理和转化张总分享的经营观点、管理要求、业务判断、案例经验和决策方向。

## 角色定位

张总是公司老板和经营决策者。本专区内容是后续老板汇报、经营复盘、月报、半年度和年度总结的重要管理背景来源。

形成汇报建议时，应将相关分享与真实业务数据结合：数据支持时提出落地方案；数据不支持或存在差异时，明确报告差异、风险和决策选项。不得只引用观点而缺少数据验证。

专区的目标不是只保存聊天记录，而是形成“原始内容可追溯、观点可检索、要求可执行、结果可复盘”的管理闭环。

## 目录结构

| 目录 | 存放内容 | 使用要求 |
|---|---|---|
| `01_原始分享记录` | 原话、会议记录、截图转写、文件摘录 | 必须注明日期、场景和来源；原话与整理内容分开 |
| `02_主题整理` | 按产品、采购、供应商、成本、销售支持、组织管理等主题归纳 | 不改变原意；AI 推断必须标注“分析判断” |
| `03_行动转化` | 从分享内容拆解出的责任人、动作、截止日期和结果 | 未指定责任人或期限时标注“待确认” |
| `04_待确认` | 来源不完整、含义不清、需向张总确认的内容 | 确认后移入对应正式目录 |
| `99_历史归档` | 已失效、已替代或已完成闭环的历史内容 | 保留原始来源和归档原因 |

## 记录原则

1. 先保存原始内容，再做总结和行动转化。
2. 张总原话、转述内容、AI 分析必须清晰区分。
3. 不得把未明确的观点扩写为公司正式决策。
4. 涉及产品、供应商、采购、成本或项目的具体动作，应同步到相应业务台账。
5. 每条分享使用唯一编号：`ZS-YYYYMMDD-序号`。
6. 用于老板汇报时，必须标注分享编号或来源，并说明当前数据是“一致、部分一致、存在差异”还是“待确认”。
