# 张总分享主题分类规则

## 分类原则

一条分享可以关联多个业务主题，但必须确定一个“主主题”，用于文件归档和索引检索。

| 主主题 | 判断标准 | 建议同步模块 |
|---|---|---|
| 经营与战略 | 涉及利润、收入、现金流、资源配置或重大经营方向 | `01_工作报告`、`00_工作台与规则` |
| 产品开发 | 涉及立项、产品定位、配方、包材、打样、测试、上市或复盘 | `09_产品开发管理` |
| 采购与成本 | 涉及询价、比价、降本、MOQ、库存、付款或账期 | `10_采购与成本管理` |
| 供应商管理 | 涉及准入、分级、评估、合作策略、暂停或淘汰 | `08_供应商管理` |
| 销售与客户 | 涉及客户需求、成交、报价支持、市场反馈或返单 | `02_会议与协同` 或关联项目 |
| 质量与交付 | 涉及质量异常、交期、生产排期或放行要求 | `05_问题反馈与复盘` |
| 组织与管理 | 涉及岗位、流程、考核、协同机制或管理要求 | `00_工作台与规则` |
| 案例与经验 | 涉及成功经验、失败教训和可复制方法 | `06_经验与模板` |

## 内容标识

- `【原话】`：有录音、文字或文件可直接核对。
- `【转述】`：由参会人根据记忆或笔记整理。
- `【分析判断】`：基于分享内容进一步形成的经营分析。
- `【明确要求】`：张总已明确提出的动作或标准。
- `【待确认】`：来源、含义、责任人、时间或口径尚未确认。
