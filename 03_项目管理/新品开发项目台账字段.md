# 新品开发项目台账字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用 |
|---|---|---|---|---|
| 项目编号 | 新品项目唯一编号 | 示例：PD-2026-001 | 是 | 串联项目、报价、订单、复盘 |
| 产品名称 | 开发产品名称 | 示例：补水精华 | 是 | 判断项目对象 |
| 产品定位 | 走量/利润/形象/定制等 | 示例：利润款 | 是 | 判断成本和优先级 |
| 目标客群 | 面向的消费者或客户 | 示例：干皮用户 | 否 | 判断卖点和产品方向 |
| 功效卖点 | 产品核心卖点 | 示例：补水保湿 | 否 | 判断配方和测试需求 |
| 目标成本 | 目标采购或产品成本 | 示例：待确认 | 否 | 判断毛利和报价风险 |
| 当前阶段 | 项目所处阶段 | 示例：打样 | 是 | 判断是否延期或卡点 |
| 目标上市时间 | 计划上市节点 | 示例：2026-09 | 否 | 判断交期风险 |
| 关键风险 | 成本、交期、质量等风险 | 示例：包材交期待确认 | 是 | 输出风险预警 |
| 下一步动作 | 要做什么 | 示例：确认首轮样品反馈 | 是 | 生成行动清单 |
| 来源 | 信息来源 | 示例：销售需求会议 | 是 | 判断数据可信度 |
