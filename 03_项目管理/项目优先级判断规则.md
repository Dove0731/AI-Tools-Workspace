# 项目优先级判断规则

## 判断维度

| 维度 | 高优先级信号 |
|---|---|
| 销售成交 | 客户明确需求、成交概率高、时间紧 |
| 毛利贡献 | 毛利空间高或可带来规模销售 |
| 上市节点 | 已承诺上市或交付时间 |
| 老板关注 | 管理层明确关注或要求 |
| 风险程度 | 不处理会影响成本、交期、质量或客户 |
| 可复制价值 | 可复用到多个产品、供应商或渠道 |

## 优先级口径

| 优先级 | 定义 | 处理方式 |
|---|---|---|
| P0 | 必须立即处理，影响经营结果 | 当天明确方案 |
| P1 | 本周必须推进，影响关键节点 | 每周重点跟踪 |
| P2 | 日常推进事项 | 常规更新 |
| P3 | 储备或低确定性事项 | 定期回顾 |

## AI 使用要求

AI 给项目排序时，不能只看“谁催得急”，必须结合成交概率、毛利、交期、风险和老板关注度。
