# 03_项目管理

## 目录用途

本目录用于管理新品开发、原料开发、包材开发、OEM/ODM 协同、成本优化和重点项目的全过程。

## 存放内容

- 项目管理索引、项目总览、项目推进看板。
- 新品开发项目、原料开发项目、包材开发项目、OEM/ODM 项目台账。
- 项目风险、优先级、进度判断规则。
- 项目复盘模板和已关闭项目记录。

## 更新规则

- 每个项目启动时必须登记项目编号和当前阶段。
- 每周至少更新一次项目进度、风险、下一节点。
- 有成本、交期、质量、供应商风险时，同步进入问题闭环台账。

## 使用方式

1. 新项目先登记到 `项目总览.md`。
2. 按项目类型进入对应子目录维护详细台账。
3. 每周用进度判断规则检查是否延期。
4. 项目关闭后填写复盘模板。
