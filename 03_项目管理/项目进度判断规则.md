# 项目进度判断规则

## 进度状态

| 状态 | 判断标准 | 处理动作 |
|---|---|---|
| 正常 | 当前阶段按计划推进，下一节点清楚 | 周度跟进 |
| 待反馈 | 已提交样品、报价或资料，等待对方反馈 | 写明反馈对象和催办日期 |
| 有延期风险 | 当前节点可能影响下一阶段 | 制定补救方案 |
| 已延期 | 超过计划日期仍未完成 | 进入风险台账并升级 |
| 暂停 | 项目条件不足或业务决定暂停 | 写明暂停原因 |
| 已关闭 | 项目完成、取消或归档 | 填写复盘 |

## 判断方法

| 检查项 | 问题 |
|---|---|
| 阶段 | 当前处于哪个阶段？ |
| 输出物 | 本阶段输出物是否完成？ |
| 时间 | 是否超过计划截止日期？ |
| 依赖 | 是否依赖销售、研发、供应商或工厂反馈？ |
| 风险 | 是否影响上市、成交、成本或交付？ |

## AI 输出要求

AI 判断项目进度时，必须给出：当前状态、延期风险、原因、经营影响、下一步动作。
