# 项目库使用说明

| 状态目录 | 进入条件 | 离开条件 |
|---|---|---|
| `01_待启动` | 已识别目标，但资源、范围或节点尚未全部确认 | 完成立项并明确负责人、里程碑和下一步 |
| `02_进行中` | 已授权启动且存在有效动作 | 完成验收、正式暂停或取消 |
| `03_已暂停` | 有明确暂停原因和恢复条件 | 恢复执行或确认终止 |
| `04_已完成` | 交付物已验收且关键台账已同步 | 完成复盘与归档检查 |
| `05_已归档` | 已复盘、链接完整、无未处理敏感事项 | 原则上只读 |

每个项目只保留一个主项目页。目录移动时同步更新 `status`、`updated` 和 [[03_项目管理/00_项目驾驶舱]]。
