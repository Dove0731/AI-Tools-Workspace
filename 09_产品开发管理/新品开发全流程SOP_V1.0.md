# 新品开发全流程 SOP V1.0

> 文件状态：**试运行版，可直接执行**  
> 适用范围：化妆品新品、老品升级、客户定制、原料/包材创新及OEM/ODM项目  
> 生效日期：2026-07-15  
> 流程负责人：产品开发负责人（姓名待确认）  
> 执行台账：[新品开发 Stage-Gate 总台账](./新品开发Stage-Gate总台账.md)  
> 经营依据：[2026年上架新品复盘](./产品复盘/2026-07-13_2026年上架新品产品开发复盘总结.md)  
> 管理背景：[张总分享行动台账 ZS-ACT-202607-010](../11_张总分享专区/03_行动转化/张总分享行动台账.md)

## 1. 目的

把新品开发从“完成立项、打样、备案、生产”等动作，升级为以客户价值、毛利、交付、质量、库存、现金流和复购为结果的 Stage-Gate 管理流程。

每个项目必须经过：

`需求入池 → 立项 → 产品定位 → 技术/供应链可行性 → 配方原料 → 包材 → 打样 → 测试/法规 → 成本报价 → 定版 → 下单/量产准备 → 量产放行 → 出货上市 → 30/60/90天复盘`

任何阶段没有达到门禁条件，不得自动进入下一阶段。

## 2. 核心经营原则

1. **先客户和商业验证，后打样与投入。** 无目标客户、无使用场景、无价格验证的项目只进入概念池。
2. **先算绝对毛利和现金占用，后判断毛利率。** 同时考虑税费、物流、损耗、MOQ、账期、促销、退货及专用库存。
3. **先小单验证，后备货放量。** 未验证复购逻辑的项目不得形成大额专用原料、包材或模具投入。
4. **技术、法规、质量、供应链与销售并行评审。** 任何一项未通过，不得以其他部门已完成为理由跳关。
5. **每一关都有退出条件。** 停止项目是经营决策，不是开发失败；退出必须处理库存、在途、订单和资料。
6. **出货不是终点，复购才是商业验证。** 上市后必须跟踪30/60/90天销量、返单、毛利额、客诉、库存和回款。

## 3. 产品定位分类

立项时只能选择一种主定位，可设置一种辅助定位：

| 定位 | 核心目标 | 必须关注 | 禁止误区 |
|---|---|---|---|
| 走量款 | 规模、交付效率和复购 | 客户覆盖、产能、成本、交期 | 只追求低价，不看绝对毛利和账期 |
| 利润款 | 毛利额和客户价值 | 差异化、价格接受度、复购 | 只看高毛利率，没有真实销量 |
| 形象款 | 品牌与销售支持 | 卖点证据、视觉、传播场景 | 无预算、无推广计划仍量产备货 |
| 定制款 | 满足明确客户订单 | 客户确认、首单、专用物料、退出责任 | 客户未确认即开模、备料或备案 |
| 储备款 | 建立技术或市场储备 | 验证目标、投入上限、停止日期 | 把储备项目包装成正式量产项目 |

## 4. 角色与责任

| 角色 | 主要责任 | 必须确认的门禁 |
|---|---|---|
| 产品开发负责人 | 项目立项、Stage-Gate推进、跨部门闭环 | 定位、里程碑、阶段结论、停止/继续建议 |
| 销售/客户负责人 | 提供客户需求、价格接受度、首单和复购证据 | 客户为什么买、买多少、何时买、是否愿意付费验证 |
| 研发/配方 | 配方、剂型、功效原料、肤感和技术风险 | 配方可行、版本可追溯、技术问题关闭 |
| 采购 | 原料、包材、OEM/ODM价格、MOQ、交期、付款和替代供应 | 到手成本、齐套节点、专用库存和单一供应风险 |
| 品质/法规/备案 | 测试方案、法规资料、宣称、备案和质量放行 | 测试通过、资料完整、备案/标签合规、批次放行 |
| 财务/成本 | 全成本、毛利额、账期、现金占用和投入上限 | 成本口径一致、经济模型成立 |
| 生产/OEM/ODM | 工艺、设备适配、排产、首件和量产稳定性 | 物料齐套、产能、工艺参数、质量记录 |
| 包装设计/市场 | 视觉、卖点表达、资料和上市计划 | 客户/渠道确认、上市物料齐套 |
| 张总/批准人 | 战略项目、重大投入、例外放行和停止损失决策 | 方向、预算、风险上限和例外条件 |

每个项目只能有一名项目总负责人。跨部门责任人不能替代项目总负责人。

## 5. 项目状态

统一使用以下状态：

| 状态 | 定义 | 允许动作 |
|---|---|---|
| 概念池 | 有想法但商业证据不足 | 调研、客户访谈、概念卡；不得备料和量产 |
| 待验证 | 客户兴趣存在，经济模型或技术尚未证实 | 付费打样、小单测试、技术验证 |
| 进行中 | 已通过立项门禁并按计划推进 | 执行当前阶段动作 |
| 风险 | 成本、交期、质量、法规、客户或库存偏离 | 只执行问题关闭动作，不自动跳关 |
| 暂停 | 等待客户、测试、资料或决策 | 停止新增投入，保留已确认资料 |
| 通过 | 当前阶段门禁全部满足 | 进入下一阶段 |
| 停止 | 商业、技术或风险条件不成立 | 执行库存、订单、费用和资料退出 |
| 已归档 | 项目结束且资料、复盘和关闭证据完整 | 仅用于复用和历史查询 |

## 6. Stage-Gate 全流程

### G0 需求入池

| 项目 | 要求 |
|---|---|
| 输入 | 客户需求、销售机会、市场洞察、老板方向、老品问题或技术储备 |
| 必做动作 | 记录需求原话、来源、目标客户、使用场景、预计时间和需求可信度 |
| 输出 | 需求卡/概念卡、来源证据 |
| 通过条件 | 需求对象和来源明确；至少能说明“谁可能买、为什么需要” |
| 未通过处理 | 进入概念池；不得直接打样、备案、开模或采购专用物料 |

### G1 立项评审

| 项目 | 要求 |
|---|---|
| 输入 | 需求卡、客户/市场证据、竞品、初步成本和供应链判断 |
| 必做动作 | 评估客户价值、战略价值、预计首单、售价区间、成本目标、上市节点、失败损失 |
| 输出 | [新品立项评审表](./新品立项/新品立项评审表.md)、项目编号、项目总负责人 |
| 通过条件 | 客户证据或明确战略理由成立；目标价、成本目标、投入上限、停止条件明确 |
| 未通过处理 | 待验证或停止；无目标客户、无价格验证、无退出机制不得正式立项 |

### G2 产品定位与商业方案

| 项目 | 要求 |
|---|---|
| 输入 | 已批准立项表、客户/渠道信息、竞品和公司能力 |
| 必做动作 | 明确走量/利润/形象/定制/储备定位，目标人群、场景、核心卖点、规格、目标采购价、建议售价、首单和复购逻辑 |
| 输出 | 产品定位书、卖点证据清单、商业假设表 |
| 通过条件 | 定位唯一且可验证；客户购买理由、价格带、销售场景和复购触发清楚 |
| 未通过处理 | 返回G0/G1；禁止用“成分热门、市场可能喜欢”代替定位 |

### G3 技术与供应链可行性

| 项目 | 要求 |
|---|---|
| 输入 | 产品定位书、规格、目标成本、上市时间 |
| 必做动作 | 评估剂型、设备、工艺、原料、包材、OEM/ODM、法规、产能和替代供应 |
| 输出 | 可行性评估、关键风险清单、初步倒排计划 |
| 通过条件 | 技术可实现；关键物料和工厂有方案；法规路径明确；最坏交期与库存暴露可接受 |
| 未通过处理 | 优化方案、付费验证或停止；非现有设备项目必须单独说明新增投入和回收逻辑 |

### G4 配方与原料方案

| 项目 | 要求 |
|---|---|
| 输入 | 功效、剂型、肤感、禁限用要求、目标成本 |
| 必做动作 | 确定配方方向、功效原料、供应商、资料、价格、交期、替代方案和法规风险 |
| 输出 | 配方方向记录、原料筛选表、样品BOM V0.x |
| 通过条件 | 原料资料齐全；关键原料有价格/交期；高风险原料有替代或批准的单一供应方案 |
| 未通过处理 | 不进入正式打样；不得先采购大货再补资料 |

### G5 包材方案

| 项目 | 要求 |
|---|---|
| 输入 | 剂型、灌装要求、规格、视觉和目标成本 |
| 必做动作 | 评估材质、密封、兼容性、工艺、MOQ、模具费、版费、损耗、交期、共用性和备选供应商 |
| 输出 | 包材方案、供应商比价、兼容性计划、包材BOM V0.x |
| 通过条件 | 规格与内容物匹配；MOQ和现金占用可接受；专用包材有消化/退出方案 |
| 未通过处理 | 继续找共用包材或小单方案；不得仅凭外观确定包材 |

### G6 打样与版本管理

| 项目 | 要求 |
|---|---|
| 输入 | 配方/包材方案、打样目标和评价标准 |
| 必做动作 | 每版样品编号，记录配方、包材、日期、反馈、责任人和下一版变化 |
| 输出 | [打样跟进台账](./打样管理/打样跟进台账.md)、样品版本记录、客户确认记录 |
| 通过条件 | 样品达到预设肤感、外观、气味、规格及客户/内部评价标准 |
| 未通过处理 | 明确调整次数和停止条件；禁止无标准反复打样 |

### G7 测试、质量与法规

| 项目 | 要求 |
|---|---|
| 输入 | 候选定版样、包材、宣称和法规路径 |
| 必做动作 | 内测、稳定性、兼容性、必要功效/安全测试、备案资料、标签和宣称审核 |
| 输出 | [样品测试反馈表](./测试与评估/样品测试反馈表.md)、测试报告、备案/法规清单 |
| 通过条件 | 必要测试通过；问题关闭；备案、标签和宣称可执行 |
| 未通过处理 | 返回G4/G5/G6；未通过不得定版、量产或对客户承诺上市日期 |

### G8 成本核算与报价

| 项目 | 要求 |
|---|---|
| 输入 | 候选BOM、工费、损耗、税费、物流、模具/版费、MOQ、账期和预计销量 |
| 必做动作 | 计算单位全成本、绝对毛利、毛利率、首单投入、库存暴露和现金占用；形成报价策略 |
| 输出 | 成本核算表、报价建议、经济模型、价格批准记录 |
| 通过条件 | 成本口径完整；售价可接受；绝对毛利和现金风险符合项目定位 |
| 未通过处理 | 降本、改规格、谈MOQ/账期、调整定位或停止；不得只用毛利率通过 |

### G9 定版与变更冻结

| 项目 | 要求 |
|---|---|
| 输入 | 测试通过样、最终BOM、包材、图稿、规格、成本和客户确认 |
| 必做动作 | 签署封样；冻结配方、BOM、图稿、质量标准、工艺和报价版本 |
| 输出 | 定版记录、封样、BOM V1.0、图稿V1.0、质量标准、变更控制表 |
| 通过条件 | 产品、客户、研发、品质、采购、生产相关方完成确认 |
| 未通过处理 | 不得下正式采购/生产订单；定版后变更必须评估成本、交期、库存和法规影响 |

### G10 下单与量产准备

| 项目 | 要求 |
|---|---|
| 输入 | 已冻结BOM、销售/客户订单、物料计划、排产和付款条件 |
| 必做动作 | 确认原料/包材订单、ETA、物料齐套、排产、首件、检验计划、备案和客户交期 |
| 输出 | 采购订单、物料齐套表、量产检查表、上市倒排计划 |
| 通过条件 | 订单依据明确；物料、产能、质量、法规、付款和客户交期均有责任人和节点 |
| 未通过处理 | 风险状态；不得用“先下单再补确认”绕过门禁 |

### G11 量产、检验与放行

| 项目 | 要求 |
|---|---|
| 输入 | 放行版BOM/工艺、齐套物料、生产计划和质量标准 |
| 必做动作 | 首件确认、过程检验、异常处理、成品检验、留样和批次追溯 |
| 输出 | 生产记录、检验报告、批次放行记录、异常单 |
| 通过条件 | 数量、质量、标签、包装和批次资料符合标准；异常已关闭或批准偏差放行 |
| 未通过处理 | 隔离、返工、重产或报废；未经品质放行不得出货 |

### G12 出货与上市

| 项目 | 要求 |
|---|---|
| 输入 | 放行成品、客户/销售订单、物流安排、上市资料和回款条件 |
| 必做动作 | 核对数量、批次、交期、运输、签收、发票/付款节点、销售资料和客服口径 |
| 输出 | 出货单、签收/上架确认、客户交付记录、上市资料包 |
| 通过条件 | 按约交付并取得签收/上架证据；回款节点明确；销售资料齐套 |
| 未通过处理 | 进入交付异常闭环；不得把“已生产”当作“已实现收入” |

### G13 30/60/90天经营复盘

| 节点 | 必查内容 | 决策输出 |
|---|---|---|
| 30天 | 首单交付、客户反馈、质量异常、退货、初销、库存和回款 | 问题关闭、继续观察或暂停补货 |
| 60天 | 补货/返单、毛利额、销售转化、库存周转、客诉和供应稳定 | 放量、优化、小单验证或停止 |
| 90天 | 累计销量、复购、客户贡献、利润、库存损失、流程问题和可复制经验 | 主推/常规/储备/淘汰；形成案例或SOP修订 |

复盘必须使用[产品上市复盘模板](./产品复盘/产品上市复盘模板.md)，不得只写“市场反馈一般”。

## 7. 四类阶段决策

| 决策 | 适用条件 | 后续动作 |
|---|---|---|
| 开发/放量 | 客户明确、经济模型成立、交付质量可控、已有付费验证或返单 | 进入下一阶段或主推池 |
| 优化后再决策 | 需求真实，但存在成本、交期、质量、法规或包材问题 | 只执行问题关闭动作 |
| 小单验证 | 客户兴趣真实，但订单、复购或经济模型未证实 | 付费打样或最小试单，不做专用库存 |
| 停止/冻结 | 无客户、无返单、负毛利、风险不可控或验证失败 | 停止新增投入，处理库存/在途/订单并复盘 |

## 8. 禁止跳关事项

- 无立项编号和项目负责人，不得进入正式打样。
- 无客户证据或战略批准，不得采购专用物料。
- 无测试/法规结论，不得定版。
- 无完整成本和报价批准，不得承诺客户价格。
- 无冻结BOM、封样和图稿，不得下量产单。
- 无物料齐套、排产和质量计划，不得承诺出货。
- 无品质放行，不得出货。
- 无30/60/90天数据，不得宣布新品成功或直接复制扩品。

确需例外时，必须记录批准人、例外原因、投入上限、风险承担、截止日期和退出条件。

## 9. 变更管理

定版后任何配方、原料、包材、供应商、工艺、图稿、规格、数量或交期变化，必须填写变更记录，并重新评估：

1. 成本与毛利；
2. MOQ、库存和已下订单；
3. 测试、兼容性和法规；
4. 生产排期和客户交期；
5. 质量标准和追溯；
6. 客户是否需要重新确认。

影响门禁条件的变更必须退回对应阶段重新评审。

## 10. 项目例会与升级

| 频率/触发 | 内容 | 输出 |
|---|---|---|
| 每周项目例会 | 各项目阶段、下一个门禁、卡点、责任人和截止时间 | 更新Stage-Gate总台账 |
| P0事件 | 已影响客户、上市、重大质量、负毛利或大额库存 | 30分钟内升级，不等待例会 |
| 阶段评审 | 进入下一阶段前 | 通过/退回/暂停/停止结论及证据 |
| 月度组合复盘 | 全部在研、上市和停止项目 | 资源重新分配、停止清单和老板决策项 |

## 11. 经营指标

| 指标 | 口径 | 当前状态 |
|---|---|---|
| 立项商业证据完整率 | 有客户证据或战略批准项目 / 正式立项项目 | 待建立基线 |
| 付费试单率 | 付费试单项目 / 进入客户验证项目 | 待建立基线 |
| 打样一次通过率 | 一次通过样品 / 总打样项目 | 待建立基线 |
| 开发周期 | 立项通过至首次合格出货天数 | 待建立基线 |
| 准时出货率 | 按承诺日期出货项目 / 应出货项目 | 待建立基线 |
| 60天返单率 | 首单后60天内返单项目 / 已完成首单项目 | 返单定义待统一 |
| 新品毛利额 | 新品收入－全成本 | 成本口径待统一 |
| 库存暴露 | 新品专用库存+在途+不可取消订单 | 数据待补 |
| 停止及时率 | 达到停止条件后按期关闭项目 / 应停止项目 | 待建立基线 |

目标值必须在取得基线后由管理层确认，SOP不预设未经批准的数字。
