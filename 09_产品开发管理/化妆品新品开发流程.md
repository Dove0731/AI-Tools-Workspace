# 化妆品新品开发流程

> 本文件为阶段总览。具体准入条件、责任、禁止跳关、变更控制、出货放行和30/60/90天复盘，以[《新品开发全流程SOP V1.0》](./新品开发全流程SOP_V1.0.md)为准。

## 标准阶段

| 阶段 | 关键动作 | 输出物 |
|---|---|---|
| 立项 | 明确需求、定位、目标成本、上市时间 | 立项评估 |
| 配方方向确认 | 明确功效、肤感、剂型、禁用要求 | 配方方向记录 |
| 原料筛选 | 询样、资料、报价、风险评估 | 原料筛选表 |
| 包材筛选 | 规格、材质、工艺、MOQ、交期 | 包材方案 |
| 打样 | 工厂/研发出样 | 样品记录 |
| 内测 | 肤感、气味、外观初评 | 内测反馈 |
| 稳定性测试 | 稳定性、兼容性、必要测试 | 测试记录 |
| 成本核算 | 原料、包材、工费、损耗 | 成本表 |
| 报价确认 | 结合毛利和成交判断 | 报价建议 |
| 定版 | 配方、包材、资料确认 | 定版记录 |
| 下单 | 原料、包材、工厂订单 | 采购订单 |
| 量产 | 排产、来料、生产、检验 | 量产记录 |
| 上市 | 发货、上架、销售资料 | 上市清单 |
| 复盘 | 总结周期、成本、问题、经验 | 复盘报告 |
