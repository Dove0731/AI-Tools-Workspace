# 09_产品开发管理

## 目录用途

本目录用于管理化妆品新品从立项到上市复盘的全过程，重点关注产品定位、配方、原料、包材、打样、测试、成本和上市节点。

## 存放内容

- 化妆品新品开发流程。
- 立项、配方协同、原料筛选、包材匹配、打样、成本、上市检查规则。
- 产品开发动作台账和产品复盘资料。

## 更新规则

- 新品项目启动时必须登记阶段、成本目标、上市时间和风险。
- 每次打样、测试、报价和确认都要更新状态。
- 上市前必须完成检查清单。

## 使用方式

1. 先按产品立项评估规则判断是否值得做。
2. 按开发流程推进每个阶段。
3. 有风险时同步到项目管理和问题闭环。
4. 上市后做产品复盘。
