# 2026 年下半年面膜产品开发方向方案 V3.0

> 方案编号：PD-PLAN-MASK-H2-2026  
> 状态：待产品决策会确认  
> 原则：基础款重跟踪，加强款按功效顺序开发；先定客户，再定产品

## 一、整体方向

下半年面膜产品分为两条线：

1. **基础跑量款**：不急于继续增加新品，重点跟进已经上市和即将投产的产品，验证销量、返单和毛利。
2. **加强功效款**：按“修复退红 → 即时美白 → 即时紧致”的顺序逐步补齐，不同时铺开多个功效。

每款新品立项前，必须先明确使用场景、客户画像、目标客户、产品成本预算和毛利预算。没有明确目标客户的产品，不进入正式立项。

## 二、基础跑量款：先跟进现有新品

### 1. B5 舒护面膜

目前已推出新品，下一步不再停留在产品开发阶段，重点跟踪上市后的实际经营数据：

- 销售客户及对应业务人员；
- 送样、报价、首单和返单情况；
- 销量、销售额、实际成本和实际毛利；
- 客户对肤感、舒护效果、膜布和包装的反馈；
- 质量异常、退货及库存情况；
- 30/60/90 天产品复盘结论。

根据实际销售结果判断该产品进入主推、优化、观察或停止状态。

### 2. 三重胶原蛋白妆字号面膜

目前处于投产准备阶段，重点做好以下事项：

- 明确投产、检验、放行和首批出货节点；
- 确认首批目标客户、预计订单和业务负责人；
- 投产前复核产品成本、客户报价和毛利预算；
- 记录首批生产数量、交付数量、客户反馈和库存；
- 出货后跟踪销售、返单、实际毛利及质量表现。

该产品是否继续放量，以客户订单、返单和实际毛利为依据，不以完成投产作为成功标准。

## 三、加强功效款：按顺序逐步开发

### 第一优先：修复退红类面膜

修复、退红功效能够在较短使用时间内呈现较直接的体验，适合现场体验、销售演示和重点客户强推，应作为下半年加强功效款的第一开发方向。

立项前由销售端补充：

- 初步目标客户及对应业务人员；
- 客户的使用场景和实际问题；
- 客户能够接受的价格区间；
- 预计首单数量和采购频率；
- 是否愿意试样、付费打样或试单；
- 产品成本预算和毛利预算。

产品端重点验证：

- 使用后舒缓、退红的即时体验；
- 不同肤质的使用感受和刺激风险；
- 配方、膜布和精华量的匹配；
- 稳定性、兼容性、安全及功效证据；
- 产品宣称和销售话术是否合规。

内部测试只能判断即时体验和是否值得继续测试，最终是否立项、投产和放量，必须结合客户试用、价格接受和试单结果。

### 第二优先：即时美白类面膜

修复退红类完成阶段验证后，再推进即时美白类。

重点不是简单增加美白成分，而是明确：

- 哪类客户需要现场可感知的提亮效果；
- 产品用于门店体验、直播展示、客户定制还是日常销售；
- 客户接受的采购价和零售价；
- 即时提亮体验如何评价；
- 长期美白功效如何验证；
- 美白功效、产品命名、宣称及相关资料是否符合要求。

即时体验和长期功效必须分开验证，不得用一次内部试用替代正式功效依据。

### 第三优先：即时紧致类面膜

即时美白类形成明确阶段结论后，再推进即时紧致类。

重点验证：

- 目标客户是否有抗皱、紧致、重要场合即时护理等需求；
- 产品是否适合现场体验和前后对比展示；
- 客户是否接受对应价格和试单数量；
- 即时肤感、贴合感和紧致体验；
- 持续使用效果、功效证据和宣称边界；
- 胶原类产品之间是否重复，能否形成清晰差异。

若与三重胶原蛋白面膜定位重叠，应优先做现有产品升级或销售场景优化，不重复开发同质新品。

## 四、客户盘与销售端要求

在每个功效方向立项前，销售端先对现有客户盘进行分类，至少记录：

| 分类字段 | 需要明确的内容 |
|---|---|
| 客户类型 | 品牌客户、批发客户、渠道客户、定制客户等 |
| 销售场景 | 门店体验、现场强推、直播展示、日常复购、客户定制等 |
| 价格带 | 客户现有采购价、可接受价格和目标零售价 |
| 当前产品 | 客户目前销售什么面膜，存在什么问题 |
| 功效需求 | 修复退红、即时美白、即时紧致或其他明确需求 |
| 订单能力 | 预计首单、补货周期、历史面膜订单和返单情况 |
| 跟进责任 | 对应业务人员、下一步动作和反馈日期 |

每款拟立项新品都必须形成目标客户清单，原则上每名相关业务人员至少落实 1 个明确强推客户，并写清：

- 客户名称；
- 为什么适合该产品；
- 准备在哪个场景推广；
- 客户能够接受的价格；
- 预计何时送样、报价和反馈。

没有目标客户清单，不安排正式打样；客户只表示“可以看看”，但没有价格、试样或试单意愿的，不作为有效立项依据。

## 五、新品立项必须确认的内容

| 项目 | 立项要求 |
|---|---|
| 使用场景 | 明确用于现场强推、门店体验、直播展示、日常复购或客户定制 |
| 客户画像 | 客户类型、渠道、价格带、现有产品和主要问题 |
| 目标客户 | 明确客户名称、对应业务人员和推进计划 |
| 产品方向 | 核心功效、即时体验、配方/膜布方向和产品差异 |
| 产品成本预算 | 原料、膜布、袋材、加工、损耗、检测/备案、物流及税费 |
| 毛利预算 | 目标客户价、单位毛利、毛利率和预计订单贡献毛利 |
| 项目投入 | 打样次数、测试费用、专用物料和库存上限 |
| 验证标准 | 客户试用、价格接受、质量合规、试单和返单标准 |
| 项目责任 | 唯一经营 Owner、销售负责人、研发、采购、财务和品控/法规 |
| 停止条件 | 客户不接受价格、毛利不成立、测试不通过或无试单意愿时停止 |

以上内容未确认完整，不进入正式立项。

## 六、下半年执行顺序

1. 跟进 B5 舒护面膜销售数据并建立 30/60/90 天复盘；
2. 完成三重胶原蛋白妆字号面膜投产、首批客户和毛利预算确认；
3. 销售端完成修复退红类客户盘分类及强推客户名单；
4. 确认修复退红类使用场景、产品成本预算和毛利预算后立项；
5. 修复退红类取得客户和阶段验证结果后，再启动即时美白类；
6. 即时美白类形成阶段结论后，再启动即时紧致类；
7. 每款产品上市后统一记录销量、返单、实际毛利、客户反馈、质量和库存，并形成产品复盘。

## 七、下半年产品方向表

| 产品方向 | 当前状态 | 下半年动作 | 进入下一阶段的标准 |
|---|---|---|---|
| B5 舒护面膜 | 已出新品 | 跟踪销售、返单、毛利、反馈和库存 | 形成30/60/90天复盘结论 |
| 三重胶原蛋白妆字号面膜 | 准备投产 | 确认投产、首批客户、报价和毛利预算 | 完成放行、出货及首批经营数据记录 |
| 修复退红加强款 | 第一开发优先级 | 先补客户方向、场景、成本和毛利预算 | 有目标客户、价格接受和试样/试单意愿 |
| 即时美白加强款 | 第二开发优先级 | 修复退红类验证后启动 | 客户、即时体验、长期功效及合规路径明确 |
| 即时紧致加强款 | 第三开发优先级 | 即时美白类形成结论后启动 | 与现有胶原产品差异明确，客户和商业模型成立 |

## 八、最终要求

下半年面膜开发不再从“研发准备做什么功效”出发，而是从“现有产品卖得怎么样、客户需要什么、业务准备推给谁、公司能赚多少”出发。

基础款先把 B5 舒护和三重胶原两款的上市、销售、返单和毛利跟清楚；加强款按修复退红、即时美白、即时紧致的顺序逐步补齐。每款产品在立项时必须同步确定使用场景、客户画像、目标客户、产品成本预算和毛利预算，否则不进入正式开发。
