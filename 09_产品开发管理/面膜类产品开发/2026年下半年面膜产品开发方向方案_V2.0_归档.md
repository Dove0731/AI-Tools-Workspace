# 2026 年下半年面膜新品开发方向方案 V2.0

> 方案编号：PD-PLAN-MASK-H2-2026  
> 状态：待产品决策会批准  
> 执行标准：[面膜类产品开发与商业验证闭环 SOP V1.0](./面膜类产品开发与商业验证闭环SOP_V1.0.md)  
> 数据限制：历史销量和毛利来自现有总结材料，毛利须用订单及财务底表复核

## 一、直接结论

下半年面膜新品只主动推进两类：

1. **基础修护型贴片面膜**：做稳定、易复购、可标准化的走量基础款；
2. **胶原紧致型贴片面膜**：做客户愿意支付更高价格的利润款。

另外保留两类，但不主动备货：

3. **亮肤/水光/DNA等客户定制面膜**：有明确客户、价格和试单才做；
4. **水凝胶贴、冻干面膜等特殊形态**：只进入订单制机会池。

同时必须对黑色 377、深蓝面膜、红白胶原等高销量低毛利产品做利润改善。该项不是新增 SKU，但优先级高于继续开发同质新品。

下半年首批建议采用：

- 1 个基础修护型贴片面膜新品；
- 1 个胶原紧致型贴片面膜新品；
- 1 个现有放量面膜利润改善项目。

任一新品未取得客户价格和试单证据，不得为了完成数量替换成其他功效继续开发。

## 二、具体做什么产品

### 方向 1：基础修护型贴片面膜——走量基础款

| 项目 | 要求 |
|---|---|
| 产品定位 | 稳定复购、交付快、成本可控的基础走量款 |
| 核心功效 | 保湿、舒缓、修护；最终主功效根据客户验证三选一，不同时堆叠多个概念 |
| 目标客户 | 已有面膜客户、需要基础通用款的批发/OEM客户、需要稳定补货产品的渠道客户 |
| 产品形态 | 贴片面膜，优先使用公司成熟配方平台、成熟膜布、通用袋材和现有灌装工艺 |
| 开发重点 | 肤感稳定、膜布贴合、精华浸润均匀、不易滴液、袋材密封稳定、MOQ和交期可控 |
| 商业模式 | 标准底盘＋客户前端定制；配方、膜布和袋材尽量跨客户复用 |
| 不做什么 | 不做多个相似保湿/舒缓 SKU；不使用客户未确认的专用膜布和专版袋材备货 |

#### 必须验证的标准

1. 至少有 1 个明确客户场景和可追溯需求记录；
2. 客户接受采购价格区间、MOQ和交期；
3. 取得付费打样、书面试单意向或批准的替代承诺；
4. 全成本和贡献毛利达到公司批准门槛；
5. 配方、膜布、袋材和灌装工艺均可使用成熟供应链；
6. 客户样对肤感、贴合、气味、精华量和包装形成书面确认；
7. 稳定性、兼容性、微生物/安全、包装密封及法规审查全部通过；
8. 首单后进入 30/60/90 天复盘，以返单和实际贡献毛利决定是否成为标准款。

### 方向 2：胶原紧致型贴片面膜——利润款

| 项目 | 要求 |
|---|---|
| 产品定位 | 有明确体验差异、证据路径和利润空间的高价值面膜 |
| 核心方向 | 胶原/紧致；不提前批准多个成分组合 |
| 历史依据 | 公司已有胶原紧致类面膜销量和返单样板 |
| 目标客户 | 接受更高采购价格、需要差异化销售理由、具备中高价格带的客户 |
| 开发重点 | 即时肤感、持续使用方案、卖点证据、功效/宣称边界、完整成本和客户支付意愿 |
| 商业模式 | 先做客户验证，再做配方和功效方案；不做无目标客户的高成本技术堆料 |
| 不做什么 | 不以内部试用证明抗皱或紧致功效；不在客户未接受价格前采购高成本专用原料 |

#### 必须验证的标准

1. 客户明确接受高于基础款的价格带，并说明购买理由；
2. 客户愿意付费打样或书面确认试单条件；
3. 配方中的关键成分、添加依据、供应资料和宣称证据路径完整；
4. 即时体验与长期功效分开评价：内部试用只评价肤感和是否继续测试，长期功效必须按批准的测试方案验证；
5. 完整成本包含原料、膜布、袋材、加工、损耗、检测/备案、物流和税费；
6. 贡献毛利达到公司批准的利润款门槛；
7. 客户样书面通过，且报价、MOQ、交期和试单数量确认；
8. 稳定性、兼容性、质量、法规和功效/宣称审查通过；
9. 试单实际毛利达到批准目标，60 天内是否返单作为放量依据。

### 方向 3：亮肤/水光/DNA等客户定制面膜——订单驱动

这类方向有历史销量样板，但不作为公司主动铺 SKU 的主线。

只在同时满足以下条件时启动：

1. 有具体客户，不接受“市场可能需要”；
2. 客户确认概念、规格、设计方向和采购价格；
3. 客户接受 MOQ、交期和首单数量；
4. 客户付费打样或形成书面试单承诺；
5. 完整成本和毛利通过财务评审；
6. 亮肤/美白等功效及宣传用语通过品控/法规审查；
7. 专用原料、膜布和袋材有客户承担或明确消化方案。

未满足以上条件，保留概念卡，不打样、不备料、不生产。

### 方向 4：水凝胶贴、冻干面膜等特殊形态——订单制机会池

| 类型 | 当前判断 | 启动条件 |
|---|---|---|
| 水凝胶眼贴、额头贴、法令纹贴 | 有供应商，但历史同类产品无返单 | 客户确认价格、MOQ并付费打样/试单 |
| 灌装凝固型水凝胶面膜 | 工艺、设备和兼容性风险高于普通贴片面膜 | 完成专项技术、质量、法规和投入评审 |
| 冻干面膜 | 需单独评估质量、交付、成本和使用方式 | 有客户订单证据，且经济模型成立 |

统一要求：不做现货、不提前采购专用物料、不列入常规开品 KPI。

## 三、现有放量面膜必须先做利润改善

| 产品样板 | 现有材料表现 | 下半年处理 |
|---|---|---|
| 黑色 377 面膜 | 销量 370,528、已返单；材料测算毛利率约 14.9% | 复核真实成本和订单毛利；评估调价、数量阶梯、膜布/袋材优化和客户战略价值 |
| 深蓝面膜 | 销量 40,307、已返单；材料测算毛利率约 16.6% | 复核规格、加工、损耗和报价，优先谈共用物料及数量阶梯 |
| 红白胶原面膜 | 销量 37,006、已返单；材料测算毛利率约 17.9% | 核对单片毛利、返单周期和客户贡献，决定保留、调价或改规格 |

以上毛利率均待财务底表复核。复核前不得直接据此调价、换供应商或降低质量标准。

每个改善项目只能形成以下五种结论之一：

- 保留现方案；
- 调整报价；
- 降本但不降低质量标准；
- 调整规格/MOQ/账期；
- 限量接单或停止。

## 四、所有面膜新品统一验证标准

### Gate 1：客户需求通过——才能进入商业测算

必须同时具备：

- 明确客户或明确客户类型；
- 客户问题原话、历史订单、询盘或书面沟通证据；
- 明确使用场景、渠道和价格带；
- 明确客户为什么不用现有产品。

以下情况不通过：内部觉得有市场、供应商推荐、管理人员试用感受好、仅有热门成分概念。

### Gate 2：商业验证通过——才能正式立项和打样

必须同时具备：

- 客户接受价格区间、MOQ和交期；
- 付费打样、书面试单意向或批准的战略例外；
- 完整成本测算；
- 贡献毛利达到公司批准门槛；
- 打样预算、次数上限、专用库存上限和停止条件明确。

没有客户承诺或毛利不成立，不打样。

### Gate 3：产品样通过——才能进入正式测试

必须同时具备：

- 样品编号以及配方、膜布、袋材、灌装量版本完整；
- 内部评价按预先设定的肤感、气味、贴合、滴液、浸润、展开和包装标准记录；
- 客户对样品、价格和修改项形成书面反馈；
- 关键问题有责任人和关闭日期。

“感觉不错”“可以”“有效果”不作为通过证据。

### Gate 4：质量与法规通过——才能定版

必须全部通过：

- 配方稳定性；
- 精华—膜布—袋材兼容性；
- 微生物、安全及必要功效验证；
- 袋材密封、渗漏和运输风险；
- 标称量、外观、膜布尺寸和批次一致性；
- 标签、宣称和备案/注册路径审查。

具体方法和阈值由品控/法规写入项目质量标准。存在未关闭的重大问题，不得定版。

### Gate 5：定版与试产通过——才能生产首单

必须同时具备：

- 客户书面确认产品、图稿、规格、数量、价格和交期；
- BOM、配方、膜布、袋材、图稿、工艺和质量标准冻结；
- 原包材齐套，批次和检验状态清楚；
- 首件、过程检验、成品检验和留样计划明确；
- 财务复核最终成本和毛利；
- 品控完成批次放行。

无客户订单或批准的最小验证依据，不生产；无品控放行，不出货。

### Gate 6：经营结果通过——才能定义为成功产品

必须检查：

- 30 天：客户反馈、质量、退货、回款、实际毛利和剩余库存；
- 60 天：是否返单、贡献毛利、库存周转和供应稳定；
- 90 天：累计订单、客户贡献、质量交付、库存损失和资源投入。

只有实际毛利达到批准目标，并形成返单或明确可持续订单，才能进入主推产品池。首单出货不等于开发成功。

## 五、下半年执行清单

| 时间 | 只做什么 | 输出 |
|---|---|---|
| 7 月下旬—8 月 | 复核历史面膜订单、成本、毛利和返单；确定基础修护、胶原紧致各自的目标客户 | 2张客户问题卡、1个利润改善清单 |
| 8—9 月 | 验证价格、MOQ、交期和付费打样/试单 | Gate 1、Gate 2评审结论 |
| 9—10 月 | 只对通过项目打样并取得客户确认 | 样品版本、客户反馈、Gate 3结论 |
| 10—11 月 | 完成质量、法规、定版和最小试单 | Gate 4、Gate 5放行记录 |
| 11—12 月 | 交付并完成30天复盘 | 实际毛利、质量、库存和继续/停止决定 |
| 2027年一季度 | 完成60/90天复盘 | 返单及主推/淘汰结论 |

如果基础修护型或胶原紧致型在 Gate 2 未通过，下半年不强行补做其他新品。

## 六、硬性管理标准

| 标准 | 要求 |
|---|---|
| 正式立项客户证据完整率 | 100% |
| 正式立项全成本复核率 | 100% |
| 未取得客户承诺前专用物料备货 | 0 |
| 未通过质量/法规放行的量产和出货 | 0 |
| 负毛利新品 | 0；战略例外须管理层书面批准 |
| 面膜项目唯一经营 Owner | 100%明确到人 |
| 首单项目30/60/90天复盘 | 100%执行 |

公司最低贡献毛利率、单项目预算上限、打样次数上限和专用库存金额上限，必须在产品决策会上确认；未确认前统一标“待确认”，不得自行填数。

## 七、停止条件

出现任一情况，暂停新增投入并提交继续/停止决策：

1. 没有明确客户或客户问题证据；
2. 客户不接受价格、MOQ或交期；
3. 客户不愿付费打样或提供有效试单承诺；
4. 全成本或贡献毛利低于批准门槛；
5. 打样次数、预算或时间达到批准上限；
6. 稳定性、兼容性、质量、功效/宣称或法规问题无法关闭；
7. 专用物料或现金占用超过批准上限；
8. 试单发生重大质量、交付、退货或亏损问题；
9. 客户机会取消或商业假设失效。

## 八、管理层只需决定四件事

1. 是否批准下半年主动开发“基础修护型＋胶原紧致型”两类贴片面膜；
2. 分别指定目标客户和唯一经营 Owner；
3. 确认最低贡献毛利、预算、打样次数和专用库存上限；
4. 确认哪个现有放量面膜先进入利润改善项目。

上述四项未确认，不启动正式打样。
