# 产品立项评估规则

## 评估维度

| 维度 | 判断问题 |
|---|---|
| 销售机会 | 是否有明确客户、渠道或销售需求 |
| 产品定位 | 是走量、利润、形象、定制还是储备 |
| 功效卖点 | 卖点是否清楚且可验证 |
| 成本目标 | 是否有目标成本和毛利空间 |
| 开发周期 | 是否满足上市或客户节点 |
| 原料风险 | 是否存在供应、法规或价格风险 |
| 包材风险 | 是否存在 MOQ、交期、库存或兼容性风险 |
| 供应商能力 | 是否有合适工厂或物料供应商 |

## 立项结论

- 立项：需求清楚、毛利可行、风险可控。
- 暂缓：关键数据缺失，需要补充。
- 取消：毛利不足、风险过高或成交价值低。
