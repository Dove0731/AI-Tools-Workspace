# 首次自主生产新品类成本核算与风险门禁 SOP V0.1

> 文件状态：制度候选/待试运行  
> 建立日期：2026-07-28  
> 适用场景：公司未自主稳定生产过，或存在新工艺、新设备/模具、新包材结构、新供应商、重大BOM变化且没有连续稳定良率数据的产品  
> 案例来源：太空舱冻干面膜、保龄球精华实际成本高于预算的用户案例；具体金额和损耗明细待确认  
> 上位衔接：[新品开发全流程SOP V1.0](../新品开发全流程SOP_V1.0.md)、[OEM订单成本核算与毛利复核SOP V1.0](../../10_采购与成本管理/成本核算/OEM订单成本核算与毛利复核SOP_V1.0.md)

## 1. 目的

在报价或量产前，把首次生产的不确定性转化为可验证的试产数据、压力情景成本和明确止损条件，防止理想BOM成本被误当作实际可交付成本。

## 2. 角色责任

| 角色 | 强制责任 |
|---|---|
| 项目经营Owner | 对立项、预算上限、客户价格、是否继续/停止负责；具体人员待确认 |
| 产品开发/研发 | 提供完整BOM、规格、工艺路线、技术难点和试产方案 |
| 生产 | 提供产能、换线/清场、设备模具、人工、投料、产出、停机及工序损耗记录 |
| 品质 | 定义关键质量标准、抽检方案、缺陷分类、放行标准和返工/报废结论 |
| 采购 | 提供原料、包材、外协、MOQ、物流、一次性费用和报价有效期 |
| 财务/成本 | 建立同口径三情景成本、复核公式、核算毛利和现金占用 |
| 批准人 | 批准量产、例外、预算上限及止损处理；具体权限待确认 |

编制、复核和批准不得由同一人独立完成。

## 3. Gate 0：高风险识别

出现任一条件即标记为“首次生产高风险项目”：

- 公司无同类产品连续稳定批次数据；
- 使用新剂型、新工艺、新设备、新模具或新包材结构；
- 关键原料、包材或供应商未通过量产验证；
- 质量标准、设备参数或合理损耗率缺历史依据；
- 工艺失败会产生高额返工、报废、交付或客户风险。

**输出：** 风险识别卡、项目Owner、试产范围。  
**未通过处理：** 未指定Owner或未识别关键风险，不得进入正式成本批准。

## 4. Gate 1：试产前临时预算

临时预算必须逐项列明：

`临时全成本 = BOM材料 + 包材 + 直接人工/加工 + 换线与清场 + 设备/模具调试 + 启动损耗 + 过程损耗 + 检验与留样 + 不良/返工/报废预留 + 物流与特殊储运 + 一次性费用分摊 + 其他已确认费用`

要求：

1. 每项注明来源、版本、含税/未税、数量、MOQ和有效期；
2. 没有实测依据的损耗和不良不得填0，统一标“待试产验证”；
3. 风险预留必须单列，不能藏入材料单价；
4. 只可标记“临时测算”，不得据此承诺正式售价或毛利。

## 5. Gate 2：最小可验证试产

试产规模由研发、生产、品质根据工艺决定，必须足以覆盖关键设备启动、主要工序和质量检验；具体数量待项目评审确认，不由AI统一设定。

试产必须记录：

| 类别 | 必录数据 |
|---|---|
| 投入 | 各原料/包材实际投料、批次和金额 |
| 产出 | 半成品、成品、合格品数量 |
| 损耗 | 启动、换线、残留、过程、取样、包装和运输损耗 |
| 质量 | 缺陷类型、不良数量、返工数量、报废数量及原因 |
| 资源 | 人工工时、设备时长、停机、调试、清场和外协费用 |
| 结果 | 实际良率、实际单位合格品成本、未关闭风险 |

关键公式：

- `合格率 = 合格成品数量 ÷ 投产数量`
- `综合损耗率 =（投入等价值数量 - 合格产出等价值数量）÷ 投入等价值数量`
- `单位合格品成本 = 本批全部可归集成本 ÷ 合格放行数量`

不同单位无法直接比较时，必须先建立等价换算，不得强行相减。

## 6. Gate 3：三情景成本

试产后形成三套模型：

| 情景 | 数据要求 | 用途 |
|---|---|---|
| 基准情景 | 采用已验证且可稳定复制的参数 | 正常报价和经营判断 |
| 压力情景 | 纳入可合理预见的低良率、返工、追加检验和延期费用 | 判断最可能的不利结果是否仍可承受 |
| 止损情景 | 明确成本、质量、交付或现金占用上限 | 触发暂停、改方案、外协或停止 |

具体良率、损耗率、风险金额和止损阈值必须由真实试产、历史类似项目或书面批准确定；无依据不得由模板预设。

## 7. Gate 4：量产评审

量产前必须同时具备：

1. 已冻结BOM、工艺、设备/模具和质量标准；
2. 试产记录及关键异常关闭证据；
3. 基准、压力和止损三情景成本；
4. 客户价格、目标毛利、首批现金投入和库存风险；
5. 量产首件、过程检验、异常升级和止损方案；
6. 编制人、独立复核人和批准人签字。

任一条件缺失，结论只能是“退回验证”“暂停”或“例外待批准”，不得标记“准予量产”。

## 8. Gate 5：首批量产控制

- 首件确认后方可连续生产；
- 关键工序按批准频次记录投入、产出和缺陷；
- 达到已批准的成本、品质、交付或报废止损条件时立即停线/暂停，不得为赶进度继续放大损失；
- 任何返工、补料、改工艺、换供应商或更换包材必须触发成本重算和变更评审；
- 未经品质放行不得出货。

## 9. Gate 6：实际成本与复盘回写

首批结单且主要费用可归集后，应完成：

- 预算单位成本与实际单位合格品成本差异；
- 差异拆分：价格、用量、启动损耗、过程损耗、品质不良、返工、报废、人工设备、检测、物流和延期；
- 预计毛利与实际毛利差异；
- 继续、优化、转外协、暂停或停止结论；
- 实测良率、损耗、工时和缺陷参数回写成本参数库。

建议时限为主要费用齐套后2个工作日内完成初版，是否作为公司正式时限待批准。

## 10. 异常升级

| 异常 | 处理 |
|---|---|
| 没有试产数据却要求报价/量产 | 暂停；提交例外审批并写明投入上限和风险承担 |
| 实际成本超过已批准止损上限 | 立即暂停追加生产，重新评审价格、工艺、规格或外协 |
| 关键品质指标未通过 | 隔离、根因、纠正验证；未关闭不得放行 |
| 生产记录缺失 | 本批参数不得作为标准成本依据，追补证据并评估同批风险 |
| 同类异常重复 | 升级现有新品开发SOP和成本模板，横向排查同类项目 |

## 11. 验收与正式发布门槛

本V0.1只有在至少1个真实高风险新品完成“风险识别—试产—三情景成本—量产评审—首批生产—实际成本复盘”，并由产品、生产、品质、采购、财务共同验收后，才可：

- 合并升级《新品开发全流程SOP》或成本核算SOP；
- 发布正式版本；
- 固化公司损耗、风险预留和审批阈值。

未完成上述验证前，本文件只能作为试运行候选，不能宣称制度已落地。
