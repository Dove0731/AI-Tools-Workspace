# 99_归档

## 目录用途

本目录用于归档已完成项目、旧报告、历史数据、旧版资料和已处理原始资料。

## 存放内容

- 已关闭项目资料。
- 历史报告、月报、半年度、年度总结。
- 历史采购、报价、供应商、订单数据。
- 旧模板、旧流程、旧规则。
- 已处理原始文件备份。

## 更新规则

- 已归档资料不作为当前默认数据源。
- 重新启用归档资料时，必须在当前台账中说明。
- 归档时保留原路径、归档路径和归档原因。

## 使用方式

1. 已关闭事项先确认是否需要复盘。
2. 将资料放入对应归档子目录。
3. 在 `归档索引.md` 记录去向。
4. 后续查询时从归档索引追溯。
