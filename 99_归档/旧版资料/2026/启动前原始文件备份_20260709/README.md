# 化妆品产品开发与采购知识库

## 用途

本知识库用于沉淀化妆品新品开发、原料采购、包材采购、供应商开发、报价比价、成本优化、订单交付、质量异常、项目复盘和老板汇报资料。

核心目标是把日常采购和开发动作转化为可追踪的经营价值，包括毛利提升、损失避免、交付效率、供应商风险、现金流效率和销售支持。

## 目录说明

- `AGENTS.md`：AI 后续处理本知识库时必须遵守的长期规则。
- `docs/`：业务说明文档和工作规则。
- `data_schema/`：后续建表、做 Excel 或数据库时可用的字段说明。
- `templates/`：日常工作可直接复制使用的模板。
- `examples/`：虚拟数据示例，帮助理解模板填写方式。

## 使用方法

1. 新品启动时，复制 `templates/新品立项模板.md` 建立项目档案。
2. 询价时使用 `templates/供应商询价模板.md`，保证供应商按同一口径报价。
3. 收到报价后，用 `templates/供应商比价分析模板.md` 做价格、MOQ、交期、付款和风险对比。
4. 做降本时，用 `templates/成本优化分析模板.md` 同时写清成本收益和经营影响。
5. 发生质量、交期、成本或沟通异常时，用 `templates/采购异常复盘模板.md` 做闭环。
6. 月度或半年度汇报时，用对应汇报模板整理给老板看的结果。

## 更新规则

- 报价、交期、MOQ、付款、认证、合同条款必须记录来源和日期。
- 未确认的信息标注“待确认”。
- 不保存敏感信息。
- 重要事项要写下一步动作：谁负责、做什么、什么时候完成、预期产出是什么。
- 示例只能使用虚拟数据，不编造真实公司数据。
