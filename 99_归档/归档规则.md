# 归档规则

## 需要归档的内容

- 已完成、暂停或取消的项目。
- 旧版本报告、旧模板、旧台账、旧流程。
- 已关闭的报价、订单、异常复盘和供应商评估。
- 已处理完的原始资料备份。

## 归档结构

| 子目录 | 内容 |
|---|---|
| `历史报告` | 周报、月报、年中、年度、老板汇报历史版 |
| `历史数据` | 历史采购订单、报价、供应商和项目数据 |
| `旧版资料` | 重构前文件、旧模板、旧规则 |
| `已关闭项目` | 已完成、暂停或取消的项目资料 |
| `原始资料归档` | 已处理的原始文件备份 |

## 归档原则

1. 不删除有追溯价值的资料。
2. 同一文件多个版本时，保留最终版和关键变更版。
3. 已归档内容不再作为当前台账默认数据源，除非重新激活。
4. 无法确认日期时，不强行编日期，标注“未标日期”。
5. 归档文件应尽量保留来源路径和处理说明。
