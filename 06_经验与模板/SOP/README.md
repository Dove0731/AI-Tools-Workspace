# 正式 SOP 目录

本目录存放已经具备责任人、输入、步骤、时间节点、验收标准、异常升级和复盘机制，可直接试运行的 SOP。

- `SOP草稿`：尚未完成责任闭环或仍在讨论的流程。
- `SOP`：可以直接执行并通过台账验证的流程。
- SOP 试运行后如需修改，必须更新版本号和修订记录，不覆盖历史结论。
