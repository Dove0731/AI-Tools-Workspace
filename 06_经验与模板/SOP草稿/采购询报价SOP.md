# 采购询报价 SOP

## 询价前

| 检查项 | 要求 |
|---|---|
| 需求 | 物料名称、规格、数量、用途、目标交期清楚 |
| 口径 | 含税/未税、币种、单位、包装方式一致 |
| 风险 | 是否专用、是否急单、是否影响上市或订单交付 |

## 询价内容

供应商报价必须至少包含：单价、税率、MOQ、阶梯价、打样费/模具费、样品周期、量产交期、付款方式、报价有效期、质量/资料承诺。

## 比价判断

| 维度 | 判断方式 |
|---|---|
| 价格 | 同口径比较到手成本，不只比单价 |
| 交期 | 是否满足项目关键节点 |
| MOQ | 是否造成库存和现金流占用 |
| 账期 | 是否有现金流改善空间 |
| 风险 | 是否单一供应商、质量不稳定、资料不完整 |
