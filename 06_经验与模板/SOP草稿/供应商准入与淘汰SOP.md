# 供应商准入与淘汰 SOP

## 准入流程

| 步骤 | 判断内容 | 输出 |
|---|---|---|
| 基础筛选 | 产品范围、资质、产能、配合度 | 初筛结论 |
| 报价评估 | 单价、MOQ、交期、账期、有效期 | 报价比价表 |
| 样品/小单验证 | 质量、交付、包装、资料 | 验证记录 |
| 分级建议 | A/B/C/D 或待评估 | 供应商分级台账 |

## 淘汰触发条件

| 触发条件 | 建议动作 |
|---|---|
| 重大质量事故且拒不整改 | D类，暂停合作 |
| 多次延期影响项目或订单 | 降级并开发替代 |
| 报价长期无竞争力且无改善 | 转为 C 类或暂停询价 |
| 资质资料长期不完整 | 不进入正式供应链 |
| 配合度低导致项目延期 | 降级并限制新项目 |
