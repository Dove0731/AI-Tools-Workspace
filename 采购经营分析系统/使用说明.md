# 采购价格与降本月度分析系统使用说明

适用范围：化妆品原料、包材、成品及其他采购品类  
运行环境：Windows 10/11，Python 3.10 或更高版本  
第一阶段数据源：Excel

## 一、这套系统能做什么

系统会按月读取采购订单，统一字段、日期、税率、金额和计量单位，并完成：

- 对比上次采购价和近 12 个月历史价格；
- 分别计算环比节约、历史基准节约、议价节约；
- 识别涨价、供应商价差、报价超支、连续涨价、供应商集中等异常；
- 生成 4 份 Excel 和 1 份 PDF（环境支持时）；
- 自动按年份、月份和版本归档；
- 记录本次使用的源文件、记录数、异常数、错误和汇总勾稽结果。

系统不修改、覆盖或删除任何原始数据。

## 二、第一次使用前

1. 安装 Python 3.10 或更高版本。
2. 安装时勾选 **Add Python to PATH**。
3. 保持电脑可以访问网络，以便第一次运行时自动安装依赖。
4. 本项目已附带少量、明确标记为“演示数据”的测试文件。

如果某一输入目录内放入了正式 Excel，系统会自动忽略该目录中的“演示数据”文件，避免正式数据与演示数据混用。导入模板不会被当成业务数据读取。

## 三、每类数据放在哪里

### 必需

- 本月采购订单：`01_原始数据/本期采购订单/`
- 历史采购订单：`01_原始数据/历史采购订单/`

### 建议提供

- 供应商报价：`01_原始数据/供应商报价/`
- 入库记录：`01_原始数据/入库记录/`
- 物料主数据：`01_原始数据/物料主数据/`

每个目录内都有“导入模板”。可以直接复制模板，填写后另存为新文件。不要在模板文件本身录入正式数据。

也可以使用 `01_原始数据/采购经营分析系统_数据录入模板.xlsx`。该文件把本期订单、历史订单、报价、入库和物料主数据整合在一个工作簿中；实际运行前，请将对应工作表另存或复制到上述分类目录。

## 四、最简单的运行方法

1. 把 Excel 放入对应目录。
2. 双击项目根目录中的 `一键生成月报.bat`。
3. 输入月份，例如 `2026-06`。
4. 如果直接回车，默认分析上一个自然月。
5. 等待系统完成。成功后会自动打开 `03_输出报告`。

同一月份重复运行不会覆盖旧报告，而是自动生成 `V001、V002、V003……`。

## 五、会生成哪些文件

输出位置：`03_输出报告/YYYY-MM/`

- `采购月度分析报告_YYYY-MM_Vxxx.xlsx`
- `采购价格异常清单_YYYY-MM_Vxxx.xlsx`
- `采购节约金额明细_YYYY-MM_Vxxx.xlsx`
- `数据质量与待确认清单_YYYY-MM_Vxxx.xlsx`
- `采购月度管理报告_YYYY-MM_Vxxx.pdf`（PDF 生成开启且环境支持时）

归档位置：`04_历史归档/年份/月份/运行时间_Vxxx/`

运行日志位置：`05_运行日志/`

## 六、节约金额怎么计算

### 1. 环比节约金额

`（上次采购价－本次采购价）×本次标准数量`

### 2. 历史基准节约金额

`（近12个月加权平均价－本次采购价）×本次标准数量`

近 12 个月加权平均价：

`历史采购总金额÷历史采购总数量`

### 3. 议价节约金额

`（供应商初始报价－最终成交价）×本次采购数量`

三类节约分别展示，不能相加。正式汇总默认使用“近 12 个月加权平均价节约金额”，并且只有“人工确认状态”改为“已确认”后，才计入经确认节约金额。

涨价影响金额单独计算：

`MAX（本次采购价－近12个月加权平均价，0）×本次标准数量`

## 七、配置文件怎么改

配置位置：`02_配置文件/`

### 字段映射表.xlsx

当原文件列名不同，例如“订单ID、下单日期、采购成本”，在对应工作表的“候选字段名”中追加，使用英文分号 `;` 分隔。

如果同一个标准字段同时命中多个原始列，系统不会擅自选择，会写入“待人工确认”。

### 物料单位换算表.xlsx

异单位比较必须有换算规则：

- 标准数量＝原数量×换算系数
- 标准单价＝原单价÷换算系数

同单位自动按 1:1 处理。箱转个、桶转千克等与包装规格有关的换算，建议按物料编码单独配置。没有唯一换算规则时，该记录不得直接计算节约或涨价影响。

### 分析规则配置.xlsx

可以调整：

- 上次采购价上涨阈值；
- 12 个月均价上涨阈值；
- 同期供应商价差阈值；
- 供应商集中度阈值；
- 数量增长阈值；
- 历史回溯月数；
- 风险金额分级；
- 统一含税或未税价格口径；
- 是否生成 PDF。

修改配置后重新运行即可，不需要改程序。

## 八、哪些内容必须人工确认

以下情况系统只提示，不会擅自匹配或认定：

- 没有物料编码；
- 规格、单位或税率缺失；
- 单位变化但没有换算规则；
- 同一个字段命中多个原始列；
- 首次采购或没有有效历史价格；
- 报价单位与订单单位是否一致；
- 规格变化后是否仍属于同一可比物料；
- 节约金额是否可以作为正式经营成果。

正式报告前，建议由采购负责人确认价格与业务原因，财务确认税价和金额口径，业务负责人确认节约是否可计入。

## 九、常见报错和解决办法

### “未找到 Python”

安装 Python 3.10 以上版本，并勾选 Add Python to PATH。安装后重新打开批处理。

### “依赖安装失败”

检查网络和公司代理；也可以在项目目录打开命令提示符，运行：

`python -m pip install -r requirements.txt`

### “没有可识别的数据”

确认文件为 `.xlsx`，放在正确目录；检查第一行是否为表头；至少提供订单号、日期、物料、数量、价格和供应商等字段。

### “分析月份没有有效记录”

检查输入月份和“订单日期”。系统按订单日期筛选，不按文件名判断月份。

### “必需字段缺失”或“字段映射冲突”

打开《数据质量与待确认清单》，按提示修改原文件表头或《字段映射表.xlsx》。不要在无法确认时强行匹配。

### “缺少单位换算”

在《物料单位换算表.xlsx》补充规则。涉及箱、桶、套等包装单位时，优先按物料编码配置专属换算。

### “文件被占用”或“Permission denied”

关闭正在打开的输入或输出 Excel 后重试。系统不会覆盖旧版本，但 Windows 可能阻止读取被独占锁定的文件。

### PDF 未生成

先查看运行日志中的“PDF状态”。Excel 报告仍会正常生成。可在《分析规则配置.xlsx》中把 `generate_pdf` 暂时改为“否”。

## 十、测试和当前限制

演示数据已验证：

- 同物料多次历史价格匹配；
- 含税价与未税价转换；
- 千克与克的单位换算；
- 首次采购；
- 环比节约、12 个月加权均价和涨价影响；
- 连续三次涨价、供应商价差和批准报价超支；
- 重复运行版本保护；
- Excel 复核公式、条件格式和图表；
- 明细、品类、供应商采购金额一致。

当前限制：

- 第一阶段不直接连接 ERP；
- 供应商报价模板暂未设置报价计量单位，默认报价与订单原单位一致，不一致时必须人工确认；
- 跨物料平均单价只用于辅助观察，不能作为正式价格趋势结论；
- 入库记录当前用于数据留存和后续扩展，尚未作为价格基准或交付 KPI；
- 名称标准化依赖配置表，不做未经确认的模糊自动改名；
- Excel 公式由 Excel 打开时自动重算。

## 十一、后续接 ERP 或数据库

接入预留文件：`src/connectors.py`

需要做的工作：

1. 新增 ERP API 或数据库只读连接；
2. 把接口字段转换为本系统标准字段；
3. 在《分析规则配置.xlsx》中把 `source_mode` 改为 `ERP` 或 `Database`；
4. 在 `src/main.py` 的数据加载入口调用连接器；
5. 保留接口请求时间、分页、失败重试和源数据审计日志。

只要连接器输出仍使用标准字段，后续价格基准、节约、异常、报告和归档模块无需重写。
