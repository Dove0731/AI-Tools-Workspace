# 交期异常字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 异常编号 | 交期异常编号 | 示例：DL-202607-001 | 是 | 串联订单和复盘 |
| 发生日期 | 发现延期日期 | 示例：2026-07-09 | 是 | 判断响应时效 |
| 订单/项目 | 关联订单或项目 | 示例：PO-202607-001 | 是 | 判断影响对象 |
| 物料 | 延期物料 | 示例：精华瓶 | 是 | 判断缺料影响 |
| 供应商/工厂 | 延期责任方 | 示例：供应商A | 是 | 评估供应商表现 |
| 原计划日期 | 原承诺交期 | 示例：2026-08-01 | 是 | 计算延期 |
| 最新预计日期 | 调整后交期 | 示例：2026-08-05 | 是 | 判断补救空间 |
| 延期天数 | 日期差异 | 示例：4天 | 否 | 量化影响 |
| 延期原因 | 供应商/物流/排产/资料等 | 示例：排产延误 | 是 | 判断责任 |
| 经营影响 | 是否影响上市、交付、收入 | 示例：可能影响上市 | 是 | 输出风险等级 |
| 补救方案 | 加急、分批、替代等 | 示例：分批发货 | 是 | 输出行动建议 |
| 来源 | 沟通记录或订单 | 示例：供应商微信 | 是 | 追溯依据 |
