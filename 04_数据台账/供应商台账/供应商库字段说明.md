# 供应商库字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 供应商名称 | 是 | 标准简称和全称分开维护更好 |
| 类型 | 是 | 原料/包材/OEM/ODM/检测/物流等 |
| 当前等级 | 是 | A/B/C/D/待评估 |
| 价格竞争力 | 是 | 高/中/低或评分 |
| 质量稳定性 | 是 | 结合异常记录 |
| 交付能力 | 是 | 准时率或主观等级 |
| 配合度 | 是 | 响应速度、资料配合、打样配合 |
| 账期支持 | 否 | 预付/月结/到货付款等 |
| 资质完整性 | 是 | 证照、体系、检测、合规资料 |
| 历史异常 | 否 | 链接到复盘记录 |
| 建议动作 | 是 | 维持/开发/替代/暂停/淘汰 |

数据要求：缺失字段不要删除，标注“待确认”；示例内容必须写明“示例”。
