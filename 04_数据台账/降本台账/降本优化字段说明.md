# 降本优化字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 优化编号 | 是 | CO-YYYY-序号 |
| 优化对象 | 是 | 产品、原料、包材、供应商、工艺或账期 |
| 原方案单价 | 是 | 标注口径 |
| 新方案单价 | 是 | 标注口径 |
| 数量 | 是 | 实际量、预测量或示例量需说明 |
| 优化金额 | 是 | 原方案单价 × 数量 - 新方案单价 × 数量 |
| 毛利影响 | 是 | 可量化优先量化 |
| 交期影响 | 是 | 是否缩短、延长或无影响 |
| 供应风险 | 是 | 单一供应商、质量、MOQ、稳定性 |
| 可复制性 | 是 | 可复制到哪些产品或物料 |
| 核算状态 | 是 | 已确认/待确认/临时参考 |

数据要求：缺失字段不要删除，标注“待确认”；示例内容必须写明“示例”。
