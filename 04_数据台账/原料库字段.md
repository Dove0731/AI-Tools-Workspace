# 原料库字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 原料编号 | 原料唯一编号 | 示例：RM-2026-001 | 是 | 串联报价、供应商、替代分析 |
| 原料名称 | 中文标准名称 | 示例：透明质酸钠 | 是 | 识别物料 |
| INCI/别名 | 国际名称或常见别名 | 示例：Sodium Hyaluronate | 否 | 避免同物异名 |
| 开发目的 | 降本、功效、替代、备选 | 示例：降本替代 | 是 | 判断开发价值 |
| 适用产品 | 关联产品或项目 | 示例：补水精华 | 否 | 判断应用范围 |
| 供应商 | 原料来源供应商 | 示例：供应商A | 是 | 做供应商比价和风险判断 |
| 单价 | 报价价格 | 示例：待确认 | 否 | 计算成本和降本空间 |
| MOQ | 最小起订量 | 示例：25kg | 否 | 判断库存和现金流影响 |
| 交期 | 样品或量产交期 | 示例：7天 | 否 | 判断项目节点风险 |
| 资料状态 | COA/MSDS/检测等资料 | 示例：MSDS 待补 | 是 | 判断合规和准入风险 |
| 风险 | 价格、质量、法规、供应风险 | 示例：单一来源 | 是 | 输出风险和替代建议 |
| 来源 | 报价单、资料或沟通记录 | 示例：报价单路径 | 是 | 追溯数据来源 |
