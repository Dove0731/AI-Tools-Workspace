# 报价记录字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 报价编号 | 报价唯一编号 | 示例：QUO-202607-001 | 是 | 串联比价和成本测算 |
| 报价日期 | 供应商报价时间 | 示例：2026-07-09 | 是 | 判断报价有效性 |
| 物料/项目 | 报价对象 | 示例：30ml 精华瓶 | 是 | 判断比价对象 |
| 供应商 | 报价来源 | 示例：供应商A | 是 | 比较供应商 |
| 单价 | 报价价格 | 示例：1.20 | 是 | 计算成本和降本 |
| 含税/未税 | 税务口径 | 示例：含税13% | 是 | 统一比价口径 |
| 币种/单位 | 价格单位 | 示例：元/套 | 是 | 避免口径混乱 |
| MOQ | 最小起订量 | 示例：10000套 | 是 | 判断库存和现金流 |
| 阶梯价 | 不同数量价格 | 示例：2万套 1.10元 | 否 | 判断谈判空间 |
| 交期 | 样品或大货周期 | 示例：25天 | 是 | 判断项目影响 |
| 付款方式 | 账期或付款节点 | 示例：30%定金 | 是 | 判断现金流 |
| 有效期 | 报价有效时间 | 示例：30天 | 否 | 判断是否需重询 |
| 来源 | 报价单或沟通记录 | 示例：报价单路径 | 是 | 追溯依据 |
