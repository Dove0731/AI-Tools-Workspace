# 产品项目库字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 项目编号 | 产品项目唯一编号 | 示例：PD-2026-001 | 是 | 串联项目、报价、订单、复盘 |
| 产品名称 | 新品或项目名称 | 示例：补水精华 | 是 | 识别分析对象 |
| 产品定位 | 走量款、利润款、形象款、定制款等 | 示例：利润款 | 是 | 判断成本目标和优先级 |
| 目标客群 | 面向消费者或客户类型 | 示例：干皮用户 | 否 | 判断卖点是否匹配 |
| 功效卖点 | 产品主推功效 | 示例：补水保湿 | 否 | 判断测试和原料方向 |
| 配方方向 | 配方开发思路 | 示例：清爽精华质地 | 否 | 判断原料和测试需求 |
| 包材方向 | 包装规格和形式 | 示例：30ml 滴管瓶 | 否 | 判断包材匹配、MOQ 和交期 |
| 成本目标 | 目标成本或目标价 | 示例：待确认 | 否 | 判断毛利和报价风险 |
| 目标上市时间 | 计划上市节点 | 示例：2026-09 | 否 | 判断交期和项目优先级 |
| 当前阶段 | 项目阶段 | 示例：打样 | 是 | 判断进度是否正常 |
| 风险 | 成本、交期、质量、供应商等 | 示例：包材 MOQ 偏高 | 是 | 输出风险提示和动作 |
| 来源 | 数据来源 | 示例：销售需求会 | 是 | 判断可信度和追溯 |
