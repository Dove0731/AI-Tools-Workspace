# 产品项目字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 项目编号 | 是 | PD/RM/PM/OEM/CO 编号 |
| 产品名称 | 是 | 新品或项目名称 |
| 产品定位 | 是 | 走量款/利润款/形象款/客户定制/渠道专供/储备款 |
| 目标客群 | 否 | 客户或用户画像 |
| 功效卖点 | 否 | 需与法规和测试支持匹配 |
| 成本目标 | 否 | 标注含税/未税和数量口径 |
| 当前阶段 | 是 | 按状态词典填写 |
| 风险 | 是 | 成本/交期/质量/供应商/现金流等 |
| 来源 | 是 | 需求表、会议、聊天或邮件路径 |

数据要求：缺失字段不要删除，标注“待确认”；示例内容必须写明“示例”。
