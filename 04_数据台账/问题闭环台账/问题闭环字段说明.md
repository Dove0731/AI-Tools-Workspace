# 问题闭环字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 问题编号 | 是 | RP-YYYYMM-序号 |
| 问题类型 | 是 | 质量/交期/成本/供应商/项目/现金流 |
| 发生日期 | 是 | 无法确认写“日期待确认” |
| 影响对象 | 是 | 产品、项目、订单、物料或供应商 |
| 影响 | 是 | 毛利、交期、质量、成交、库存、现金流 |
| 原因 | 是 | 未查明写“待确认” |
| 责任方 | 是 | 内部/供应商/工厂/客户/待确认 |
| 动作 | 是 | 谁做、做什么、何时完成 |
| 状态 | 是 | 待确认/进行中/已关闭 |
| 关闭证据 | 否 | 复测、到货、赔付、补料、老板确认等 |
