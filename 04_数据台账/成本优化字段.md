# 成本优化字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 优化编号 | 成本优化事项编号 | 示例：CO-2026-001 | 是 | 串联降本项目 |
| 优化对象 | 产品、原料、包材、供应商等 | 示例：精华瓶 | 是 | 判断优化范围 |
| 原方案 | 优化前方案 | 示例：供应商A | 是 | 作为计算基准 |
| 新方案 | 优化后方案 | 示例：供应商B | 是 | 作为对比方案 |
| 数量 | 核算数量 | 示例：10000 | 是 | 计算优化金额 |
| 原方案单价 | 原单价 | 示例：1.30 | 是 | 计算优化金额 |
| 新方案单价 | 新单价 | 示例：1.10 | 是 | 计算优化金额 |
| 优化金额 | 原方案单价×数量-新方案单价×数量 | 示例：2000 | 是 | 判断降本贡献 |
| 税费/物流/损耗 | 额外成本 | 示例：物流另计 | 否 | 判断真实收益 |
| MOQ影响 | 是否增加库存 | 示例：MOQ增加5000 | 否 | 判断现金流风险 |
| 账期影响 | 付款方式变化 | 示例：月结变预付 | 否 | 判断现金流 |
| 质量/交期风险 | 新方案风险 | 示例：需小单验证 | 是 | 判断是否执行 |
| 来源 | 报价和测算依据 | 示例：比价表 | 是 | 追溯计算 |
