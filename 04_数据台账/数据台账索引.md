# 数据台账索引

本目录统一字段口径，正式业务数据可放 Markdown、Excel 或后续数据库。所有数据必须可追溯来源。

## 一、总控台账

| 台账 | 位置 | 用途 |
|---|---|---|
| 总台账 | `总台账.md` | 汇总所有重要事项、风险、下一步动作 |
| 台账维护规则 | `台账维护规则.md` | 规定什么时候入账、怎么维护、禁止事项 |
| GitHub 协作与权限台账 | `GitHub协作与权限台账.md` | 管理私有仓库、成员权限、运行记录和验收状态 |

## 三、维护优先级

| 优先级 | 必须维护的内容 |
|---|---|
| P0 | 影响上市、交付、客户成交、重大质量或大额成本的事项 |
| P1 | 影响毛利、供应稳定、现金流或关键项目节点的事项 |
| P2 | 日常采购、开发、沟通中需要追踪但风险可控的事项 |
| 待确认 | 数据不完整，必须补来源、日期、口径或责任人 |


## 数据标准入口

- `数据标准/README.md`：正式业务字段标准说明。
- `数据标准/采购订单字段标准.md`：采购订单AI分析字段及口径。
- `数据标准/供应商数据字段标准.md`：供应商评价字段及口径。
- `数据标准/成本优化字段标准.md`：成本优化测算字段及口径。

根目录 `data_schema` 为历史字段参考入口；后续正式业务优先使用本目录的数据标准。
