# 原料库字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 原料编码 | 否 | 有 ERP 编码则填写 |
| 原料中文名 | 是 | 标准名称 |
| INCI/别名 | 否 | 避免同物异名 |
| 供应商 | 是 | 报价或样品来源 |
| 单价 | 否 | 含税/未税需标注 |
| MOQ | 否 | 同时判断库存和现金流 |
| 交期 | 否 | 样品和量产交期分开 |
| 资质资料 | 否 | COA/MSDS/备案/检测等 |
| 风险 | 是 | 价格、质量、供货、法规、替代风险 |
| 来源日期 | 是 | 报价或资料日期 |

数据要求：缺失字段不要删除，标注“待确认”；示例内容必须写明“示例”。
