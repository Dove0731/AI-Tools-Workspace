# 供应商数据字段标准

| 字段 | 必填 | 口径说明 |
|---|---|---|
| 供应商名称 | 是 | 工商主体全称或唯一内部名称 |
| 供应类别 | 是 | 原料、包材、OEM/ODM、检测、物流等 |
| 等级 | 是 | A战略、B常规、C备选、D暂停或淘汰 |
| 合作状态 | 是 | 待准入、试单、合作中、暂停、淘汰 |
| 报价记录 | 是 | 日期、物料、规格、数量、税费、运费、MOQ、有效期 |
| 交付表现 | 是 | 承诺交期、实际交期、准交及延期记录 |
| 质量表现 | 是 | 验收、异常、影响、整改及复发情况 |
| 风险记录 | 是 | 资质、单一供应、产能、财务、合规、质量及交付风险 |

供应商评价不能只依据价格，至少同时考虑价格竞争力、质量稳定性、交付能力、配合度、开发能力、账期支持、文件资质、历史异常、可替代性和长期价值。AI评级建议须标注“待确认”。
