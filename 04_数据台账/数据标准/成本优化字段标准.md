# 成本优化字段标准

| 字段 | 必填 | 口径说明 |
|---|---|---|
| 优化项目 | 是 | 关联产品、SKU、物料、供应商或工艺 |
| 原成本 | 是 | 原方案单位成本及构成 |
| 优化后成本 | 是 | 新方案单位成本及构成 |
| 节约金额 | 是 | 原方案单价×数量－新方案单价×数量 |
| 年度影响 | 否 | 按已确认年度数量测算 |
| 毛利影响 | 否 | 单位毛利、毛利率及年度毛利额影响 |
| 实施状态 | 是 | 待评估、验证中、待决策、实施中、已完成、暂停 |

## 补充口径

- 单独记录税费、物流、损耗、MOQ、一次性费用和账期变化。
- 年度影响注明数量依据和周期；未确认数量标注“待确认”。
- 同时评估质量、交期、法规、供应、库存和现金流。
- 节约金额不等于净收益；净收益需扣除一次性投入、切换成本和新增风险成本。
