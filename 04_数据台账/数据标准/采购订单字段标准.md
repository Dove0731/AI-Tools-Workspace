# 采购订单字段标准

| 字段 | 必填 | 口径说明 |
|---|---|---|
| 供应商 | 是 | 正式名称或唯一内部名称 |
| 物料编码 | 是 | 与物料主数据一致 |
| 物料名称 | 是 | 采购物料或服务名称 |
| 类别 | 是 | 原料、包材、OEM/ODM成品、服务等 |
| 采购日期 | 是 | 订单确认日期，YYYY-MM-DD |
| 采购数量 | 是 | 同时记录计量单位 |
| 采购单价 | 是 | 注明币种、税费和运费口径 |
| 历史价格 | 否 | 同物料、规格、税费和物流口径的可比价格 |
| 价格变化 | 否 | 金额变化及变化率 |
| 优化金额 | 否 | 原方案单价×数量－新方案单价×数量 |
| 交期 | 是 | 承诺日期或交付周期 |
| 付款周期 | 是 | 预付比例、节点或账期天数 |
| 备注 | 否 | MOQ、质量、交付、异常及来源说明 |

## AI分析要求

必须分析采购金额、价格变化、供应商差异、MOQ、交期、付款、质量和替代供应风险。优化金额应单独说明税费、物流、损耗、MOQ和账期影响。不可比价格不得直接认定为涨价或降价。
