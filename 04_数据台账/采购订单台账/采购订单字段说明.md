# 采购订单字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 订单号 | 是 | 系统或手工订单编号 |
| 下单日期 | 是 | 采购日期 |
| 物料编码/名称 | 是 | 原料或包材 |
| 供应商 | 是 | 订单供应商 |
| 数量 | 是 | 采购数量和单位 |
| 单价 | 是 | 含税/未税口径 |
| 金额 | 是 | 数量 × 单价，必要时含税费物流 |
| 需求项目 | 否 | 关联新品、订单或库存需求 |
| 预计到货 | 否 | 交期判断依据 |
| 实际到货 | 否 | 延期分析依据 |
| 异常 | 否 | 质量、少货、延期、价格差异 |
| 来源 | 是 | 订单文件或系统导出路径 |

数据要求：缺失字段不要删除，标注“待确认”；示例内容必须写明“示例”。
