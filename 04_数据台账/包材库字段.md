# 包材库字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 包材编号 | 包材唯一编号 | 示例：PM-2026-001 | 是 | 串联报价、打样、订单 |
| 包材名称 | 包材品类 | 示例：精华瓶 | 是 | 判断包材类型 |
| 规格 | 容量、尺寸、结构 | 示例：30ml | 是 | 判断匹配度和报价口径 |
| 材质/工艺 | 材料和表面工艺 | 示例：玻璃瓶+电镀盖 | 否 | 判断成本和交期 |
| 适用产品 | 对应产品 | 示例：补水精华 | 否 | 判断共用或专用风险 |
| 供应商 | 包材供应商 | 示例：供应商B | 是 | 做比价和交付判断 |
| 单价 | 报价单价 | 示例：待确认 | 否 | 计算成本 |
| MOQ | 起订量 | 示例：10000套 | 否 | 判断库存和资金占用 |
| 打样周期 | 样品周期 | 示例：10天 | 否 | 判断开发进度 |
| 量产交期 | 大货交期 | 示例：30天 | 否 | 判断上市风险 |
| 兼容性风险 | 与料体、灌装、运输匹配风险 | 示例：需做兼容性测试 | 否 | 判断质量风险 |
| 来源 | 报价、样品或沟通记录 | 示例：微信截图路径 | 是 | 追溯依据 |
