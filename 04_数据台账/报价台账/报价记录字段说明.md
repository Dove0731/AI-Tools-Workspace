# 报价记录字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 报价编号 | 否 | 可按日期+物料+供应商生成 |
| 物料/项目 | 是 | 原料、包材或 OEM 项目 |
| 供应商 | 是 | 报价来源 |
| 单价 | 是 | 标注含税/未税、币种、单位 |
| MOQ | 是 | 起订量 |
| 阶梯价 | 否 | 不同数量对应价格 |
| 交期 | 是 | 样品/量产分开 |
| 付款方式 | 是 | 预付、月结、到货付款等 |
| 报价有效期 | 否 | 过期需重新确认 |
| 来源 | 是 | 报价单、聊天、邮件路径 |
| 备注 | 否 | 税费、物流、损耗、模具费等 |

数据要求：缺失字段不要删除，标注“待确认”；示例内容必须写明“示例”。
