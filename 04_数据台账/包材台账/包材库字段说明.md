# 包材库字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 包材编码 | 否 | 有 ERP 编码则填写 |
| 包材名称 | 是 | 如瓶、盖、泵、盒、标签等 |
| 规格/材质/工艺 | 是 | 容量、材质、表面工艺、颜色等 |
| 适用产品 | 否 | 对应产品或系列 |
| 供应商 | 是 | 报价或打样来源 |
| 单价 | 否 | 含税/未税需标注 |
| MOQ | 否 | 判断是否造成库存积压 |
| 打样状态 | 是 | 未启动/已出样/待反馈/已确认 |
| 交期 | 否 | 打样和量产分开 |
| 兼容性风险 | 否 | 与料体、灌装、运输相关风险 |
| 来源日期 | 是 | 报价或沟通日期 |

数据要求：缺失字段不要删除，标注“待确认”；示例内容必须写明“示例”。
