# 质量异常字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 异常编号 | 质量异常编号 | 示例：QA-202607-001 | 是 | 串联复盘和供应商记录 |
| 发生日期 | 异常发现日期 | 示例：2026-07-09 | 是 | 判断响应时效 |
| 产品/物料 | 异常对象 | 示例：精华瓶 | 是 | 判断影响范围 |
| 供应商/工厂 | 责任相关方 | 示例：供应商A | 否 | 判断责任和分级 |
| 异常描述 | 具体质量问题 | 示例：瓶身划痕 | 是 | 识别问题类型 |
| 涉及数量/批次 | 异常规模 | 示例：待确认 | 否 | 判断损失 |
| 影响范围 | 样品、来料、生产、客户 | 示例：来料检验 | 是 | 判断经营影响 |
| 临时措施 | 当前处理 | 示例：暂停使用 | 是 | 判断是否控风险 |
| 根因 | 发生原因 | 示例：待确认 | 是 | 生成复盘建议 |
| 长期预防 | 防复发措施 | 示例：增加出货检验 | 否 | 判断是否形成 SOP |
| 关闭证据 | 复检、补货、赔付等 | 示例：复检通过 | 否 | 判断是否关闭 |
| 来源 | 检验记录或反馈 | 示例：质检报告 | 是 | 追溯依据 |
