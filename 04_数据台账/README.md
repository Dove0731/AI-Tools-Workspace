# 04_数据台账

## 目录用途

本目录用于统一产品、原料、包材、供应商、报价、订单、成本优化、质量异常和交期异常的数据字段，保证后续分析有统一口径。

## 存放内容

- 总台账、台账维护规则、数据质量检查清单。
- 各类数据字段说明。
- 产品、原料、包材、供应商、报价、订单、降本和问题闭环台账。

## 更新规则

- 新增字段必须说明字段含义、示例、是否必填和 AI 如何使用。
- 涉及价格、数量、税率、MOQ、交期、账期的数据必须保留来源。
- 未确认字段保留，不删除，标注“待确认”。

## 使用方式

1. 新数据先判断属于哪类台账。
2. 按字段文件检查数据完整性。
3. 重要事项同步登记到 `总台账.md`。
4. 缺失字段进入“待确认”，不能编造。
