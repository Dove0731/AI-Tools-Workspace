# 采购订单字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 订单号 | 采购订单编号 | 示例：PO-202607-001 | 是 | 串联订单和到货 |
| 下单日期 | 订单生成日期 | 示例：2026-07-09 | 是 | 分析采购周期 |
| 物料名称 | 采购物料 | 示例：精华瓶 | 是 | 判断采购对象 |
| 供应商 | 订单供应商 | 示例：供应商A | 是 | 分析供应商表现 |
| 数量 | 采购数量 | 示例：10000 | 是 | 计算金额和 MOQ |
| 单价 | 采购单价 | 示例：1.20 | 是 | 分析价格变化 |
| 金额 | 订单金额 | 示例：12000 | 是 | 分析采购规模 |
| 需求项目 | 对应项目或订单 | 示例：PD-2026-001 | 否 | 判断业务用途 |
| 预计到货 | 计划到货时间 | 示例：2026-08-01 | 否 | 判断交期风险 |
| 实际到货 | 实际到货时间 | 示例：待确认 | 否 | 分析延期 |
| 到货状态 | 未到/部分/完成/异常 | 示例：部分到货 | 是 | 判断订单执行 |
| 异常 | 质量、数量、延期等 | 示例：延期3天 | 否 | 进入问题闭环 |
| 来源 | 采购单或系统导出 | 示例：ERP导出 | 是 | 追溯数据 |
