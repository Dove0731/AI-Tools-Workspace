# 台账维护规则

## 一、什么时候必须进台账

| 情形 | 必须进入的台账 |
|---|---|
| 新品、原料、包材、OEM/ODM、降本项目启动 | `04_数据台账/总台账.md` 和对应专项台账 |
| 收到供应商报价 | `04_数据台账/报价台账/报价总台账.md` |
| 供应商进入准入、评分、降级、淘汰 | `04_数据台账/供应商台账/供应商总台账.md` |
| 发生采购订单、到货、延期、金额差异 | `04_数据台账/采购订单台账/采购订单总台账.md` |
| 出现质量、交期、成本、供应商异常 | `04_数据台账/问题闭环台账/问题闭环总台账.md` |
| 产生降本、替代、框架价、阶梯价机会 | `04_数据台账/降本台账/降本优化总台账.md` |

## 二、每条台账必须有的内容

| 字段 | 要求 |
|---|---|
| 编号 | 使用统一编号，便于跨文件追踪 |
| 状态 | 未开始、进行中、待反馈、有风险、待确认、已关闭 |
| 来源 | 文件路径、报价单、会议纪要、聊天记录、系统导出路径 |
| 经营影响 | 至少说明成本、毛利、交期、质量、供应商、库存或现金流中的一个 |
| 下一步动作 | 写清谁做、做什么、什么时候完成、产出什么 |

## 三、禁止事项

- 不把未确认数据写成确定结论。
- 不只记录价格，不记录 MOQ、交期、付款方式和风险。
- 不只写“跟进中”，必须写清下一步动作。
- 不把 AI 输出直接当正式数据，必须先进入 `98_AI输出暂存区` 核对。
