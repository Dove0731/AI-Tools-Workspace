# 供应商库字段

| 字段名称 | 字段含义 | 示例 | 是否必填 | AI 分析时如何使用该字段 |
|---|---|---|---|---|
| 供应商编号 | 供应商唯一编号 | 示例：SUP-2026-001 | 是 | 串联报价、订单、异常 |
| 供应商名称 | 标准名称 | 示例：供应商A | 是 | 识别合作对象 |
| 类型 | 原料、包材、OEM/ODM等 | 示例：包材 | 是 | 判断评估维度 |
| 主供物料 | 主要供应内容 | 示例：精华瓶 | 否 | 判断供应角色 |
| 当前等级 | A/B/C/D/待评估 | 示例：B类 | 是 | 判断管理策略 |
| 价格竞争力 | 高/中/低或评分 | 示例：中 | 是 | 判断比价优势 |
| 质量稳定性 | 质量表现 | 示例：待确认 | 是 | 判断合作风险 |
| 交付能力 | 准时交付能力 | 示例：交期稳定 | 是 | 判断交期风险 |
| 配合度 | 响应和协同表现 | 示例：反馈慢 | 是 | 判断项目推进风险 |
| 开发能力 | 新品打样和方案能力 | 示例：可配合开发 | 否 | 判断长期价值 |
| 账期支持 | 付款条件 | 示例：月结30天 | 否 | 判断现金流影响 |
| 文件资质 | 资质资料完整性 | 示例：营业执照已收 | 是 | 判断准入条件 |
| 历史异常 | 质量、交期、价格等异常 | 示例：曾延期一次 | 否 | 判断分级和淘汰 |
| 可替代性 | 是否有备选供应商 | 示例：暂无替代 | 否 | 判断供应风险 |
| 来源 | 资料、评分或沟通记录 | 示例：供应商档案 | 是 | 追溯判断依据 |
