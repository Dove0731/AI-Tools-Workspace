## 二、资料进入规则

| 资料状态      | 放置位置                | 处理动作         |
| --------- | ------------------- | ------------ |
| 未分类       | `97_待整理/待分类`        | 判断应进入哪个正式模块  |
| 含敏感信息     | `97_待整理/待脱敏检查`      | 脱敏后再进入正式目录   |
| AI 生成未确认  | `98_AI输出暂存区/待确认输出`  | 人工核对数据、来源、结论 |
| 已确认待入库    | `98_AI输出暂存区/已确认待入库` | 录入台账并放入正式目录  |
| 已关闭项目或旧资料 | `99_归档`             | 保留来源和关闭说明    |

## 三、台账关联原则

同一事项如果同时涉及项目、供应商、报价、订单和异常，必须用同一个项目编号或问题编号串联，避免资料分散后无法追溯。

| 编号类型 | 用途 | 示例 |
|---|---|---|
| `PD-YYYY-序号` | 新品开发项目 | `PD-2026-001` |
| `RM-YYYY-序号` | 原料开发项目 | `RM-2026-001` |
| `PM-YYYY-序号` | 包材开发项目 | `PM-2026-001` |
| `SUP-YYYY-序号` | 供应商开发 | `SUP-2026-001` |
| `CO-YYYY-序号` | 成本优化项目 | `CO-2026-001` |
| `RP-YYYYMM-序号` | 问题复盘 | `RP-202607-001` |
