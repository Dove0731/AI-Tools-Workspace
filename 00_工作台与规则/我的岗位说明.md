# 我的岗位说明

## 我的岗位定位

我是化妆品公司的产品开发与采购项目负责人，核心价值不是单纯“下单采购”或“跟进打样”，而是通过产品开发、供应商管理、成本控制和交付协同，帮助公司提升毛利、支撑销售成交、降低供应链风险、缩短新品开发周期。

## 我的核心职责

| 职责 | 具体内容 | 经营价值 |
|---|---|---|
| 新品开发项目管理 | 跟进立项、配方方向、原料、包材、打样、测试、定版、量产、上市 | 缩短开发周期，支撑销售成交 |
| 原料与包材采购 | 询价、比价、样品、资料、MOQ、交期、下单 | 控制成本，保障交付 |
| 供应商管理 | 准入、分级、绩效、异常、淘汰、备选开发 | 降低质量、交期、单一供应商风险 |
| 成本优化 | 替代物料、年度框架价、阶梯价、付款条件优化 | 提升毛利和现金流效率 |
| 异常闭环 | 处理质量、交期、报价、成本、沟通异常 | 减少损失，形成可复用 SOP |
| 老板汇报 | 输出经营视角的结果、问题、风险和决策建议 | 帮助管理层快速判断和拍板 |

## 我的工作边界

| 范围内 | 范围外但需协同 |
|---|---|
| 产品开发进度统筹 | 配方最终技术判断由研发确认 |
| 原料、包材、供应商采购分析 | 财务付款审批由财务和老板确认 |
| 供应商准入和分级建议 | 法规、质量最终放行由品质/法规确认 |
| 成本优化测算和建议 | 销售最终报价和客户成交由销售确认 |
| 项目风险识别和推动闭环 | 工厂排产最终安排由生产/OEM 工厂确认 |

## 我需要 AI 帮我解决的问题

- 把零散资料整理成台账、报告、复盘和老板汇报。
- 对采购订单、报价、供应商、项目进度做异常识别。
- 按经营视角分析成本、毛利、交期、质量、库存和现金流影响。
- 生成可直接复制使用的邮件、谈价话术、会议纪要、行动清单。
- 根据历史数据提炼供应商分级、降本机会和项目风险。
- 把会议、聊天、表格、PPT、Word 等资料转成结构化工作成果。

## 协同关系

| 对象 | 我需要对接什么 | 输出结果 |
|---|---|---|
| 老板 | 经营结果、风险、降本、需决策事项 | 结论清楚的汇报和决策选项 |
| 研发 | 配方方向、原料风险、测试反馈、成本目标 | 原料筛选和样品推进 |
| 销售 | 客户需求、目标价、上市时间、成交概率 | 产品定位和开发优先级 |
| 供应商 | 报价、MOQ、交期、账期、资料、质量异常 | 比价、谈判、分级和替代方案 |
| OEM/ODM 工厂 | 打样、报价、资料、排产、量产风险 | 项目进度和量产保障 |
| 品质/法规 | 检测、资质、质量异常、合规风险 | 放行依据和风险闭环 |
| 财务 | 付款方式、账期、预付款、现金流影响 | 付款建议和现金流风险提示 |
