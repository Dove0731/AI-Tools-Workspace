# 知识入库与分流规则

## 目的

将 ChatGPT 与 Codex 的有效会话内容转为可检索、可追溯的 Obsidian 知识资产；会话摘要不是业务事实的替代品。

## 自动处理

同步器仅提取用户与助手正文，执行脱敏、按会话 ID 去重，并先归入：

- `07_AI工作区/AI知识同步/新AI工具人/新品开发`
- `07_AI工作区/AI知识同步/新AI工具人/采购与成本`
- `07_AI工作区/AI知识同步/新AI工具人/供应商管理`
- `07_AI工作区/AI知识同步/新AI工具人/订单与交付`
- `07_AI工作区/AI知识同步/新AI工具人/质量与异常`
- `07_AI工作区/AI知识同步/新AI工具人/经营与汇报`
- `07_AI工作区/AI知识同步/新AI工具人/会议与协同`
- `07_AI工作区/AI知识同步/新AI工具人/系统与自动化`
- `07_AI工作区/AI知识同步/新AI工具人/其他待整理`

## 人工确认后的正式归位

| 内容类型 | 正式目录 | 必须补齐的信息 |
|---|---|---|
| 可执行新品事项 | `03_项目管理` / `09_产品开发管理` | 项目名、阶段、负责人、节点、成本和风险 |
| 报价、订单、成本判断 | `10_采购与成本管理` / `04_数据台账` | 物料、供应商、数量、含税口径、MOQ、交期、账期 |
| 供应商评价或异常 | `08_供应商管理` / `05_问题反馈与复盘` | 证据、影响、责任人、整改节点、替代方案 |
| 会议结论和跨部门行动 | `02_会议与协同` | 议题、结论、责任人、完成日期、验收标准 |
| 可复用方法、模板或话术 | `06_经验与模板` | 适用场景、输入、输出、版本和来源 |
| 尚未核实的 AI 结论 | `98_AI输出暂存区` | 待确认项、确认人、截止时间 |

## 升级规则

涉及毛利、重大客户、质量、交付、库存、现金流、合规、品牌或重复性供应风险时，不得仅保留在 AI 会话知识中；必须建立正式台账或异常复盘，并明确责任人与截止时间。

## 云端同步

每日 18:10 自动运行。无变化不提交；发现密钥、凭证、未忽略的大文件或 Git 冲突时停止推送并通知，不绕过安全检查。
