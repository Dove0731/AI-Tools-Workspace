# 标签规则

## 推荐标签

| 标签 | 用途 |
|---|---|
| `#新品开发` | 新产品从立项到上市的事项 |
| `#原料采购` | 原料开发、询价、比价、替代和采购 |
| `#包材采购` | 包材开发、打样、报价、交期和库存 |
| `#供应商管理` | 准入、分级、绩效、异常和淘汰 |
| `#成本优化` | 降本、替代、年度框架价、阶梯价 |
| `#交期风险` | 延期、排产、物流、交付卡点 |
| `#质量异常` | 样品、来料、生产、客诉相关质量问题 |
| `#老板汇报` | 可用于管理层汇报的结论和材料 |
| `#待确认` | 数据、判断或责任仍未确认 |

## 使用规则

每个正式文件至少有一个业务标签；未确认信息必须同时标注 `#待确认`，关闭后删除该标签并写明关闭日期。
