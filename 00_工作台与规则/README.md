# 00_工作台与规则

## 目录用途

本目录是整个“化妆品产品开发与采购 AI 工作库”的总入口，负责统一工作方法、分析口径、命名规则、AI 使用规则和经营视角判断标准。

## 存放内容

- 工作库总索引、工作台、索引与台账清单。
- 岗位说明、AI 使用规则、经营视角分析规则。
- 命名规则、标签规则、信息分级规则、系统词典。
- 公司已发布制度及标准文件入口。
- 旧目录整合说明和重构成果清单。

## 更新规则

- 当岗位职责、汇报口径、台账规则或 AI 使用方式变化时，优先更新本目录。
- 新增规则必须写明适用范围、使用方式和禁止事项。
- 涉及经营口径、成本口径、供应商等级口径的变更，要同步检查 04、08、10 目录。

## 使用方式

1. 新任务先看 `总索引.md` 判断归属。
2. 不确定怎么分析时，先看 `AI使用总规则.md` 和 `经营视角分析规则.md`。
3. 不确定资料放哪里时，看 `索引与台账清单.md`。
4. 所有未确认数据必须标注“待确认”。
