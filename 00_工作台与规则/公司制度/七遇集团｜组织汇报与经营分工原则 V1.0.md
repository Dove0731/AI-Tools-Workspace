# 七遇集团｜组织汇报与经营分工原则 V1.0

生效日期：2026年8月2日。适用范围：七遇集团现有组织架构内的所有部门负责人及员工。

# 一、目的

明确直线汇报、经营协同与最终拍板的边界，避免同一事项出现两个直接上级，避免副总被降级为高级执行者，也避免董事长/总经理持续陷入日常救火。

# 二、基本规则

1. 每位员工只对应一位直线主管；日常任务、评价、培养与资源申请以该主管为准。

2. 跨部门事项由陈海玲副总组织协同；协同不改变部门的直线汇报关系。

3. 涉及战略、资金财务真实性、研发方向、关键人和重大取舍的事项，由董事长/总经理最终拍板。

4. 各部门负责人不得以协同为由绕开直线主管；也不得以直线管理为由拒绝跨部门配合。

# 三、部门汇报与分工

|部门/岗位|直线汇报对象|陈海玲副总职责|董事长/总经理最终拍板事项|
|---|---|---|---|
|陈海玲副总|董事长/总经理|经营组织、人效、干部、机制与跨部门协同|公司经营方向、重大组织调整、关键人任免|
|谢俊生销售总监|董事长/总经理|协同交付资源、干部培养与销售机制落地|收入目标、重点客户、销售策略与培养重点|
|事业一部、事业二部、销售运营与销售助理|谢俊生销售总监|协同交付、人效与机制问题|重大客户、价格底线、战略客户与重大例外|
|客服部|谢俊生销售总监|协调跨部门交付、投诉与改善闭环|重大客户投诉与赔付原则|
|研发部|董事长/总经理|推动项目节点、资源协同与跨部门问题解决|研发方向、优先级、重大立项、关键定制与技术投入|
|财务负责人|董事长/总经理|使用经营数据推动预算、成本、人效与组织方案；不接管财务独立性|利润、现金流、回款、付款、财务真实性、内控与重大风险|
|人力资源|陈海玲副总|直线管理招聘、绩效流程、干部盘点、培训与组织执行|管理层任免、核心岗位、薪酬框架与重大人事处理|
|行政部|陈海玲副总|直线管理行政与制度执行|重大行政支出、公司制度和权限边界|
|采购部|陈海玲副总|直线管理供应、成本、交期与采购机制|重大供应商、重大采购、关键成本与重大例外|
|品控开发部|董事长/总经理|协同质量、开发、供应与交付的跨部门节点|质量标准、开发优先级、重大质量事故与放行例外|
|设计部|陈海玲副总|直线管理设计资源与交付效率|品牌方向、重大包装与客户定制边界|
|万妍+云仓|陈海玲副总|直线管理仓储、物流、人效与运行机制|仓储模式、岗位/人效调整与重大库存处置|
|百媚工厂|陈海玲副总|直线管理生产、交付、人效与工厂运行机制|产能投资、重大排产取舍、安全与重大质量事项|

# 四、必须遵守的边界

**陈海玲副总**不替研发决定方向，不接管财务独立性，不替谢俊生经营所有客户；她的核心价值是让组织、干部、机制和跨部门协同真正跑起来。

**谢俊生销售总监**不应变成逐个客户跟进的高级销售；他应经营收入、利润、回款、客户质量和销售团队能力，并把有效经验沉淀为销售机制。

**品控开发部**直接向董事长/总经理汇报，对质量标准、开发优先级、重大质量风险和放行例外负责；与研发部的具体开发职责边界，应在岗位职责确认后单独明确，避免重复开发或责任空档。

**研发与财务**虽直线向董事长/总经理汇报，但应固定向陈海玲副总同步项目节点和经营数据，以支持公司整体组织经营。

# 五、运行与复核

本原则自发布日起执行。出现跨部门争议时，先按本文件确认直线责任、协同责任与最终拍板权；两周后基于真实运行中的卡点进行复核，必要时仅修订相关边界，不另建平行汇报体系。

# 六、岗位说明书的共建与定稿

岗位说明书是组织协同的共同约定，不由单一岗位或单一管理者闭门制定。凡涉及岗位职责、协同接口、权限边界、升级确认事项和验收标准，相关管理层均应基于真实业务协作提出意见。

**共建方式：**岗位牵头人先形成试行稿；直接协作部门补充职责接口、风险边界和验收口径；管理层以评论或明确建议参与校准，不以直接改写造成版本混乱。

**定稿与试行：**总经理对岗位说明书定稿并决定试行。试行中出现职责重叠、协同卡点或结果责任不清时，记录实际问题后复核更新；未经确认，不以个人理解替代正式岗位边界。

**公开与私密边界：**岗位职责、汇报关系、协同接口和结果要求可向管理层公开；个人培养判断、评价记录及未成熟结论保留在私密管理记录中。
