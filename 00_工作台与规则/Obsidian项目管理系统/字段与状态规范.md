# 字段与状态规范

## 项目必填属性

| 字段 | 允许值或格式 | 说明 |
|---|---|---|
| `type` | `project` | 用于识别项目页 |
| `project_id` | `PRJ-YYYYMM-NNN` | 全库唯一编号 |
| `status` | 待启动/进行中/已暂停/已完成/已归档/待确认 | 只使用统一状态 |
| `priority` | P0/P1/P2/P3/待确认 | P0 为紧急且经营影响重大 |
| `owner` | 姓名/待确认 | 第一责任人 |
| `stage` | 业务阶段/待确认 | 新品项目优先使用 Stage-Gate 阶段 |
| `start_date` | `YYYY-MM-DD`/待确认 | 计划启动日期 |
| `due_date` | `YYYY-MM-DD`/待确认 | 当前承诺完成日期 |
| `updated` | `YYYY-MM-DD` | 最近有效更新日期 |
| `tags` | YAML 列表 | 至少包含 `项目` 与业务分类 |

## 任务状态

`待办 → 进行中 → 等待外部 → 待验收 → 已完成`

- “已完成”必须有可检查产出或业务证据。
- 只有文档、SOP、脚本或测试完成时，应写明“文档已完成”或“技术验证已完成”，不得推断业务已闭环。
- 缺少负责人、日期、数量、金额、验收或来源时填写“待确认”。

## 优先级口径

| 优先级 | 判断口径 |
|---|---|
| P0 | 已影响或即将影响收入、量产、重大质量、合规或关键交付，需要立即处理 |
| P1 | 本周必须推进，延误将造成明显成本、库存、交期或客户影响 |
| P2 | 计划内重要事项，可按节点推进 |
| P3 | 优化、储备或低影响事项 |

## 文件命名

- 项目：`PRJ-YYYYMM-NNN_项目名称.md`
- 决策：`DEC-YYYYMMDD-NNN_决策主题.md`
- 风险问题：`RISK-YYYYMMDD-NNN_风险主题.md`
- 会议：`YYYY-MM-DD_会议主题.md`
- Codex 任务：`YYYY-MM-DD_任务主题.md`
