# 系统地图

| 工作对象 | 主目录 | 标准输入 | 标准输出 |
|---|---|---|---|
| 工作入口 | `00_工作台与规则` | 待办、业务要求、数据缺口 | 优先级、路由、下一步 |
| 报告 | `01_工作报告` | 已确认数据和项目结论 | 日报、周报、月报、老板汇报 |
| 会议协同 | `02_会议与协同` | 议题、参会人、证据 | 结论、行动项、责任人、截止日期 |
| 项目 | `03_项目管理` | 目标、范围、资源、节点 | 项目卡、里程碑、复盘、归档 |
| 数据 | `04_数据台账` | 有来源的数据记录 | 可追溯的业务台账 |
| 问题复盘 | `05_问题反馈与复盘` | 异常事实、影响、证据 | 根因、纠正预防、闭环证据 |
| 模板知识 | `06_经验与模板` | 已验证做法 | 模板、SOP、话术 |
| AI 协作 | `07_AI工作区` | 明确任务、范围、来源 | 执行记录、草稿、验证结果 |
| 供应商 | `08_供应商管理` | 资质、报价、交付、质量 | 分级、策略、淘汰或替代建议 |
| 产品开发 | `09_产品开发管理` | 立项、样品、测试、成本 | Stage-Gate 结论和上市准备 |
| 采购成本 | `10_采购与成本管理` | 报价、订单、MOQ、账期 | 比价、降本、交付和现金流判断 |
| 管理背景 | `11_张总分享专区` | 张总原话、明确要求、转述 | 标明来源的管理背景和行动转化 |
| 待处理 | `97_待整理` | 未分类或待脱敏资料 | 分类、补录、确认 |
| AI 暂存 | `98_AI输出暂存区` | 未确认 AI 产出 | 确认、作废或正式入库 |
| 归档 | `99_归档` | 已关闭且有证据的资料 | 只读历史记录 |

## 信息流

`收集 → 判断优先级 → 建项目/建任务 → 执行与协同 → 记录决策和风险 → 验收 → 复盘 → 知识沉淀 → 归档`

任何节点资料不足时，保留“待确认”，不得用计划、模板或测试结果替代真实业务完成。
