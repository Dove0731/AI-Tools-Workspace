# 经营视角分析规则

## 核心判断

产品开发和采购的价值，最终要落到经营结果：提升毛利、支撑成交、保障交付、降低风险、改善现金流。

## 采购如何创造经营价值

| 采购动作 | 经营价值 | 分析要点 |
|---|---|---|
| 比价议价 | 降低采购成本，提高毛利 | 同口径比较单价、税费、物流、损耗、MOQ |
| 供应商替代 | 降低单一供应商风险 | 验证质量、交期、资料、账期和稳定性 |
| 年度框架价 | 锁定成本，提升议价权 | 评估年度量、价格波动和库存风险 |
| 阶梯价谈判 | 用规模换价格 | 判断销量预测是否支撑起订量 |
| 账期优化 | 改善现金流 | 比较预付、到货付款、月结对资金占用的影响 |

## 产品开发如何支撑销售成交

| 开发动作 | 对销售的价值 |
|---|---|
| 明确产品定位 | 让销售知道卖给谁、卖什么价值 |
| 控制成本目标 | 保证报价有毛利空间和成交竞争力 |
| 缩短打样周期 | 提高客户响应速度 |
| 控制包材和原料风险 | 避免上市前反复调整 |
| 准备产品资料 | 支撑销售介绍、客户确认和渠道上架 |

## 降本如何影响毛利

降本金额计算口径：

`优化金额 = 原方案单价 × 数量 - 新方案单价 × 数量`

分析时必须补充：

- 是否含税、物流、损耗。
- 是否因 MOQ 增加造成库存占用。
- 是否改变质量风险或交期风险。
- 是否可复制到其他产品或物料。
- 是否影响销售报价和成交空间。

## 交期如何影响收入确认

| 交期问题 | 经营影响 |
|---|---|
| 原料延期 | 影响打样、生产和订单交付 |
| 包材延期 | 影响灌装、包装和上市节点 |
| 工厂排产延后 | 影响客户交付和收入确认 |
| 物流不确定 | 增加加急费、延期风险和客户投诉 |

判断交期问题时，必须说明是否影响上市时间、客户交付、销售回款或收入确认。

## 供应商稳定性如何影响公司风险

| 风险 | 影响 |
|---|---|
| 单一供应商 | 议价弱、断供风险高 |
| 质量不稳定 | 返工、索赔、客诉、品牌风险 |
| 交付不稳定 | 项目延期、订单延期 |
| 资料不完整 | 备案、法规、客户审核受阻 |
| 配合度差 | 增加沟通成本和项目周期 |

## 付款方式如何影响现金流

| 付款方式 | 现金流影响 | 分析建议 |
|---|---|---|
| 全额预付 | 资金占用高，供应商风险高 | 尽量争取分段付款或到货付款 |
| 定金+尾款 | 风险中等 | 明确交付节点和验收条件 |
| 到货付款 | 对现金流较友好 | 适合稳定供应商 |
| 月结 | 现金流支持最好 | 可作为 A/B 类供应商谈判目标 |
