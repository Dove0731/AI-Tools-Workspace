# 系统词典

本目录用于统一产品开发、采购、供应商和复盘口径，避免同一概念在不同文件里写法不一致。

| 词典 | 用途 |
|---|---|
| `系统词典/00_标签规范词典.md` | 标签和主题归类 |
| `系统词典/01_产品开发词典.md` | 项目阶段、打样、测试、上市节点 |
| `系统词典/02_采购成本词典.md` | 报价、MOQ、账期、税费、物流、损耗、降本口径 |
| `系统词典/03_供应商分级词典.md` | A/B/C/D 分级和动作口径 |
| `系统词典/04_风险问题词典.md` | 质量、交期、库存、现金流、供应商风险分类 |
| `系统词典/05_状态字段词典.md` | 未开始、进行中、待反馈、有风险、已关闭等状态 |
