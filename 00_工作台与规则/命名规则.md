# 命名规则

## 通用格式

- 日常记录：`YYYY-MM-DD_主题.md`
- 月度资料：`YYYY-MM_主题.md`
- 项目资料：`项目编号_产品或事项_资料类型.md`
- 供应商资料：`供应商简称_资料类型_YYYYMMDD.md`
- 报价资料：`物料或项目_供应商简称_报价_YYYYMMDD.md`
- 复盘资料：`RP-YYYYMM-序号_问题名称_复盘.md`

## 编号建议

| 类型 | 编号格式 | 示例 |
|---|---|---|
| 新品开发项目 | `PD-YYYY-序号` | `PD-2026-001` |
| 原料开发项目 | `RM-YYYY-序号` | `RM-2026-001` |
| 包材开发项目 | `PM-YYYY-序号` | `PM-2026-001` |
| OEM/ODM 协同项目 | `OEM-YYYY-序号` | `OEM-2026-001` |
| 成本优化项目 | `CO-YYYY-序号` | `CO-2026-001` |
| 供应商开发 | `SUP-YYYY-序号` | `SUP-2026-001` |
| 问题复盘 | `RP-YYYYMM-序号` | `RP-202607-001` |

## 禁止命名

- 不使用“最终版”“最新版”作为唯一版本说明，必须带日期。
- 不使用无意义文件名，如“新建文档”“报价”“供应商资料”。
- 不把未确认数据命名为“已确认”“已定版”。
