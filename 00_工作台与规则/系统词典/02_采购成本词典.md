# 采购成本词典

| 概念 | 标准口径 | 使用要求 |
|---|---|---|
| 报价单价 | 供应商提供的含税/未税价格 | 必须标注币种、税率、有效期、报价日期 |
| 到手成本 | 单价 + 税费 + 物流 + 损耗 + 其他必要费用 | 用于真实经营判断，不能只看报价单价 |
| MOQ | 最小起订量 | 同时说明库存占用和现金流影响 |
| 账期 | 付款节点和周期 | 说明是否影响现金流、是否需要老板决策 |
| 优化金额 | 原方案单价 × 数量 - 新方案单价 × 数量 | 税费、物流、损耗、MOQ、账期需单独说明 |
| 年度框架价 | 基于年度量或预测量锁定价格 | 必须评估量不达标、价格下跌和供应锁定风险 |
| 阶梯价 | 不同采购量对应价格 | 需要结合项目销量预测和库存风险判断 |
