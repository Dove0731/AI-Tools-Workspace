# 标签规范词典

| 标签 | 标准含义 | 常见归档位置 |
|---|---|---|
| `#新品开发` | 新产品立项、打样、测试、量产、上市 | `09_产品开发管理`、`03_项目管理` |
| `#原料采购` | 原料询价、替代、采购和风险 | `10_采购与成本管理/原料采购` |
| `#包材采购` | 包材开发、报价、打样、交期和库存 | `10_采购与成本管理/包材采购` |
| `#供应商管理` | 准入、分级、绩效、异常、淘汰 | `08_供应商管理` |
| `#成本优化` | 降本、阶梯价、替代、框架价 | `10_采购与成本管理/成本优化` |
| `#质量异常` | 样品、来料、生产、客诉质量问题 | `05_问题反馈与复盘` |
| `#交期风险` | 供应商、工厂、物流、排产延期 | `05_问题反馈与复盘/02_交期异常` |
| `#现金流` | 付款、账期、预付款、库存占用 | `10_采购与成本管理/付款与现金流` |
| `#老板汇报` | 可上报经营结果或需决策事项 | `01_工作报告/老板汇报` |
| `#待确认` | 数据、判断、责任或时间未确认 | 先放原目录，关闭时删除标签 |
