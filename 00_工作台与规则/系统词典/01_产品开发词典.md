# 产品开发词典

| 字段 | 标准选项 | 说明 |
|---|---|---|
| 项目阶段 | 需求确认、立项评审、配方方向、包材匹配、打样、测试、报价核算、客户确认、量产准备、上市、关闭 | 每个项目只能有一个当前阶段 |
| 产品定位 | 走量款、利润款、形象款、客户定制、渠道专供、储备款 | 影响成本目标和开发优先级 |
| 打样状态 | 未启动、已发需求、已出样、待反馈、需调整、已确认、暂停 | 必须记录样品版本和反馈来源 |
| 测试状态 | 未测、进行中、通过、未通过、需复测、待客户确认 | 需记录测试项目和结论来源 |
| 量产风险 | 无明显风险、成本风险、交期风险、质量风险、包材匹配风险、供应商风险、法规资料风险 | 有风险必须对应下一步动作 |
