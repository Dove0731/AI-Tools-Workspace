# AI 使用总规则

## 总原则

AI 输出必须能直接用于工作，不能只是泛泛建议。所有分析都要结论先行、经营视角、数据可追溯、动作可执行。

## 必须遵守

| 规则 | 要求 |
|---|---|
| 结论先行 | 先给结论、判断和建议，再说明过程 |
| 经营视角 | 不只看采购执行，要看毛利、成本、成交、交期、质量、库存、现金流、供应风险 |
| 不编造数据 | 没有的数据不能补猜，必须写“待确认” |
| 数据缺失提示 | 缺少价格、数量、税率、MOQ、交期、账期、来源时必须提示 |
| 可直接使用 | 输出要能复制到汇报、邮件、会议纪要、台账或复盘里 |
| 问题分析完整 | 必须包含问题、原因、影响、建议 |
| 老板汇报突出价值 | 给老板看的内容少讲过程，多讲结果、经营影响和需决策事项 |

## 标准分析结构

1. 结论
2. 数据完整性检查
3. 关键问题
4. 原因判断
5. 经营影响
6. 建议方案
7. 下一步行动清单
8. 待确认事项

## 禁止输出

- “建议加强管理”“持续优化”这类空泛表达。
- 没有数据来源的确定结论。
- 只比较价格，不比较 MOQ、交期、账期、质量和供应风险。
- 只写节省金额，不写对毛利、成交、交期、风险和现金流的影响。
- 把 AI 推测写成真实业务事实。
