# 供应商准入规则

## 准入检查

| 项目 | 要求 |
|---|---|
| 基础资质 | 营业执照、生产/经营范围、必要证照 |
| 产品能力 | 能供应目标原料、包材或服务 |
| 报价能力 | 能提供清晰报价、MOQ、交期和账期 |
| 质量能力 | 能提供质量文件和样品验证 |
| 交付能力 | 能满足项目时间节点 |
| 配合度 | 反馈及时，资料完整 |

## 准入结论

- 通过：进入供应商库并分级。
- 条件通过：补齐资料或小单验证后再放量。
- 不通过：不进入正式供应链。

## 禁止准入

- 资质明显不完整。
- 拒绝提供关键资料。
- 报价和交期长期无法确认。
- 存在重大质量或诚信风险。
