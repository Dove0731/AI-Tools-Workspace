# 供应商评估表字段

| 字段 | 含义 | 示例 | 是否必填 | AI 使用方式 |
|---|---|---|---|---|
| 供应商名称 | 评估对象 | 供应商A | 是 | 识别供应商 |
| 类型 | 原料/包材/OEM/ODM等 | 包材 | 是 | 匹配评估标准 |
| 价格竞争力 | 相对市场报价 | 中 | 是 | 判断成本优势 |
| 质量稳定性 | 质量表现 | 待确认 | 是 | 判断质量风险 |
| 交付能力 | 准时交付能力 | 良好 | 是 | 判断交期风险 |
| 配合度 | 响应和协同 | 反馈慢 | 是 | 判断项目推进风险 |
| 开发能力 | 打样和方案能力 | 可开发新品 | 否 | 判断长期价值 |
| 账期支持 | 付款条件 | 月结30天 | 否 | 判断现金流 |
| 文件资质 | 资质资料完整性 | 待补检测报告 | 是 | 判断准入风险 |
| 历史异常 | 异常记录 | 延期1次 | 否 | 判断降级或淘汰 |
| 可替代性 | 是否有替代供应商 | 暂无 | 否 | 判断供应风险 |
| 长期合作价值 | 是否值得重点培养 | 待确认 | 是 | 判断分级 |
