# 采购订单—入库—在途分析：Codex完整执行指令

## 一、任务目标

读取三类数据：

1. ERP采购订单：权威下单数据；
2. ERP采购入库单：权威完工/收货数据；
3. 人工采购在途表：只补充预计送货、负责人、异常原因和跟进动作，不得覆盖ERP事实。

生成订单完成分析、临期延期预警、分批入库汇总、历史价格对比、降本/涨价影响及数据质量异常清单。

## 二、直接发送给Codex的完整指令

```text
你现在需要在当前项目中建立“采购订单—入库—在途自动分析流程”。

【输入文件】
在项目的 input/ 目录中查找最新的以下三类Excel文件，文件名可带导出时间：
1. 采购订单*.xlsx
2. 采购入库单*.xlsx
3. 采购在途*.xlsx

【数据权威顺序】
1. ERP采购订单是下单事实；
2. ERP采购入库单是实际完成事实；
3. 人工采购在途表只作参考补充，绝不能覆盖ERP采购数量、实际入库数量、入库日期、入库价格和金额。

【真实字段】
ERP采购订单字段：
单据编号、采购日期、供应商、单据状态、采购组织、关闭状态、物料编码、物料名称、采购单位、采购数量、交货日期、是否赠品、业务关闭、委外领料套数。

ERP采购入库单字段：
单据编号、入库日期、供应商、单据状态、物料编码、物料名称、库存单位、实收数量、批号、仓库、含税单价、仓位、仓位.A库.编码、仓位.A库.名称、订单单号、单价、金额。

人工在途表可能包含：
采购订单号、物料编码、物料名称/包材名称、下单数量、已到数量、未到采购在途、预计送货时间、2次预计送货时间、跟进负责人、包材供应商、延期原因/跟进动作、异常问题原因、备注、本次采购成本、上批采购成本。

注意：当前人工在途文件的“OEM在途订单10月”和“自主品牌采购在途10月”缺少采购订单号、物料编码，不能可靠自动匹配。必须将这些行列入“在途待补字段清单”，不得使用产品名称或包材名称强行模糊匹配。只有同时具备采购订单号和物料编码的在途记录才允许自动关联。

【清洗规则】
1. 所有列名去除换行、首尾空格和重复空格；
2. ERP采购订单中“单据编号”只在每张单据第一行出现，后续物料行为空。必须按原始行顺序向下填充，直到下一个非空单据编号；
3. ERP采购入库单中“单据编号”也按相同方式向下填充为“入库单号”；
4. 采购订单号、订单单号、物料编码统一转为文本、去首尾空格并转大写；
5. 采购数量、实收数量、含税单价、单价、金额转换为数值；
6. 采购日期、交货日期、入库日期及在途预计日期转换为真实日期；
7. 建立明细匹配键：采购订单号 + "|" + 物料编码；
8. 不允许只按采购订单号匹配，因为一张采购订单可能有多个物料；
9. 一个在途单元格中出现多个CGDD订单号时，提取所有CGDD+数字编号并拆分；若无法判断每个订单对应数量，则放入人工确认清单；
10. 保留原始文件名、工作表名和原始行号，方便追溯。

【采购订单标准表】
输出以下字段：
采购订单号、采购日期、供应商、单据状态、采购组织、关闭状态、物料编码、物料名称、采购单位、采购数量、要求交货日期、是否赠品、业务关闭、委外领料套数、明细匹配键、订单有效标识、来源文件、原始行号。

订单有效标识规则：
- 单据状态=已审核，且业务关闭不等于业务关闭，且关闭状态不等于已关闭：有效；
- 已关闭订单仍保留，但单独标记，不进入未到货催办；
- 赠品单独标记，默认不进入价格分析。

【入库汇总规则】
先保留入库明细，再按“订单单号+物料编码”汇总：
- 累计实收数量 = 实收数量求和；
- 累计入库金额 = 金额求和；
- 加权含税单价 = 累计入库金额 / 累计实收数量；
- 若金额为空但含税单价不为空，补算行金额=实收数量×含税单价，并标记“金额补算”；
- 首次入库日期 = 最小入库日期；
- 最近入库日期 = 最大入库日期；
- 入库次数 = 不重复入库单号数量；
- 入库单号集合 = 去重后的入库单号列表。

不得对多次入库单价进行简单平均，必须使用金额/数量计算加权单价。

【订单与入库匹配】
以采购订单标准表为左表，按明细匹配键关联入库汇总表。

计算：
- 完成率 = 累计实收数量 / 采购数量；
- 未到数量 = MAX(采购数量 - 累计实收数量, 0)；
- 超收数量 = MAX(累计实收数量 - 采购数量, 0)；
- 无入库记录：未到货；
- 0 < 累计实收数量 < 采购数量：部分入库；
- 累计实收数量在采购数量±0.1%范围：已完成；
- 累计实收数量 > 采购数量×1.001：超收；
- 已关闭订单：已关闭，不进入催办。

交付判断：
- 已完成订单延期天数 = MAX(最近入库日期 - 要求交货日期, 0)；
- 未完成有效订单延期天数 = MAX(运行日期 - 要求交货日期, 0)；
- 距要求交货日期0—3天且未完成：临期；
- 已超过要求交货日期且未完成：延期；
- 人工在途预计时间仅用于补充“最新承诺到货日”，不得改变ERP延期判断。

【历史价格与降本逻辑】
由于ERP采购订单导出文件没有采购单价，已完成订单的实际价格必须使用采购入库单的加权含税单价。

价格比较必须满足：
1. 物料编码相同；
2. 采购单位/库存单位相同；
3. 历史订单采购日期早于当前订单采购日期；
4. 历史记录单价和数量有效；
5. 赠品不参与；
6. 首次采购无历史基准价，标记“首单”，降本金额为空；
7. 历史基准价默认取同一物料最近一次有效完成采购的加权含税单价；
8. 同时补充“过去12个月最低价”和“同供应商上次价格”，但不得用最低价直接替代默认基准价。

计算：
- 价格差 = 本次加权含税单价 - 历史基准价；
- 价格变化率 = 价格差 / 历史基准价；
- 降本单价 = MAX(历史基准价 - 本次加权含税单价, 0)；
- 降本金额 = 降本单价 × 本次累计实收数量；
- 涨价单价 = MAX(本次加权含税单价 - 历史基准价, 0)；
- 涨价影响金额 = 涨价单价 × 本次累计实收数量；
- 价格上涨超过3%：标记价格异常并要求填写上涨原因。

严禁用人工在途表的“上批采购成本”覆盖ERP历史价格。未入库订单可展示“人工本次采购成本”，但价格状态必须标记“待ERP入库确认”，不得计入正式降本金额。

【人工在途补充】
只有存在采购订单号和物料编码时，才按明细匹配键关联以下字段：
预计送货时间、2次预计送货时间、跟进负责人、供应商简称、延期原因/跟进动作、异常问题原因、备注、人工本次采购成本、人工上批采购成本。

如果ERP与在途数据冲突：
- 采购数量、累计实收数量、价格、入库日期以ERP为准；
- 跟进负责人、最新承诺日期、异常原因和动作使用在途表；
- 输出“ERP与在途差异清单”，不得静默覆盖。

【必须输出的文件】
在 output/ 目录生成：
1. 采购订单入库在途分析.xlsx
   - 00_经营摘要
   - 01_订单完成分析
   - 02_临期延期清单
   - 03_分批入库汇总
   - 04_价格降本分析
   - 05_供应商交付统计
   - 06_ERP在途差异
   - 07_数据质量异常
   - 08_原始字段映射
2. 采购订单入库在途分析报告.md
3. data_quality_report.json

【经营摘要指标】
- 有效采购订单明细数；
- 已完成、部分入库、未到货、延期、临期、超收数量；
- 按时完成率；
- 累计采购数量、累计实收数量和未到数量；
- 正式确认的降本金额和涨价影响金额；
- 价格上涨超过3%的明细数；
- 供应商按时交付率排名；
- 未匹配入库、入库找不到订单、在途缺少主键、ERP与在途冲突数量。

【数据质量检查】
至少检查：
1. 采购订单号或物料编码为空；
2. 同一明细匹配键在采购订单表重复；
3. 采购数量为0或非数值；
4. 入库订单单号在当前采购订单导出范围不存在；
5. 入库物料编码与订单明细不匹配；
6. 金额与实收数量×含税单价差异超过0.01；
7. 同一明细出现多个不同入库单价；
8. 实收数量明显超过采购数量；
9. 在途表缺少采购订单号或物料编码；
10. 在途人工已到数量与ERP累计实收数量不一致；
11. 日期无法解析；
12. 单位不一致；
13. 表内存在#REF!、#VALUE!等公式错误。

【Excel要求】
- 保留原始数据，不覆盖输入文件；
- 所有金额、数量、日期和百分比使用正确的数据类型及显示格式；
- 所有结果能追溯到来源文件、工作表和原始行号；
- 冻结表头、启用筛选；
- 临期用黄色、延期和涨价异常用红色、已完成用绿色；
- 计算逻辑尽量以可审计字段展示，不隐藏关键中间结果；
- 输出前检查公式错误、行数、汇总金额和匹配率；
- 随机抽查至少10个订单明细，核对订单数量、入库数量、入库金额和匹配键；
- 运行结束后在终端输出：输入行数、有效行数、匹配成功数、未匹配数、输出文件路径及主要异常。
```

## 三、执行前必须调整的人工在途表

当前“OEM在途订单10月”和“自主品牌采购在途10月”没有采购订单号、物料编码，无法与ERP稳定关联。建议在最左侧增加：

1. 采购订单号；
2. 物料编码；
3. 明细匹配键（采购订单号 + `|` + 物料编码）。

订单号和物料编码必须来自ERP，不建议由AI根据产品名称或包材名称猜测。

## 四、建议项目目录

```text
采购自动化分析/
├─ input/
│  ├─ 采购订单_导出时间.xlsx
│  ├─ 采购入库单_导出时间.xlsx
│  └─ 采购在途_更新日期.xlsx
├─ output/
├─ archive/
├─ scripts/
└─ README.md
```

每次运行前把最新ERP导出文件放入 `input/`，程序按文件更新时间选择最新版本；运行完成后将上一批输入及输出移动至 `archive/YYYY-MM/`，不得覆盖历史结果。
