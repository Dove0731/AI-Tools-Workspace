# 10_采购与成本管理

## 目录用途

本目录用于管理原料、包材、报价比价、采购订单、成本核算、降本、年度框架价、MOQ、付款方式和现金流分析。

## 存放内容

- 采购流程 SOP、询价比价规则、成本核算模型。
- 降本金额计算规则、订单分析规则、年度框架价谈判规则。
- MOQ 和付款现金流分析规则。
- 金蝶云星空物料、BOM、组织分配、收料、退料及主数据变更规则。

## 更新规则

- 报价、订单和成本数据必须保留来源。
- 降本测算必须说明税费、物流、损耗、MOQ 和账期影响。
- 采购异常必须同步问题闭环。

## 使用方式

1. 采购前明确需求、规格、数量、交期和口径。
2. 收到报价后按比价规则分析。
3. 下单后跟踪订单、到货和异常。
4. 定期识别降本和框架价机会。
5. 新建或变更物料、BOM 及相关业务单据时，先执行《金蝶云星空操作手册》的查重和质量门。
