# 采购价格对比逻辑

任务编号：AI-20260810-002

## 一、比较前提

当前价格与历史价格只有在物料编码、规格型号、质量标准、计量单位、币种、含税状态、税率、运费口径及可比数量梯度一致时才能直接比较。不一致时须先标准化，否则标注“不可比”。

历史基准优先使用：

1. 同物料、同规格、同供应商最近一次有效采购价。
2. 同物料、同规格的历史加权平均价。
3. 同物料、同规格的其他合格供应商有效价格。
4. 经业务确认的预算价或目标价。

必须输出基准类型、日期和来源。

## 二、基础计算

| 指标 | 计算口径 | 结果解释 |
|---|---|---|
| 当前采购金额 | 当前价格×采购数量 | 本次订单金额 |
| 单位价格变化 | 当前价格－历史价格 | 正数涨价，负数降价 |
| 价格变化率 |（当前价格－历史价格）÷历史价格×100% | 历史价格为0或缺失时不计算 |
| 单位节约 | 历史价格－当前价格 | 仅当前价低于历史价时为正 |
| 节约金额 | MAX（历史价格－当前价格，0）×采购数量 | 只统计降价形成的节约 |
| 单位涨价 | 当前价格－历史价格 | 仅当前价高于历史价时为正 |
| 涨价金额 | MAX（当前价格－历史价格，0）×采购数量 | 只统计涨价形成的增本 |
| 净价格影响 | 节约金额－涨价金额 | 正数净节约，负数净增本 |
| 年度预计节约 | MAX（历史价格－当前价格，0）×已确认年度预计量 | 无确认数量时不计算 |
| 年度预计增本 | MAX（当前价格－历史价格，0）×已确认年度预计量 | 无确认数量时不计算 |

节约与涨价必须分开汇总，不能只展示净额，以免掩盖重点涨价物料。

## 三、结果分类

| 条件 | 分类 | 输出动作 |
|---|---|---|
| 当前价格＜历史价格 | 降价/节约 | 输出单位节约、单项节约和年度预计节约 |
| 当前价格＝历史价格 | 持平 | 输出采购金额和非价格优化机会 |
| 当前价格＞历史价格 | 涨价/增本 | 输出单位涨价、涨价金额、年度预计增本和原因 |
| 历史价格缺失/为0 | 无法比较 | 列入数据缺口，不计算变化率 |
| 口径不一致 | 条件不可比 | 输出差异项，待标准化或人工确认 |

## 四、异常波动识别

任一条件满足即列入异常清单：

1. 价格变化率绝对值达到已确认的预警阈值。
2. 当前价格高于该物料历史最高可比价。
3. 当前价格低于历史最低价且伴随规格、质量、税费、交期或付款条件变化。
4. 同物料同日或相近日期，不同供应商同口径价格差异达到阈值。
5. 同供应商同物料短期内连续调价。
6. 当前价格、数量为0或负数，或价格较历史记录出现数量级差异。
7. 物料编码相同但名称/规格不同，或名称相同但编码异常变化。
8. 涨价导致订单金额、年度成本、毛利或现金流产生重大影响。

### 建议初始阈值（待确认）

- 价格变化率绝对值≥5%：关注。
- 价格变化率绝对值≥10%：重点异常。
- 单项涨价金额达到公司确认金额阈值：重点异常。
- 同类供应商价格差达到公司确认比例阈值：比价预警。

以上为流程建设建议，不是公司已确认标准；启用自动判断前必须由采购负责人确认。

## 五、异常原因分类

异常记录至少判断：

- 原材料或市场行情变化。
- 采购数量/MOQ或规格改变。
- 税率、币种、物流费用变化。
- 工艺、质量标准或包装要求变化。
- 供应商产能、交期或账期条件变化。
- 单一供应或临时紧急采购。
- 录入错误、单位错误或历史基准不适用。
- 其他原因：待确认。

## 六、供应商维度对比

按供应商汇总：

- 采购金额及占比。
- 涨价物料数、涨价金额。
- 降价物料数、节约金额。
- 同类物料价格排名。
- 交期和付款条件变化。
- 质量及供应风险。
- 可谈判、锁价、替代或分单机会。

低价不能直接等于高竞争力；必须同步判断质量、交期、MOQ、账期和稳定性。

## 七、经营输出

- 已实现节约、涨价增本、净价格影响。
- 年度预计节约与年度预计增本。
- 对单位成本、毛利额和毛利率的影响。
- 涨价集中物料、重点供应商和单一供应风险。
- 谈价、替代、锁价、MOQ、账期及采购节奏优化动作。
- 数据缺口、责任人和完成时限。
