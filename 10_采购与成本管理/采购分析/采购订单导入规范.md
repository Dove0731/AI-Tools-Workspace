# 采购订单导入规范

任务编号：AI-20260810-002  
任务名称：采购数据自动分析能力建设

## 一、目的

统一采购Excel的字段、格式、数据口径和校验规则，使导入数据可直接用于采购金额、价格变化、降本、涨价和供应商分析。本文件只定义业务规则，不包含程序代码。

## 二、Excel文件要求

- 文件格式：优先使用 `.xlsx`；如使用 `.csv`，编码和分隔符须明确。
- 一行一条采购订单明细；同一订单多个物料必须分行。
- 第一行为字段名，不使用合并单元格、多层表头、隐藏计算逻辑或空白字段名。
- 原始数据区域不得插入小计、合计、说明行或图片。
- 日期、数量、单价必须保存为可计算值，不得仅用文本描述。
- 文件须保留来源、导出日期、数据期间和版本。
- 原始文件不得直接覆盖；修订后另存并说明修订内容。

## 三、必需字段

| 标准字段 | 必填 | 格式/示例 | 业务口径 |
|---|---|---|---|
| 供应商 | 是 | 文本 | 使用可唯一识别的供应商正式名称 |
| 物料编码 | 是 | 文本 | 与物料主数据一致，前导零不得丢失 |
| 物料名称 | 是 | 文本 | 原料、包材、成品或服务名称 |
| 规格型号 | 是 | 文本 | 价格可比的重要条件；无规格时标注“待确认” |
| 采购日期 | 是 | YYYY-MM-DD | 订单确认或生效日期，口径须全表一致 |
| 采购数量 | 是 | 数值 | 应同时明确计量单位；退货、冲销另行标识 |
| 采购单价 | 是 | 数值 | 当前订单单位价格 |
| 历史采购价格 | 条件必填 | 数值 | 可比历史基准价；缺失时不计算价格变化和节约 |
| 交期 | 是 | YYYY-MM-DD或整数天 | 必须说明是承诺到货日还是交付周期 |
| 付款方式 | 是 | 文本 | 预付比例、付款节点或账期天数 |
| 备注 | 否 | 文本 | 税费、运费、MOQ、异常、数据来源等说明 |

## 四、强烈建议补充字段

仅有上述字段可以完成基础分析，但以下字段缺失会影响可比性和经营判断：

| 字段 | 作用 |
|---|---|
| 订单号、订单行号 | 去重和追溯 |
| 类别 | 原料、包材、OEM/ODM成品、服务分类 |
| 计量单位 | 防止kg、g、个、箱等误比 |
| 币种 | 避免跨币种直接比较 |
| 含税状态、税率 | 统一含税/未税口径 |
| 运费口径 | 区分含运和不含运 |
| 历史价格日期、来源 | 判断基准有效性 |
| 历史供应商、历史规格 | 判断是否真正可比 |
| MOQ | 评估库存和现金流 |
| 实际到货日期 | 判断准交情况 |
| 年度预计采购量、依据 | 测算年度预计节约 |
| 质量验收状态 | 判断低价方案的质量风险 |
| 订单状态 | 排除计划、取消、冲销、待核销记录 |
| 数据来源 | 支持复核和审计 |

## 五、数据格式规则

1. 供应商名称、物料编码和规格型号前后空格需清理，但不得擅自改名。
2. 物料编码按文本导入，禁止科学计数法和前导零丢失。
3. 数量、单价、历史价格不得包含“元”“个”等文字；单位另列。
4. 金额保留原始精度，展示时可四舍五入，计算不得提前截断。
5. 空值统一保留为空或标注“待确认”，不得用0代替未知数据。
6. 交期为日期时使用YYYY-MM-DD；为周期时使用整数天并标明“周期”。
7. 付款方式需可识别，例如“30%预付+70%发货前”“月结30天”。
8. 备注不能替代必填字段。

## 六、导入校验

### 阻断分析

出现以下情况时，该行不得进入价格和降本计算：

- 供应商、物料编码、采购日期、数量或单价缺失。
- 数量或单价不是有效数值。
- 历史采购价格缺失或为0，却要求计算价格变化率。
- 当前与历史规格、单位、币种、税费或运费口径不一致且未标准化。
- 无法识别退货、冲销、赠品、样品、计划或取消记录。

### 可导入但需预警

- 交期或付款方式缺失。
- 历史价格来源、日期或供应商缺失。
- 物料名称相同但编码不同，或编码相同但名称/规格不一致。
- 同订单、物料编码、规格和数量重复。
- 单价、数量或日期明显偏离该物料历史记录。
- 缺少年度预计采购量，导致无法年度化测算。

## 七、导入结果

每批数据输出：

- 原始行数、有效行数、阻断行数、预警行数、重复行数。
- 可分析字段和缺失字段清单。
- 口径不一致明细。
- 可进行价格比较的记录数。
- 可进行年度节约测算的记录数。
- 待业务确认事项及责任人。
