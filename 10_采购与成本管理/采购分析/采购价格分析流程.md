# 采购价格分析流程

任务编号：AI-20260810-001  
任务名称：采购订单价格分析与降本识别流程建设

## 一、目标

输入采购订单数据后，形成“数据校验—价格分析—降本识别—供应商判断—经营价值输出—行动闭环”的标准流程。

## 二、适用范围

适用于原料、包材、OEM/ODM成品及采购服务。比较必须满足同物料、同规格、同质量标准、同币种、同含税/运费口径和可比数量梯度；否则标注“不可直接比较”或“待确认”。

## 三、输入资料

1. 当前订单：订单号、日期、供应商、物料编码/名称、类别、规格、数量、单位、单价、币种、税率、运费、MOQ、交期、付款周期。
2. 历史采购：同物料历史日期、供应商、规格、数量梯度、单价及税费物流口径。
3. 供应商资料：报价、交付、质量、合作状态、等级和风险记录。
4. 年度需求：已确认年度或剩余年度预计采购量。
5. 可选资料：预算价、目标价、市场参考价、替代报价、质量异常和到货记录。

缺失字段不得补造，必须列入数据完整性检查。

## 四、标准执行流程

### 步骤1：数据接收与校验

- 检查必填字段、空值、重复订单、异常数量和异常单价。
- 统一日期、币种、单位、含税/未税、运费和规格口径。
- 退货、冲销、赠品、样品、计划订单等特殊记录不得混入正式价格。
- 输出“可分析、条件可比、不可比较、待确认”四类状态。

### 步骤2：建立可比价格基准

历史价格优先顺序：

1. 同物料、同规格、同供应商最近一次有效采购价。
2. 同物料、同规格的历史加权平均价。
3. 同物料、同规格的其他合格供应商有效报价。
4. 同类物料经规格、质量和采购条件标准化后的参考价。

`历史加权平均价 = Σ（历史单价 × 历史数量）÷ Σ历史数量`

必须保留历史价格来源、日期和口径；无有效基准时不得虚构。

### 步骤3：采购价格分析

逐物料输出当前价、最近历史可比价、历史最低/最高/加权平均价、变化额、变化率、趋势、同类物料差异和同口径供应商报价排序。

- 价格变化额：`当前价格－历史可比价格`
- 价格变化率：`（当前价格－历史可比价格）÷历史可比价格×100%`

趋势分为上涨、下降、持平或数据不足。异常预警阈值须由业务负责人确认；未配置前只展示事实变化。

### 步骤4：成本优化识别

- 单位节约：`历史可比价格－当前采购价格`
- 单项节约金额：`（历史可比价格－当前采购价格）×当前采购数量`
- 年度预计节约金额：`（历史可比价格－当前采购价格）×已确认年度预计采购数量`

结果大于0为节约，等于0为持平，小于0为成本增加。年度数量未确认时标注“待确认”，不得用当前订单量自动年化。

税费、物流、损耗、MOQ、模具/测试费、账期和切换成本单列。

`净经营收益 = 节约金额－新增物流－新增损耗－一次性投入－切换成本`

### 步骤5：供应商分析

| 维度 | 分析内容 | 数据来源 |
|---|---|---|
| 报价变化 | 当前/历史报价、变化额、变化率、有效期 | 报价单、订单 |
| 价格竞争力 | 同口径报价排名、与历史/目标价差异 | 报价台账 |
| 供应稳定性 | 准交表现、产能、断供和单一依赖 | 到货、供应商台账 |
| 交付风险 | 承诺/实际交期、延期次数及业务影响 | 订单、到货记录 |
| 质量风险 | 验收、不合格、整改和复发 | 质量异常记录 |
| 现金流支持 | 预付比例、账期和MOQ占款 | 合同、付款条件 |
| 替代能力 | 合格备选数量及切换条件 | 供应商开发资料 |

数据不足时不得直接判定稳定性或风险等级；合作建议不能只依据低价。

### 步骤6：经营价值输出

老板摘要依次输出：

1. 本期已实现节约、年度预计节约、净经营收益。
2. 单位成本、单位毛利、毛利率和年度毛利影响；缺销售价格时标注待确认。
3. 单一供应、交期、质量、MOQ、账期和切换风险。
4. 对排产、上市、补货、收入确认和客户交付的支持。
5. 谈价、锁价、替代开发、账期谈判、MOQ优化、质量整改动作。
6. 需决策方案、预计收益、风险、责任人和截止日期。

## 六、质量控制

- 不同规格、币种、税费、运费和数量梯度不得直接混比。
- 负数、零价、赠品、样品、冲销及异常记录单独处理。
- 所有结论保留来源和口径。
- 未经确认不得写入正式降本台账或供应商评级。
