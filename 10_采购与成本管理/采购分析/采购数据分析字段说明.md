# 采购数据分析字段说明

任务编号：AI-20260810-001

## 一、字段分层

- P0必填：缺失时无法完成核心价格或节约测算。
- P1必填：缺失时无法完成供应商、交付或现金流判断。
- P2建议：用于提高经营分析深度。
- 计算字段：由标准公式产生，不直接补录。

## 二、采购订单字段

| 字段 | 层级 | 类型/格式 | 说明 |
|---|---|---|---|
| 订单号 | P0 | 文本 | 采购订单唯一编号 |
| 采购日期 | P0 | YYYY-MM-DD | 订单确认日期 |
| 供应商名称 | P0 | 文本 | 与供应商主数据一致 |
| 物料编码 | P0 | 文本 | 物料唯一编码 |
| 物料名称 | P0 | 文本 | 原料、包材、成品或服务名称 |
| 类别 | P0 | 枚举 | 原料、包材、OEM/ODM成品、服务 |
| 规格型号 | P0 | 文本 | 价格可比的必要条件 |
| 采购数量 | P0 | 数值 | 必须大于0；退货/冲销单独标识 |
| 计量单位 | P0 | 文本 | kg、个、套等 |
| 采购单价 | P0 | 数值 | 当前订单单位价格 |
| 币种 | P0 | 文本 | CNY等 |
| 含税状态 | P0 | 枚举 | 含税、未税 |
| 税率 | P0 | 百分比 | 未涉及则填写0并说明 |
| 运费口径 | P0 | 枚举 | 含运费、不含运费 |
| MOQ | P1 | 数值 | 最小起订量 |
| 承诺交期 | P1 | 日期/天数 | 区分日期或周期 |
| 实际到货日期 | P1 | YYYY-MM-DD | 用于准交判断 |
| 付款周期 | P1 | 文本/天数 | 预付比例、节点或账期 |
| 质量验收状态 | P1 | 枚举 | 未验、合格、不合格、让步接收 |
| 订单状态 | P1 | 枚举 | 计划、执行中、到货、关闭、取消、待核销 |
| 数据来源 | P0 | 文本/路径 | 系统或文件来源 |
| 备注 | P2 | 文本 | 异常及特殊口径 |

## 四、年度需求字段

| 字段 | 层级 | 说明 |
|---|---|---|
| 年度预计采购量 | P0（年度测算） | 经确认的全年或剩余年度数量 |
| 数量预测期间 | P0（年度测算） | 全年、剩余年度或指定期间 |

## 六、计算字段

| 字段 | 公式/规则 |
|---|---|
| 当前采购金额 | 当前采购单价×当前采购数量 |
| 价格变化额 | 当前采购价格－历史可比价格 |
| 价格变化率 |（当前采购价格－历史可比价格）÷历史可比价格×100% |
| 单位节约 | 历史可比价格－当前采购价格 |
| 单项节约金额 |（历史可比价格－当前采购价格）×当前采购数量 |
| 年度预计节约金额 |（历史可比价格－当前采购价格）×已确认年度预计采购数量 |
| 历史加权平均价 | Σ（历史单价×历史数量）÷Σ历史数量 |
| 准交率 | 准时交付次数÷有效交付总次数×100% |
| 质量合格率 | 合格批次÷有效验收总批次×100% |
| 净经营收益 | 节约金额－新增物流、损耗、一次性投入和切换成本 |

## 七、数据校验规则

1. 数量、单价和税率必须为有效数值。
2. 历史价格为0或缺失时不得计算变化率。
3. 规格、币种、税费、运费或数量梯度不同，先标准化或标注不可比。
4. 重复订单按订单号、物料编码和订单行号识别。
5. 零价、负数、赠品、样品、退货、冲销和待核销记录单独分类。
6. 年度预计数量没有来源或确认记录时标注待确认。
7. 供应商稳定性、风险和等级必须有交付、质量或风险记录支撑。
8. 所有结果保留原始来源、分析期间和口径版本。
