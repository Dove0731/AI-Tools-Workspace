# OEM订单成本核算与毛利复核SOP V1.0

> 文件状态：**试运行版，可直接执行**  
> 适用范围：OEM/ODM报价、打样、接单、下单、量产、出货及订单复盘  
> 生效日期：2026-07-15  
> 流程负责人：财务/成本负责人（姓名待确认）  
> 业务负责人：OEM销售/项目负责人（姓名待确认）  
> 执行台账：[OEM订单成本复核与异常台账](./OEM订单成本复核与异常台账.md)  
> 关联规则：[成本核算模型](../成本核算模型.md)、[询价比价规则](../询价比价规则.md)

## 1. 目的

防止因成本明细缺项、单位错误、税率口径不一致、公式引用错误、数量或损耗错误、价格变更未重算等原因，导致OEM订单报价毛利与实际毛利严重偏离。

标准闭环：

`订单需求确认 → BOM及成本来源收集 → 初算 → 独立复核 → 毛利反算 → 报价审批 → 订单锁版 → 量产前重算 → 出货前复核 → 结单后实际毛利复盘`

任何阶段未通过毛利门禁，不得自动进入下一阶段。

## 2. 本次案例触发

| 项目 | 已知事实 | 状态 |
|---|---|---|
| 原计划毛利率 | 30% | 用户提供 |
| 实际毛利率 | 7.5% | 用户提供 |
| 毛利率偏差 | -22.5个百分点 | 按30%-7.5%计算 |
| 产品 | `ZC-Q-H-0003` 正彩水杨酸去黑头面膜膏120g | 用户补充 |
| 错误成本 | 1.51236元/瓶 | 用户补充 |
| 实际成本 | 2.021元/瓶 | 用户补充 |
| 订单数量 | 10,000瓶 | 用户补充 |
| 单位成本少计 | 0.50864元/瓶 | 2.021-1.51236 |
| 利润差额 | 5,086.40元 | 0.50864×10,000 |
| 已知原因 | 成本明细表计算错误 | 用户提供 |
| 具体错误公式/单元格 | 未提供 | 待确认 |
| 客户、订单号、订单阶段 | 未提供 | 待确认 |

在销售价格、税费和其他成本不变的前提下，本案成本差异校验为：

`利润差额 =（2.021 - 1.51236）× 10,000 = 5,086.40元`

如需用毛利率偏差做第二次校验，在销售收入和含税/未税口径一致的前提下：

`预计毛利损失 = 同口径销售收入 ×（30% - 7.5%）= 同口径销售收入 × 22.5%`

销售收入尚未提供，因此暂不能用“销售收入×22.5%”复核5,086.40元是否与毛利率偏差完全一致。

## 3. 角色与职责

| 角色 | 责任 | 不得代替的审核 |
|---|---|---|
| OEM销售/项目负责人 | 提供客户、产品、规格、数量、报价、交付和付款条件 | 不得自己编制后自己最终批准成本 |
| 产品开发/研发 | 提供最终配方、规格、BOM、打样和变更信息 | 不得口头变更BOM而不留版本 |
| 采购 | 提供原料、包材、加工、物流、模具/版费的有效报价和MOQ | 不得用过期报价或估计价替代正式来源 |
| OEM工厂/生产 | 提供加工费、损耗、良率、最小批量和异常成本 | 不得在量产后才补报固定费用 |
| 财务/成本 | 建立成本口径、独立复算、验证公式、审核毛利和现金影响 | 必须独立于首次编制人复核 |
| 品质/法规 | 提供检测、备案、质量放行和异常预留成本 | 不得遗漏必要测试、资料和返工风险 |
| 部门负责人 | 审批低于目标毛利、数据缺失或特殊战略订单 | 必须写明批准理由、风险上限和补救动作 |
| 张总/经营批准人 | 审批重大低毛利、重大投入或战略例外 | 不承担基础成本整理和公式检查 |

## 4. 统一成本与毛利口径

### 4.1 收入口径

同一张成本表只能选用一种口径：

- 含税收入与含税成本比较；或
- 不含税收入与不含税成本比较。

税率、币种、汇率、单位和数量必须在表头明确。不得用含税售价减未税成本直接计算毛利。

### 4.2 OEM订单全成本

`OEM订单全成本 = 原料 + 内料/半成品 + 直接包材 + 外包装 + 加工/灌装 + 人工/工费 + 损耗 + 检测/备案/资料 + 模具/版费分摊 + 物流 + 税费差异 + 客户专属费用 + 质量/返工预留 + 其他已确认费用`

是否纳入平台费、销售佣金、促销、样品、仓储、融资或管理分摊，由公司财务口径确认；未确认时必须单列，不得默认忽略。

### 4.3 标准公式

- `单位全成本 = 订单全成本 ÷ 预计合格出货数量`
- `订单毛利额 = 同口径销售收入 - OEM订单全成本`
- `订单毛利率 = 订单毛利额 ÷ 同口径销售收入`
- `目标成本上限 = 同口径销售收入 ×（1 - 目标毛利率）`
- `最低报价单价 = 单位全成本 ÷（1 - 目标毛利率）`
- `毛利率偏差 = 复核毛利率 - 批准目标毛利率`
- `成本偏差 = 最新全成本 - 已批准全成本`

最低报价公式只适用于毛利率按销售收入计算且税费口径一致的情况。

## 5. 成本明细必填项

| 类别 | 必填字段 | 来源 |
|---|---|---|
| 订单 | 客户、产品、规格、订单数量、合格出货数量、币种、交期 | 客户订单/合同 |
| 收入 | 含税/未税售价、税率、销售收入、付款方式、账期 | 报价单/合同 |
| 原料 | 名称、规格、单位用量、损耗率、采购价、税率、MOQ | BOM、采购报价 |
| 包材 | 内外包材、数量、损耗、单价、模具/版费、MOQ | BOM、包材报价 |
| 加工 | 打样、配制、灌装、组装、包装、人工和最低加工费 | 工厂报价 |
| 质量法规 | 检测、备案、资料、抽检、留样、返工预留 | 品质/法规确认 |
| 物流 | 原料、包材、成品运输及特殊储运 | 物流报价/历史结算 |
| 分摊 | 模具、版费、检测及一次性费用的分摊数量和规则 | 财务确认 |
| 变更 | 配方、BOM、供应商、价格、数量、交期变更及生效日 | 变更单 |
| 复核 | 编制人、复核人、批准人、版本号、日期 | 审批记录 |

任何必填项为空，状态只能为“待确认”，不得显示“成本已完成”。

## 6. 八道流程门禁

### Gate 1：订单与报价条件确认

| 必须确认 | 通过标准 | 未通过处理 |
|---|---|---|
| 产品规格、数量、客户交期、税率、币种、付款和报价有效期 | 订单和报价条件有书面来源 | 不启动正式成本计算 |

### Gate 2：BOM与成本来源齐套

| 必须确认 | 通过标准 | 未通过处理 |
|---|---|---|
| 配方/BOM版本、供应商报价日期、MOQ、损耗、加工和一次性费用 | 每项成本可追溯到BOM、报价或批准依据 | 只能出“临时测算”，不得对外承诺 |

### Gate 3：首次成本计算

编制人完成成本明细，必须检查：

1. 单位换算是否一致，如kg/g、箱/个、套/片；
2. 采购价、用量、数量、损耗和分摊公式是否覆盖全部行；
3. 求和范围是否遗漏新增行或隐藏行；
4. 是否存在手工覆盖公式、硬编码结果、错误绝对/相对引用；
5. 税率、币种和含税/未税口径是否一致；
6. 合格出货数量是否扣除合理损耗，而不是只用投产数量。

### Gate 4：独立复核与三重校验

首次编制人以外的财务/成本人员必须完成：

1. **逐项加总校验：** 从原料、包材、加工等明细重新汇总全成本；
2. **反算校验：** 用目标毛利率反算目标成本上限和最低报价；
3. **数量校验：** 用订单总成本、单位成本和数量互相反算，确认三者一致。

复核人不得只查看表格最终显示的毛利率。

### Gate 5：报价与接单审批

| 情形 | 处理要求 |
|---|---|
| 复核毛利率达到已批准目标且数据完整 | 进入报价审批 |
| 复核毛利率低于目标 | 调价、降本、改规格、谈MOQ/账期或提交例外审批 |
| 关键成本为估算/缺失 | 报价必须注明条件和有效期；未经批准不得转正式订单 |
| 战略低毛利订单 | 写清客户价值、后续收益、投入上限、风险和退出条件，由指定批准人签字 |

销售不得先承诺价格，再要求成本表“倒算到目标毛利”。

### Gate 6：订单锁版与变更重算

订单确认后冻结：客户版本、售价、数量、BOM、成本表、供应商报价和审批记录。

以下变化必须重新计算并审批：

- 配方、原料、包材、规格或供应商变化；
- 订单数量、MOQ、损耗、加工费或物流变化；
- 汇率、税率、账期或客户价格变化；
- 质量返工、加急、补料、补货或报废。

### Gate 7：量产前和出货前复核

| 时间点 | 检查内容 | 未通过处理 |
|---|---|---|
| 量产前 | 最新BOM、采购价、实际下单量、损耗、工费、一次性费用 | 毛利低于目标时暂停量产或例外审批 |
| 出货前 | 实际合格数量、实际采购/加工费用、返工报废、物流和客户售价 | 毛利异常立即升级；不得等结单后才发现 |

### Gate 8：结单后实际毛利复盘

出货、结算和主要费用入账后，复盘：

- 预计毛利与实际毛利差异；
- 差异来自价格、数量、用量、损耗、质量、返工、物流、税费还是公式；
- 是否影响客户报价、供应商策略和同类订单；
- 是否需要追溯使用同一模板、BOM或报价的其他订单；
- 形成纠正措施、责任人、完成日期和模板升级记录。

## 7. Excel/成本表防错控制

1. 输入单元格、公式单元格、审核单元格使用不同颜色并设置图例。
2. 公式区域锁定保护，普通使用人不得手工覆盖。
3. 禁止在合计区域使用固定数字替代公式。
4. 新增成本行必须自动纳入汇总范围；模板发布前用首行、末行和新增行测试。
5. 设置校验字段：明细合计与总成本差额必须为0。
6. 设置毛利反算字段：目标成本上限与实际全成本自动比较。
7. 设置异常提示：成本缺项、负数、单位为空、税率为空、毛利低于目标时显示阻断状态。
8. 隐藏行、隐藏列、外部链接和手工粘贴公式必须列入复核检查。
9. 文件命名统一为：`客户_产品_数量_成本核算_V版本_日期_状态.xlsx`。
10. 已批准版本只读归档；修改必须升级版本号并保留变更说明。

## 8. 本案应急处理

| 优先级 | 动作 | 建议责任人 | 时限 | 验收标准 |
|---|---|---|---|---|
| P0 | 停止继续使用错误成本表及其复制版本 | 财务/成本负责人 | 立即 | 文件标记停用，使用人收到通知 |
| P0 | 锁定本单报价、合同、BOM、成本表和实际费用 | OEM项目负责人+财务 | 当日 | 可还原30%和7.5%的完整计算链 |
| P0 | 定位具体错误单元格、公式、来源和发生环节 | 成本编制人+独立复核人 | 1个工作日 | 根因可复现，不只写“操作失误” |
| P0 | 计算订单绝对毛利损失及尚未发生的风险敞口 | 财务 | 1个工作日 | 明确销售收入、全成本、毛利额和差异金额 |
| P0 | 批量复核使用同模板、同BOM或同编制逻辑的OEM订单 | 财务+销售+采购 | 2个工作日形成首版 | 订单范围、偏差、状态和补救动作完整 |
| P1 | 发布修正版成本模板并锁定公式 | 财务/成本负责人 | 2个工作日 | 通过故意错行、漏行、换单位测试 |
| P1 | 对未报价/未生产/在产/已出货订单分类处理 | 部门负责人 | 2个工作日 | 每单形成调价、降本、暂停、例外或损失控制结论 |

## 9. 异常升级

| 发现阶段 | 必须动作 |
|---|---|
| 对外报价前 | 停止报价，修正后重新审批 |
| 客户已接受但未下单 | 重新报价或调整规格/成本，保留客户沟通记录 |
| 已下单未量产 | 暂停采购/排产，评估调价、降本、数量和退出成本 |
| 已量产未出货 | 立即核算剩余可控成本，评估返工、物流和交付方案 |
| 已出货 | 核实实际损失、回款和后续订单价格，形成专项复盘 |
| 同类模板可能受影响 | 扩大至100%订单复核，不得只修当前一单 |

## 10. SOP验收指标

| 指标 | 口径 | 目标 |
|---|---|---:|
| 成本来源完整率 | 有来源成本项/全部成本项 | 100% |
| 独立复核率 | 已独立复核订单/正式报价订单 | 100% |
| 公式校验通过率 | 三重校验通过订单/审核订单 | 100% |
| 变更重算率 | 已重算变更订单/应重算订单 | 100% |
| 低于目标毛利审批率 | 有例外审批订单/低于目标毛利订单 | 100% |
| 实际毛利复盘率 | 已复盘结单订单/应复盘订单 | 100% |

具体目标毛利率、容差和审批权限由公司确认，不在SOP中编造。

## 12. 关联报价规则

本SOP负责确认“成本是否正确、毛利底线是否满足”；冻干粉按订单数量形成标准对外报价、统一版本及例外审批，按[OEM冻干粉数量分层报价与自动核价SOP V1.0](../报价比价/OEM冻干粉数量分层报价与自动核价SOP_V1.0.md)执行。成本底价不得直接替代数量阶梯标准报价。
