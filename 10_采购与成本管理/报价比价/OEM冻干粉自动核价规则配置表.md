## 三、核价输入输出映射

| 字段 | 类型 | 来源/公式 | 缺失处理 |
|---|---|---|---|
| 产品编码、规格 | 输入 | 报价申请 | 禁止报价 |
| 预计合格出货数量 | 输入 | 客户需求/订单 | 禁止报价 |
| 客户、税率、币种、运费、账期、交期 | 输入 | 报价条件 | 标“待确认”，禁止正式报价 |
| 基础成本 | 查表 | 按产品+有效日期匹配成本基线 | 禁止报价 |
| 数量阶梯 | 查表 | 按产品+数量+有效日期唯一命中 | 0个或多个命中均禁止报价 |
| 数量调整后全成本 | 公式 | `C_base + F/Q + C_qty + C_other` | 任一成本缺失则禁止报价 |
| 毛利底价 | 公式 | `C_full/(1-G_target)` | 目标毛利缺失则禁止报价 |
| 标准报价 | 公式 | `MAX(P_floor,P_tier)` | 不允许手工覆盖 |
| 报价状态 | 公式 | 字段、版本、阶梯、毛利及审批校验 | 显示禁止原因 |

### 数量命中规则

| 数量 | 处理 |
|---:|---|
| 低于10,000 | 禁止自动报价，转人工审核/MOQ确认 |
| 10,000—29,999 | 命中第一档最新有效单价 |
| 30,000—49,999 | 命中第二档最新有效单价 |
| 50,000—99,999 | 命中第三档最新有效单价 |
| 100,000—199,999 | 命中第四档最新有效单价 |
| 200,000—499,999 | 命中第五档最新有效单价 |
| 500,000及以上 | 不返回标准价，状态显示“人工审核” |
