# 成本核算模型

## 基础模型

产品成本 = 原料成本 + 包材成本 + 加工成本 + 检测/资料成本 + 物流 + 损耗 + 其他费用

## 核算表

| 成本项 | 金额 | 口径 | 来源 | 备注 |
|---|---:|---|---|---|
| 原料成本 | 待确认 | 含税/未税 |  |  |
| 包材成本 | 待确认 | 含税/未税 |  |  |
| 加工成本 | 待确认 |  |  |  |
| 物流 | 待确认 |  |  |  |
| 损耗 | 待确认 |  |  |  |
| 其他 | 待确认 |  |  |  |

## 分析要求

- 说明含税/未税。
- 说明数量口径。
- 说明是否含物流、损耗、MOQ。
- 判断对毛利和报价成交的影响。
