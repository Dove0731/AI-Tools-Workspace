# 金蝶云星空操作手册

> 版本：V1.0（试行）  
> 建立日期：2026-07-15  
> 适用部门：开发部、采购开发部、采购跟单部、研发、财务、仓库及相关生产工厂  
> 适用范围：物料编码、物料主数据、BOM、组织分配、采购/生产衔接、收料、退料、调拨及主数据维护  
> 文件状态：已按现有资料建立统一处理逻辑；第 14 节所列冲突口径须由业务负责人确认后转为正式制度。

## 1. 结论与执行原则

金蝶操作必须执行“先核需求、再查重、后编码；先主数据、后 BOM；先审核、后分配；业务变更必须同步系统”的顺序。任何人不得仅凭群消息、旧截图或相似产品直接新增、修改或停用编码。

本手册建立六道控制门：

1. **需求完整门**：品名、规格、品牌/客户、生产方式、组织、单位、包材清单、配方状态、成本和交期等关键字段齐全。
2. **编码查重门**：在目标组织及相关组织中按编码、名称、规格、别名查询，确认没有可复用物料。
3. **主数据校验门**：编码、名称、规格、物料分组、属性、基本单位、存货类别、税率、生产组织等字段相互一致。
4. **BOM 齐套门**：子项、用量、单位、损耗、货主、组织、版本、生效日期完整，配方由研发维护。
5. **单据执行门**：保存、提交、审核完成后，才能分配、下单、推送收料或进入生产。
6. **变更闭环门**：包装、配方、工厂、箱规、货主或单位变化时，同步更新物料、BOM、订单及变更记录。

## 4. 端到端流程

### 4.1 标准流程

`接收需求 → 完整性检查 → 系统查重 → 确认编码规则 → 新增物料 → 保存 → 提交 → 审核 → 按组织分配 → 建立 BOM → 研发维护配方 → BOM 校验/审核 → 下单 → 收料/生产 → 上市或交付 → 变更维护`

### 4.2 需求不完整时

缺少以下任一关键字段，不得进入编码：

- 品牌或客户归属、产品名称、规格/净含量、基本单位；
- 自主生产、委外全包、半包委外、外购或客供的生产模式；
- 目标组织、实际生产工厂、货主；
- 包材组成、通用/专用判断、是否直接销售；
- 配方号或现货生产编码、配方是否确版；
- 批号/日期要求、箱规、计划数量、需求日期；
- 特殊产品属性、医械后缀、客户保密命名要求。

处理动作：当天退回发起人补充，并在交接记录中写明缺失字段、责任人和补充时限。

## 5. 编码建立规则

### 5.1 编码前查重

至少执行四种查询：

1. 按拟用编码完整查询；
2. 按产品/物料名称关键字查询；
3. 按规格、品牌或客户代号组合查询；
4. 在七遇、百媚、云浮、千娇、万妍、展欣等相关组织查询可复用记录。

名称相近但规格、材质、工艺、单位、货主或用途不同，不得直接复用。完全一致的物料原则上复用现有编码，不重复建档。

### 5.2 主产品编码

| 场景 | 编码结构 | 名称规则 | 示例 |
|---|---|---|---|
| 七遇自有品牌 | `品牌-属性-单位-流水号` | 备案名称+净含量 | `ZC-L-Z-0004 正彩紫苏壬二酸去角质啫喱100g` |
| 七遇客户定制 | `OEM-品牌-属性-单位-流水号` | 备案名称+净含量；保密客户按客户代号命名 | `OEM-HS-L-P-01 海氏海诺硫磺沐浴露500g` |
| 七遇外购品 | `品牌-属性-单位-流水号` | 证件/确认名称+净含量 | `NP-G-H-001 奈派草本植萃祛痘膏30g` |
| 万妍 | `WY-品牌-属性-单位-流水号` | 备案名称+净含量 | 具体流水号以系统查重结果为准 |
| 千娇相关下单 | `QY/SE/QJ-品牌-属性-单位-流水号` | 证件名称+净含量 | 前缀按实际下单主体确认 |
| 展欣 | `ZX-品牌-属性-单位-流水号` | 备案名称+净含量 | 在七遇系统建档并按规则分配 |
| 耗材 | `HC-物品缩写-流水号` | 物品名称+规格 | `HC-BQ-0001 热敏纸标签纸30*20*1000` |

流水号必须从系统现有最大有效号码顺延，不得凭记忆填写。

### 5.3 专用包材编码

专用包材采用 `主产品编码-包材后缀`，名称采用 `主产品名称-包材名称`。

| 后缀 | 包材 | 默认单位 |
|---|---|---|
| `P` | 瓶子 | 个 |
| `T` | 泵头/刷头 | 个 |
| `G` | 盖子/刮板 | 个；同一产品发生歧义时须确认 |
| `S` | 内塞 | 个；与“勺子”冲突，见第 14 节 |
| `H` | 盒子/彩盒 | 个 |
| `N` | 内托 | 个 |
| `WD` | 外袋 | 个 |
| `R` | 软管、铝塑管、塑料管 | 个 |
| `X` | 吸嘴袋 | 个 |
| `J` | 不干胶 | 张 |
| `GB` | 刮板烟包膜 | 按实际确认 |
| `D` | 手拉垫 | 个 |
| `W` | 碗+刷子 | 套 |
| `BZX` | 标准箱 | 个 |
| `K` | 卡纸 | 个 |
| `LB` | 喇叭头 | 个 |
| `GM` | 盖膜 | kg |
| `DM` | 底膜 | kg |
| `F` | 封口贴 | 个 |

示例：`ZC-L-Z-0004-R 正彩紫苏壬二酸去角质啫喱100g-软管`。

### 5.4 通用包材编码

通用包材采用 `品牌-物品缩写-流水号` 或 `TY-物品缩写-流水号`。只有经过确认确实可跨产品共用，且材质、尺寸、工艺、供应商限制和质量标准一致时，才可使用通用编码。

已有示例包括：

- `品牌-LB-01`：铝箔袋；
- `品牌-MB-01`：膜布；
- `品牌-JM-01`：卷膜；
- `TY-YB-001`：烟包膜；
- `TY-SS-001`：收缩膜；
- `TY-ZZ-001`：周转箱；
- `TY-FX-001`：封箱胶。

直接销售包材可按供应商成套包材建立一个物料；成品 BOM 必须按实际组成拆分，不得把成套采购逻辑直接替代生产 BOM 明细。

### 5.5 特殊产品与保密客户

- 医用退热贴、械一面膜：系统名称后缀使用 `YYXY`。
- 医用敷料、医用敷贴、械二面膜：系统名称后缀使用 `YYXE`。
- 特殊类型名词是否体现在系统名称中，按法规及现行命名规则执行；不得只照搬市场名称。
- 特殊客户产品以客户代号替代实际品牌名称；客户代号必须有受控对应表，禁止在普通名称字段泄露客户信息。

## 6. 物料主数据操作

### 6.1 点击路径

进入目标组织后，打开 `物料列表 → 新增`；录入完成后依次执行 `保存 → 提交 → 审核`。需要跨组织使用的，再执行 `业务操作/分配`。

### 6.2 必填及强校验字段

| 字段 | 处理规则 | 校验点 |
|---|---|---|
| 创建组织/使用组织 | 必须与目标账套及业务主体一致 | 不得在错误组织建档 |
| 编码 | 按第 5 节生成并查重 | 不重复、不跳用无依据流水号 |
| 名称 | 证件/备案/合同确认名称+规格 | 与编码、规格及保密规则一致 |
| 规格型号 | 净含量、尺寸或合同规格 | 不使用含糊简称 |
| 物料分组 | 成品、包材、耗材、原料或对应业务分组 | 与业务用途一致 |
| 物料属性 | 自制、外购或委外 | 与生产模式一致 |
| 基本单位 | 按实际收发和 BOM 使用单位 | 与合同、仓库和 BOM 一致 |
| 存货类别 | 成品、委外半成品或原材料等 | 与财务核算口径一致 |
| 允许业务 | 采购、销售、库存、生产/委外按需勾选 | 不多勾无关业务 |
| 税率/税分类 | 由财务确认 | 截图中的 13% 仅是历史示例，不作为固定税率 |
| 厂/生产部门 | 按实际承接工厂和车间 | 不得沿用相似产品默认值 |
| 同步旺店通 | 云仓耗材等确需同步的物料选择“是” | 未确认不得勾选 |
| 分类字段 | 一级、二级、三级分类及成品类别 | 采用现行系统字典 |
| 毛重/净重/箱规/单品尺寸 | 入库或实测后补全 | 补录要有仓库/实物依据 |

### 6.3 不同物料的建议口径

| 类型 | 物料分组 | 物料属性 | 存货类别 | 基本单位 | 其他控制 |
|---|---|---|---|---|---|
| 自主生产成品 | 成品 | 自制 | 产成品 | 盒/支/瓶等 | 允许销售、库存、生产 |
| 委外成品 | 成品 | 委外 | 产成品 | 实际销售单位 | 明确委外工厂及成品类别 |
| 委外半成品 | 对应产品组 | 委外 | 委外半成品 | 实际单位 | 明确生产组织 |
| 专用/通用包材 | 包材 | 外购 | 原材料 | 个/张/kg/套 | 单位必须与采购及 BOM 一致 |
| 耗材 | 耗材 | 外购 | 原材料或财务确认类别 | 实际单位 | 云仓使用时核实旺店通同步 |
| 外购成品 | 成品 | 外购 | 产成品 | 实际销售单位 | 核合同名称、规格和箱规 |

## 7. 多组织建立与分配

| 业务场景 | 建档组织 | 分配要求 | 特殊说明 |
|---|---|---|---|
| 七遇自主/客户定制/外购 | 七遇系统 | 审核后按实际业务分配百媚、云浮 | 只分配实际需要的组织 |
| 七遇委外至万妍 | 先建七遇编码 | 再按万妍规则建/使用对应编码 | 建立编码映射关系 |
| 七遇委外至展欣 | 七遇系统 | 物料分配展欣；BOM 货主选展欣并分配展欣 | 分配前核实货主和组织 |
| 千娇、万妍本组织业务 | 对应系统 | 资料显示通常不执行七遇式分配 | 以当前权限和组织规则为准 |

组织编号和仓库映射会随系统配置变化，手册保留业务名称，不将历史截图中的编号作为永久规则。操作前以当前系统组织名称为准。

## 8. BOM 建立与维护

### 8.1 建立前条件

- 父项成品物料已审核；
- 所有专用/通用包材物料已审核；
- 生产模式、实际工厂、货主和配方状态已确认；
- 纸箱尺寸、箱规、包材工艺、单价及大货文件已核对；
- 新包材已完成容量、真空、兼容性或其他必要测试。

### 8.2 点击与字段逻辑

进入 `物料清单列表 → 新增`，录入：

- BOM 版本：初版按现行规则建立，示例为 `V1.0`；
- 单据类型：物料清单；
- BOM 分类：标准 BOM；
- BOM 用途：通用；
- 父项物料编码及父项单位；
- 子项物料编码、用量分子/分母、子项单位、子项属性、子项类型；
- 货主类型、货主；
- 固定/变动损耗率；
- 生效日期。

录入后执行 `保存 → 提交 → 审核 → 按需分配`，再通知研发维护配方。

### 8.3 BOM 业务规则

1. 成品 BOM 按实际物理组成拆分包材，不得因供应商整套报价而合并生产子项。
2. 配方原料及用量由研发维护，开发不得凭旧 BOM 自行复制为确版配方。
3. 包材单位、BOM 单位和采购单位不一致时，必须建立明确换算关系；无法换算时停止下单。
4. 客供包材的货主类型选“客户”，货主选择对应客户；客户编码由财务建立。
5. 自有物料的货主类型按业务组织处理，展欣业务按已确认规则选择展欣并完成分配。
6. 纸箱、包材、配方或用量变更时，必须同步修改 BOM；生效日期不得晚于实际跑单日期。
7. 历史已生产版本不得无痕覆盖。变更必须记录旧值、新值、原因、影响订单和生效日期。
8. BOM 完成后必须进行“父项—子项—单位—用量—货主—组织—生效日”七项复核。

## 9. 采购、生产、收料及退料衔接

### 9.1 采购订单

接收订单后，核对名称、编码、数量、单价、单位、含税/运费、交期、收料组织和合同。系统录入错误会影响后续收料、财务结算和上下游单据，故采购订单提交前必须由经办人自检，关键订单由复核人二次检查。

### 9.2 生产/委外订单

- 下单前确认最新大货文件、批号/日期格式、纸箱尺寸、箱规、包材单价及 BOM 完整性。
- 自主生产按已审核 BOM 下生产订单。
- 完全委外原则上建立委外成品主编码并按实际业务下委外订单；如无自带物料，可不拆自有生产 BOM。
- 半包委外或自带包材委外必须建立 BOM，把公司提供的物料列入子项并正确设置货主。
- 百媚转委外或更换生产工厂时，先确认应选 BOM，再执行转单/改厂，不得只改群通知。

### 9.3 收料通知

- 原料、包材和成品到货前，按实际生产工厂推送收料通知。
- 收料组织必须与采购订单、货主和实际收货工厂一致。
- 云仓耗材或成品需传旺店通时，核对使用组织、收料组织、收料仓库及同步状态。
- 直发客户的成品按现行物流专用仓及客服/销售出库流程处理，必须保留入库和销售出库闭环。

历史资料中出现的组织编号仅作线索：七遇、百媚、云浮、千娇、万妍、展欣的现行编号和仓库名称须在首次执行前由系统管理员确认。

### 9.4 到货异常与退料

到货不良或数量异常时，当天完成：

1. 仓库冻结异常数量并留存照片、批次和检验结果；
2. 采购联系供应商确认补货、返工、折让或退货方案；
3. 需退货时在金蝶建立退料申请/退货相关单据；
4. 核对系统退料数量与实物退回数量；
5. 月结前检查供应商账单是否扣减；
6. 异常同步问题闭环台账，避免账实和应付不一致。

### 9.5 样品调拨

资料中已有流程为：`调拨开单 → 复制出库外部单号发群 → 建手工单并发送出库单编号 → 样品到公司后做调拨入库`。实际使用前须补充确认来源组织、目标组织、仓库、物料编码和数量；任一项不清不得调拨。

## 10. 变更、禁用与删除

已审核或已发生业务的编码原则上不删除，采用禁用或版本变更：

1. 发起部门提交变更/禁用原因及影响范围；
2. 编码管理员查询库存、未结采购单、生产单、BOM、销售及财务影响；
3. 有库存或未结单据时，先形成处置方案，不直接禁用；
4. 修改包装、纸箱或配方时同步更新 BOM；
5. 确认无继续使用场景后执行禁用；
6. 在变更台账记录旧编码/旧值、新编码/新值、责任人、审批人和生效日。

禁止通过“改名复用旧编码”解决新物料需求。

## 11. 质量门与自检清单

### 11.1 物料审核前

- [ ] 需求字段齐全，来源可追溯；
- [ ] 已跨组织查重；
- [ ] 编码结构、流水号、名称和规格一致；
- [ ] 物料分组、属性、单位、存货类别一致；
- [ ] 税率和财务字段已确认；
- [ ] 工厂、生产部门和同步设置正确；
- [ ] 特殊产品/客户保密规则已执行。

### 11.2 BOM 审核前

- [ ] 父项和全部子项已审核；
- [ ] 专用包材与通用包材判断正确；
- [ ] 子项单位和用量可换算；
- [ ] 货主类型和货主正确；
- [ ] 配方由研发确认；
- [ ] 生效日期不晚于跑单日期；
- [ ] 箱规、纸箱、大货工艺和系统 BOM 一致。

### 11.3 下单前

- [ ] 最新大货文件已确认；
- [ ] 批号/日期格式已确认；
- [ ] 合同名称、数量、单价、含税运费和交期正确；
- [ ] BOM 与实际生产方式一致；
- [ ] 收料组织、仓库、货主和供应商正确；
- [ ] 特殊测试和配方状态满足量产条件。

## 12. 处理案例

### 案例 1：自有品牌自主生产新品

需求：正彩紫苏壬二酸去角质啫喱 100g，自主生产，使用软管。

处理：

1. 查重后建立主产品 `ZC-L-Z-0004`；
2. 建立软管 `ZC-L-Z-0004-R`，名称为主产品名称+软管；
3. 主产品物料属性选自制，软管选外购；
4. 审核后按实际工厂分配；
5. 建 BOM，列入软管、盖、盒、纸箱等实际子项；
6. 通知研发加入确版配方；
7. 七项复核通过后下单。

### 案例 2：客户定制且含客供包材

需求：OEM 产品，客户提供瓶、泵和盖，公司负责料体、彩盒和装配。

处理：

1. 按 OEM 编码规则建主产品；
2. 客供物料仍需有可识别物料编码，先查重；
3. 财务建立客户编码；
4. BOM 中客供子项的货主类型选客户，货主选对应客户；
5. 公司采购/提供的子项按业务组织设置货主；
6. 下单前核对客供数量、损耗和到料时间，避免影响齐套生产。

### 案例 3：完全委外成品

需求：供应商提供料体、包材和生产，公司直接采购成品。

处理：

1. 建立委外/外购成品主编码，属性按实际交易模式确认；
2. 核对供应商资质、名称、规格、合同、箱规、含税运费及检测备案费；
3. 原则上不建立公司自有生产拆分 BOM；系统必须要求 BOM 时，按委外业务配置处理并标记来源；
4. 推送收料通知，核对收料组织和仓库；
5. 到货异常按退料闭环处理。

### 案例 4：自带包材委外加工

需求：公司提供部分包材，委外工厂完成灌装和装配。

处理：

1. 建委外主编码；
2. 建 BOM，列出公司自带包材和料体；
3. 设置正确货主、供应组织、单位和损耗；
4. 确认物料已分配到承接工厂；
5. 下委外订单前检查公司物料是否齐套。

### 案例 5：展欣承接委外

处理：七遇系统先建物料并审核，随后分配展欣；BOM 货主按确认规则选展欣并分配展欣。任何一步缺失都会造成展欣无法正常领料或下单。

### 案例 6：包材从专用改为通用

不得直接修改原编码名称。先验证材质、尺寸、工艺、质量标准和可共用产品范围；确认可通用后新建/复用通用编码，变更相关 BOM，并处置原专用物料库存和未结订单。

### 案例 7：纸箱或包材临时变更

收到更改通知后，先确认设计和采购规格，再同步修改物料资料及 BOM。生效日期必须早于或等于跑单日期；已下订单需判断是否撤单、改料或分批切换，并记录库存风险。

### 案例 8：不良品退货影响月结

仓库确认不良数量后，当天建立退料申请并退回供应商；采购核对供应商账单是否扣减。未完成系统退料前，不得仅凭聊天记录扣账，避免账实不一致。

## 13. 异常升级机制

| 异常 | 立即动作 | 责任人 | 升级条件 |
|---|---|---|---|
| 编码重复/规则冲突 | 停止新增，截图并登记 | 开发/编码管理员 | 当天无法判定，升级部门负责人 |
| 单位或规格不一致 | 暂停审核/下单 | 开发+采购+仓库 | 影响合同或 BOM 换算时升级财务/负责人 |
| 货主或组织错误 | 暂停分配及单据执行 | 经办人 | 已产生下游单据，升级系统管理员+财务 |
| 配方/BOM 未确版 | 暂停生产下单 | 开发+研发 | 影响上市节点，升级项目负责人 |
| 到货异常 | 冻结、留证、退料/补货 | 仓库+采购 | 影响生产/交付或月结，当天升级 |
| 旧编码需禁用 | 查库存和未结单据 | 编码管理员 | 有库存或在途订单，升级部门负责人 |

## 14. 待确认口径与当前处理办法

以下问题在源文件中存在冲突或证据不足，未确认前不得擅自固化：

| 待确认事项 | 源文件表现 | 当前试行处理 |
|---|---|---|
| 后缀 `S` 重复 | 同时用于内塞和勺子 | 停止自动生成；按现有编码查重后交编码管理员裁定 |
| 后缀 `G` 重复 | 同时用于盖子和刮板 | 同一父项有歧义时不得直接使用，先确认扩展后缀 |
| 示例流水号不一致 | 主产品示例为 `ZC-M-H-0045`，子项却出现 `ZC-M-H-0005-*` | 认定为示例错误，不得照抄；以父项实际编码为准 |
| 千娇/万妍/展欣组织编号 | 不同截图和流程只给出局部编号 | 以当前系统组织名称和系统管理员确认为准 |
| BOM 初版及变更版本规则 | 示例出现 V1.0，但缺少完整版本制度 | 初版使用系统默认/确认版本；变更必须留痕，待补正式版本规则 |
| 固定税率 | 截图显示 13% 增值税 | 仅作历史示例，每次按财务有效税务口径处理 |
| 特殊产品名称隐藏规则 | 文档表述与法规名称可能不一致 | 上线前由法规确认系统名称、备案名称和销售名称的对应关系 |
