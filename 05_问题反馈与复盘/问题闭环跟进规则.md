# 问题闭环跟进规则

## 闭环必填内容

| 模块 | 要求 |
|---|---|
| 问题描述 | 写清发生了什么、涉及谁、涉及什么物料或项目 |
| 发生原因 | 未查清写“待确认”，不能猜成事实 |
| 影响范围 | 项目、订单、客户、供应商、库存、现金流 |
| 经营影响 | 成本、毛利、交期、质量、成交、收入确认 |
| 责任归属 | 内部、供应商、工厂、客户、待确认 |
| 临时措施 | 先止损或保障交付 |
| 长期预防措施 | 防止复发的流程、标准、台账或 SOP |
| 是否形成 SOP | 是/否/待确认 |

## 关闭标准

- 临时措施已执行。
- 根因已确认或明确待验证。
- 长期预防措施已安排责任人。
- 关闭证据已保存。
- 对供应商等级、项目计划或采购规则的影响已同步更新。
