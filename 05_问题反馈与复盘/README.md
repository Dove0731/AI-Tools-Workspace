# 05_问题反馈与复盘

## 目录用途

本目录用于沉淀采购、供应商、质量、交期、报价、成本和项目问题的复盘，推动问题闭环并形成可复用 SOP。

## 存放内容

- 采购异常、供应商延期、质量异常、报价异常、成本超标复盘模板。
- 问题分级规则和闭环跟进规则。
- 已确认的复盘记录和问题索引。

## 更新规则

- 发生影响成本、交期、质量、供应商稳定、现金流或客户交付的问题时必须记录。
- 复盘必须包含问题描述、原因、影响范围、经营影响、责任归属、临时措施、长期预防措施、是否形成 SOP。
- 未关闭问题必须同步到问题闭环台账。

## 使用方式

1. 根据问题类型复制对应复盘模板。
2. 先写清经营影响，再分析原因和责任。
3. 临时措施和长期预防必须分开写。
4. 关闭时补充关闭证据。
