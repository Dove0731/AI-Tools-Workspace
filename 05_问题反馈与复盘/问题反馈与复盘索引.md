# 问题反馈与复盘索引

问题进入本目录的标准：已经影响或可能影响成本、交期、质量、供应商稳定、库存、现金流、项目成交或上市节点。

公司级异常处理统一依据：[《异常问题处理闭环机制（试行）》公司公布版](../00_工作台与规则/公司制度/七遇集团异常问题处理闭环机制（试行）_公司公布版.docx)。具体异常必须同步登记责任人、节点、验证结果、标准沉淀和关闭证据。

| 类型 | 位置 | 必须写清 |
|---|---|---|
| 质量异常 | `01_质量异常协同` | 现象、批次/样品、原因、责任、复测、关闭 |
| 交期异常 | `02_交期异常` | 原计划、实际、影响项目、补救方案 |
| 成本异常 | `03_成本异常` | 涨价、报价差异、金额影响、谈判方案 |
| 供应商异常 | `04_供应商异常` | 供应商表现、分级影响、替代方案 |
| 项目复盘 | `05_项目复盘` | 目标、结果、偏差、经验、下次动作 |
| 复盘索引 | `06_复盘索引` | 复盘编号、主题、状态、关闭日期 |
