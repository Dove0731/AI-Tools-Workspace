# RP-202607-003 OEM冻干粉统一底价导致报价体系风险复盘

## 一、结论

本次不是单一价格录入错误，而是自动核价体系把“成本底价”和“对外报价”混在一起：冻干粉类目只有统一成本底价，没有按数量、固定费用分摊、目标毛利和商业条件形成阶梯报价。连续两次OEM案例分别暴露成本公式错误和报价逻辑缺失，说明风险已从个人操作上升为规则、系统和审批机制问题。

2026-07-20已取得自动核价表并完成只读审计：源表实际存在5档/6档冻干粉数量价格，但自动取价链断裂、两张规则表口径冲突，且全表45个单元格包含`#REF!`。已报价客户、成交数据和实际利润损失仍未取得，不能认定已经发生对外错报；当前风险等级建议P1，若发现客户已接受或订单已按低于毛利底线价格执行，则立即升级P0。

## 二、事实、判断与待确认

| 类型 | 内容 |
|---|---|
| 已知事实 | 用户反馈OEM核算表中冻干粉类目只有成本底价；即使通品成本可能一致，也应根据不同数量给出不同成本报价/销售报价；要求调整自动核价表 |
| 已知背景 | 前一OEM案例中，`ZC-Q-H-0003`错误成本1.51236元/瓶、实际成本2.021元/瓶、数量10,000瓶，利润差额5,086.40元；该案例的具体错误公式仍待定位 |
| AI判断 | 两案共同指向报价治理缺口：缺少唯一规则源、数量阶梯、毛利反算、独立复核、版本锁定和例外审批 |
| 待确认 | 哪组冲突单价为最新有效版本、价格生效日、历史数量、已报价/成交范围、实际利润影响、责任人及具体审批人 |

## 三、原因分析

| 层级 | 原因 | 证据状态 |
|---|---|---|
| 直接原因 | 冻干粉自动核价规则只有统一成本底价，没有数量阶梯报价 | 用户陈述；源表待补 |
| 规则原因 | 未明确成本底价、标准报价和例外成交价的边界 | 现有规则需补强 |
| 系统原因 | 已确认J列未自动命中阶梯、K3:K25毛利公式断链；是否有底价阻断及人工改价留痕仍待确认 | [源表审计](../../10_采购与成本管理/报价比价/2026-07-20_OEM自动核算报价源表审计.md) |
| 管理原因 | 报价参数、版本、审批和复核责任未形成唯一责任链 | 责任人待确认 |
| 数据原因 | 缺历史成交数量、订单固定费用、税费、运费、账期和实际毛利数据 | 待补 |

## 四、经营影响

1. 小数量订单若按统一底价报价，固定费用和服务成本可能无法回收。
2. 大数量订单若无正式阶梯策略，销售可能随意让价或失去有条件报价空间。
3. 同一产品、数量和交易条件出现不同报价，会造成内部相互压价、客户比价冲突和价格信用损失。
4. 报价不绑定版本和审批，会把毛利风险延后到下单、量产甚至结单后才发现。
5. 实际涉及客户数、订单数和利润金额待确认，当前不得补算。

## 六、关闭标准

本案同时满足以下条件才可关闭：

1. 自动核价表源文件、生产版本和使用范围明确。
2. 数量阶梯、目标毛利、税费口径和审批权限已批准。
3. 自动核价表完成调整并通过全部边界测试。
4. 旧版本已停用，人工改价被锁定或需审批。
5. 近期待生效及已生效冻干粉报价已100%复核并形成一单一结论。
6. 首批正式报价及订单实际毛利复盘无未关闭异常。
