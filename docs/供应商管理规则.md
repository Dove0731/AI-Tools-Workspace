# 供应商管理规则

## 分级标准

| 等级 | 定义 | 管理动作 |
| --- | --- | --- |
| A 类战略合作 | 质量稳定、交付可靠、价格有竞争力、开发能力强 | 优先导入新品和年度框架合作 |
| B 类常规合作 | 能满足日常采购，风险可控 | 正常合作，定期复盘 |
| C 类备选 | 可作为替代资源，但仍需验证 | 保留报价、样品和资质 |
| D 类暂停或淘汰 | 存在严重质量、交期、配合或诚信风险 | 停止新项目导入 |

## 评估维度

- 价格竞争力
- 质量稳定性
- 交付能力
- 配合度
- 账期支持
- 开发能力
- 资质文件完整性
- 历史异常记录
- 是否适合长期合作

## 准入资料

- 营业执照或合法经营资质
- 生产许可、认证或检测能力说明
- 主营品类和代表案例
- 产能、MOQ、交期、付款条件
- 质量管理方式
- 公开联系人和联系方式

## 风险预警

连续打样不通过、报价频繁变动、资料长期不齐、交期承诺失真、质量整改不积极、单一依赖过高、付款条件恶化时，应标记风险并准备替代供应商。
