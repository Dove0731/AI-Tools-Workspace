# 报价与成本分析规则

## 报价必须记录

- 报价日期、供应商、规格版本
- 数量梯度、单价、币种
- 是否含税、税率、是否含运费
- MOQ、交期、付款条件
- 报价有效期
- 打样费、模具费、版费、检测费、物流费
- 报价来源

## 成本拆解

| 成本项 | 内容 |
| --- | --- |
| 内容物 | 主料、辅料、香精、活性物、损耗 |
| 包材 | 瓶、泵、盖、软管、外盒、标签、纸箱 |
| 加工 | 灌装、组装、贴标、喷码、检验 |
| 合规 | 检测、备案、认证、留样 |
| 物流仓储 | 运输、仓储、二次配送 |
| 资金成本 | 预付款、账期、库存占用 |
| 异常成本 | 返工、报废、延期、客诉 |

## 优化金额

`优化金额 = 原方案单价 × 数量 - 新方案单价 × 数量`

如果存在 MOQ、物流、税费、损耗或付款周期变化，需单独说明净影响。

## 结论口径

推荐供应商时必须写：推荐对象、推荐原因、不选最低价的原因、主要风险、控制动作、需要决策事项。
