# 产品开发流程

## 流程总览

化妆品新品开发按“需求确认 - 产品方案 - 供应资源 - 打样测试 - 成本确认 - 量产准备 - 上市复盘”推进。

## 1. 需求确认

确认产品定位、目标客群、渠道、目标零售价、预计销量、目标毛利率、上市时间和竞品参考。

输出：新品立项记录、目标成本、上市倒排计划。

## 2. 产品方案

确认配方方向、功效卖点、质地、香型、容量、包材结构、外观工艺、合规和检测要求。

输出：产品方案说明、打样要求、初步 BOM。

## 3. 供应资源

筛选配方厂、原料商、包材厂、检测机构，收集资质、MOQ、交期、报价和付款条件。

输出：供应商候选表、风险清单、主备供应商建议。

## 4. 打样测试

跟进配方样、包材样、组合样，验证肤感、气味、外观、稳定性、兼容性、漏液、运输和灌装适配。

输出：样品测试记录、修改意见、确认样。

## 5. 成本确认

拆解内容物、包材、加工、检测、物流、损耗、税费和付款条件，测算目标售价下的毛利空间。

输出：报价比价分析、成本优化建议、是否进入量产的判断。

## 6. 量产准备

确认 BOM、订单数量、质量标准、验收标准、设计稿、印刷稿、备案资料和交付节点。

输出：量产准备清单、采购订单、风险预案。

## 7. 上市复盘

复盘开发周期、成本结果、交付结果、供应商表现、质量反馈和销售支持效果。

输出：项目复盘、供应商评分更新、后续优化计划。
