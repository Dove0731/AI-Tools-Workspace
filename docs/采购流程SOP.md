# 采购流程 SOP

## 1. 需求确认

下单或询价前必须确认：采购对象、用途、规格、数量、质量标准、目标成本、期望交期、付款要求和是否影响销售节点。

## 2. 询价

询价必须统一口径：规格版本、数量梯度、是否含税、是否含运费、MOQ、交期、付款条件、报价有效期、模具费、打样费、检测费。

## 3. 比价

比价不能只看单价，必须同时比较：

| 维度 | 判断问题 |
| --- | --- |
| 单价 | 是否低于历史价和目标价 |
| MOQ | 是否造成库存和现金占用 |
| 交期 | 是否影响开发或销售档期 |
| 付款 | 是否影响现金流 |
| 质量 | 是否有异常记录 |
| 供应风险 | 是否单一来源 |
| 销售支持 | 是否能提供资料、卖点或认证 |

## 4. 下单

下单前确认规格版本、确认样、报价有效期、交期、验收标准、付款节点和异常责任。

## 5. 跟进

按节点记录：下单确认、备料、排产、生产、出货、到货、验收、入库、付款。

## 6. 异常处理

异常发生后记录事实、影响、责任、证据、补救方案、截止时间和复盘结论，并更新供应商评价。
