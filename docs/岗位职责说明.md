# 岗位职责说明

## 岗位定位

化妆品产品开发与采购岗位负责连接市场需求、产品方案、供应资源、成本结构和交付计划，确保新品能按期、按质、按成本目标落地，并持续优化成熟产品供应链。

## 核心职责

| 职责 | 工作内容 | 经营价值 |
| --- | --- | --- |
| 新品开发 | 立项、打样、测试、报价、量产、上市跟进 | 缩短开发周期，支持销售窗口 |
| 原料采购 | 原料资源开发、报价、资质、替代方案 | 稳定配方供应，降低断供风险 |
| 包材采购 | 包材开发、工艺确认、兼容测试、交期跟进 | 控制外观质量和交付节奏 |
| 供应商管理 | 准入、评估、分级、异常记录 | 提升供应链稳定性 |
| 成本优化 | 比价、谈判、替代、规格优化 | 提升毛利和成交空间 |
| 异常复盘 | 质量、交期、成本、沟通异常闭环 | 避免重复损失 |
| 汇报支持 | 月报、复盘、老板决策材料 | 让工作结果可视化 |

## 关键产出

- 新品项目计划
- 供应商询价与比价分析
- 成本拆解和降本方案
- 样品测试记录
- 采购订单跟进表
- 质量和交期异常复盘
- 老板汇报材料
