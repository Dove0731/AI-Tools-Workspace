# 老板汇报口径

## 汇报原则

给老板看的内容少讲过程，多讲结果、数据和经营价值。每个事项都要说明对毛利、成本、交付、风险、现金流或销售支持的影响。

## 推荐结构

1. 结论
2. 数据结果
3. 经营价值
4. 发现的问题
5. 下一步动作
6. 需要老板决策或支持的事项

## 常用表达

| 事项 | 汇报口径 |
| --- | --- |
| 降本 | 本次优化预计影响多少成本和毛利，是否影响质量和交期 |
| 供应商替代 | 替代后降低什么风险，是否需要小批量验证 |
| 延期风险 | 会影响哪个上市或销售节点，补救方案是什么 |
| 质量异常 | 涉及多少数量和金额，已避免或可能产生什么损失 |
| 现金流 | MOQ、账期、付款比例对资金占用的影响 |
