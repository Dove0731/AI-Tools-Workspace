# 02_会议与协同

## 目录用途

本目录用于管理新品开发、采购、供应商、工厂和跨部门沟通形成的会议纪要、行动清单和协同闭环。

## 存放内容

- 新品开发会议纪要、供应商沟通纪要、采购异常协调会议。
- 管理层周复盘会前材料：[七遇管理层周复盘会议材料准备模板](./部门会议/七遇管理层周复盘会议材料准备模板_V1.0.md)。
- 跨部门协同事项跟进表。
- 会议结论转行动清单规则。
- 已确认的沟通结论和待办事项。

## 更新规则

- 每次会议或关键沟通后当天记录。
- 会议纪要必须包含决议、责任人、截止时间、风险点和下一步动作。
- 重要行动同步到 `协同事项总台账.md`。

## 使用方式

1. 按会议类型复制模板。
2. 把会议内容整理成“结论 + 行动”。
3. 需要跨部门跟进的事项进入跟进表。
4. 已关闭事项补充关闭日期和证据。
