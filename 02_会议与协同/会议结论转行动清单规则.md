# 会议结论转行动清单规则

## 目的

把会议内容从“讨论记录”变成可执行、可追踪、可关闭的行动清单。

## 转换规则

| 会议内容 | 转换方式 |
|---|---|
| 形成共识 | 写入“决议” |
| 有人要处理 | 写入“动作” |
| 有时间要求 | 写入“截止时间” |
| 可能影响成本、交期、质量、客户 | 写入“风险点” |
| 需要下次确认 | 写入“下一步动作” |

## 行动清单标准

| 字段 | 要求 |
|---|---|
| 决议 | 一句话说明会议确定了什么 |
| 责任人 | 必须具体到人或部门 |
| 截止时间 | 必须有日期或明确时间点 |
| 风险点 | 说明不完成会影响什么 |
| 下一步动作 | 写清做什么、交付什么 |

## 禁止写法

- “继续跟进”：必须写跟进什么、谁跟、何时反馈。
- “尽快处理”：必须写具体截止时间。
- “供应商确认中”：必须写供应商需确认的具体内容。
