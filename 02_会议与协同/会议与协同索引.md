# 会议与协同索引

## 协同原则

所有会议和沟通记录必须落到四件事：结论、责任人、截止日期、输出物。没有下一步动作的内容不进入正式协同记录。

| 场景 | 记录位置 | 重点 |
|---|---|---|
| 部门周例会 | `部门会议` | 项目进度、采购卡点、异常闭环 |
| 销售需求对接 | `销售对接` | 客户需求、目标价、上市时间、成交概率 |
| 研发配方对接 | `研发配方对接` | 功效方向、原料风险、测试要求 |
| 包装设计对接 | `包装设计对接` | 包材结构、打样、成本、交期 |
| 品质法规对接 | `品质法规对接` | 资质、测试、合规、质量异常 |
| 生产计划对接 | `生产计划对接` | 量产排期、BOM、来料节点 |
| 财务付款对接 | `财务付款对接` | 付款节点、账期、现金流影响 |
| 供应商沟通 | `供应商沟通` | 报价、交期、质量、账期、异常 |
| OEM/ODM 工厂协同 | `OEM_ODM工厂协同` | 打样、报价、资料、排产、量产风险 |
