# 包材库字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 包材编号 | 是 | 建议 PK-品类-序号 |
| 包材名称 | 是 | 如 50ml PETG 精华瓶 |
| 包材类型 | 是 | 瓶、泵、盖、软管、外盒、标签等 |
| 材质 | 是 | PETG、PP、PE、玻璃、纸等 |
| 容量或尺寸 | 是 | 容量、口径、长宽高 |
| 工艺 | 否 | 喷涂、烫金、丝印、电镀 |
| 适配产品 | 否 | 对应 SKU 或项目 |
| 供应商 | 是 | 包材供应商 |
| 单价 | 否 | 记录数量梯度 |
| MOQ | 否 | 最小起订量 |
| 模具费 | 否 | 开模或改模费用 |
| 打样周期 | 否 | 样品周期 |
| 量产交期 | 否 | 量产周期 |
| 兼容性状态 | 否 | 未测、测试中、通过、不通过 |
| 外观确认状态 | 否 | 未确认、待修改、已确认 |
| 风险说明 | 否 | 色差、漏液、刮花、交期、起订量 |
