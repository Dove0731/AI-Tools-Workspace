# 降本优化字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 降本编号 | 是 | 建议 CO-YYYYMM-序号 |
| 项目或 SKU | 是 | 关联产品或项目 |
| 降本类型 | 是 | 供应商替代、规格优化、工艺优化、MOQ 优化、账期优化 |
| 原方案 | 是 | 原供应商、规格、成本和问题 |
| 新方案 | 是 | 新供应商、规格、成本和变化 |
| 原单支成本 | 是 | 原成本口径 |
| 新单支成本 | 是 | 新成本口径 |
| 单支节约 | 是 | 原成本减新成本 |
| 年度预计数量 | 否 | 年度测算 |
| 预计毛利提升 | 否 | 单支节约乘以数量 |
| 一次性费用 | 否 | 模具、测试、认证、切换成本 |
| 净收益 | 否 | 毛利提升减一次性费用 |
| 质量影响 | 是 | 是否影响效果、外观、稳定性 |
| 交付影响 | 是 | 是否影响上市或补货 |
| 现金流影响 | 否 | MOQ、账期、库存变化 |
| 风险等级 | 是 | 低、中、高 |
| 验证状态 | 是 | 待样、测试中、通过、不通过、已导入 |
| 决策建议 | 是 | 推荐、暂缓或放弃 |
