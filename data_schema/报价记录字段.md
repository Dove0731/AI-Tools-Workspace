# 报价记录字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 报价编号 | 是 | 建议 Q-YYYYMMDD-序号 |
| 报价日期 | 是 | 供应商给价日期 |
| 项目名称 | 否 | 关联项目 |
| 供应商 | 是 | 报价来源 |
| 报价对象 | 是 | 原料、包材、成品、服务 |
| 规格版本 | 是 | 避免不同规格混比 |
| 数量梯度 | 是 | 如 1000、5000、10000 |
| 单价 | 是 | 含币种 |
| 是否含税 | 是 | 是、否 |
| 税率 | 否 | 如 13% |
| 是否含运费 | 是 | 是、否 |
| MOQ | 是 | 最小起订量 |
| 交期 | 是 | 打样或量产交期 |
| 付款条件 | 是 | 预付、账期等 |
| 报价有效期 | 否 | 过期需复核 |
| 额外费用 | 否 | 模具费、打样费、版费、检测费 |
| 报价来源 | 是 | 邮件、报价单、截图、会议纪要 |
| 经营影响 | 否 | 毛利、现金流、交期、风险 |
