# 产品项目库字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 项目编号 | 是 | 建议 P-YYYYMM-序号 |
| 项目名称 | 是 | 新品、改版、降本或替代项目名称 |
| 项目类型 | 是 | 新品、改版、降本、替代供应商、质量改善 |
| 产品品类 | 是 | 护肤、彩妆、洗护、香氛等 |
| 目标客群 | 否 | 核心消费者 |
| 目标渠道 | 否 | 线上、线下、直播、经销等 |
| 项目负责人 | 是 | 内部负责人 |
| 当前阶段 | 是 | 立项、打样、测试、报价、下单、量产、上市、复盘 |
| 目标上市时间 | 是 | 用于倒排计划 |
| 目标零售价 | 否 | 含币种 |
| 目标成本 | 否 | 单支或单套成本 |
| 目标毛利率 | 否 | 经营目标 |
| 核心卖点 | 否 | 成分、功效、肤感、包装、价格 |
| 关键供应商 | 否 | 主供应商 |
| 备选供应商 | 否 | 风险备选 |
| 样品状态 | 否 | 未打样、已到样、测试中、通过、需修改 |
| 报价状态 | 否 | 未询价、已报价、比价中、已确认 |
| 主要风险 | 否 | 成本、交期、质量、法规、供应 |
| 经营价值 | 否 | 毛利、交付、风险、销售支持 |
| 下一步动作 | 是 | 负责人、截止时间、产出 |
