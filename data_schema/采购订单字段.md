# 采购订单字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 订单编号 | 是 | 内部采购订单号 |
| 下单日期 | 是 | 订单确认日期 |
| 项目或 SKU | 是 | 关联项目或产品 |
| 供应商 | 是 | 执行供应商 |
| 采购对象 | 是 | 物料或服务名称 |
| 规格版本 | 是 | 下单版本 |
| 数量 | 是 | 采购数量 |
| 单价 | 是 | 含币种和税费口径 |
| 总金额 | 是 | 订单金额 |
| 付款条件 | 是 | 付款比例和账期 |
| 预计交期 | 是 | 供应商承诺日期 |
| 实际交付日期 | 否 | 完成交付后填写 |
| 订单状态 | 是 | 待确认、生产中、待出货、已到货、异常、关闭 |
| 质量验收状态 | 否 | 未验、通过、不通过、让步接收 |
| 付款状态 | 否 | 未付、部分付款、已付款 |
| 交付风险 | 否 | 对上市、库存或客户承诺的影响 |
| 异常记录 | 否 | 质量、交期、数量、价格异常 |
| 下一步动作 | 是 | 责任人和截止日期 |
