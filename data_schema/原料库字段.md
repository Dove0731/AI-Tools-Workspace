# 原料库字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 原料编号 | 是 | 建议 RM-品类-序号 |
| INCI 名称 | 是 | 国际原料名称 |
| 中文名称 | 是 | 常用名称 |
| 功能分类 | 是 | 保湿、乳化、防腐、活性、香精、色粉等 |
| 适用品类 | 否 | 面霜、精华、洁面等 |
| 供应商 | 是 | 原料商或代理商 |
| 规格 | 否 | 含量、等级、包装 |
| 报价 | 否 | 记录日期和币种 |
| MOQ | 否 | 最小起订量 |
| 交期 | 否 | 常规交期 |
| 付款条件 | 否 | 预付、账期、月结等 |
| 合规资料 | 是 | MSDS、COA、过敏原、动物源说明等 |
| 样品状态 | 否 | 未取样、测试中、通过、不通过 |
| 替代原料 | 否 | 替代型号或供应商 |
| 风险等级 | 否 | 低、中、高 |
| 风险说明 | 否 | 价格波动、断供、合规限制 |
