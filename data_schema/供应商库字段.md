# 供应商库字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 供应商编号 | 是 | 建议 S-品类-序号 |
| 供应商名称 | 是 | 公司全称或内部简称 |
| 供应商类型 | 是 | 原料、包材、代工、检测、物流 |
| 主营品类 | 是 | 优势品类 |
| 联系人 | 否 | 公开商务联系人 |
| 公开联系方式 | 否 | 公司电话或公开邮箱 |
| 所在地区 | 否 | 城市或产业带 |
| 资质资料 | 是 | 营业执照、生产许可、认证 |
| 产能说明 | 否 | 月产能、设备、旺季限制 |
| 常规 MOQ | 否 | 按品类记录 |
| 常规交期 | 否 | 打样和量产交期 |
| 付款条件 | 否 | 预付、账期、月结 |
| 合作项目 | 否 | 历史项目 |
| 质量表现 | 否 | 异常率、整改速度 |
| 交付表现 | 否 | 准交率、延期记录 |
| 报价竞争力 | 否 | 高、中、低 |
| 供应商等级 | 是 | A、B、C、D |
| 风险说明 | 否 | 单一依赖、资料不全、价格波动 |
