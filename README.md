# 化妆品产品开发与采购 AI 工作中枢

本工作库用于把新品开发、原料与包材采购、供应商管理、报价比价、成本优化、交期跟进、质量异常协同、采购订单分析、项目复盘和老板汇报沉淀成可追踪、可复用、可交接的工作系统。

本库不是普通资料夹，核心用法是：所有事项先进工作台和台账，再进入项目、供应商、采购成本或问题复盘模块，最后形成报告、模板或归档记录。

## 目录结构

- `00_工作台与规则`：首页、目录说明、命名规则、信息分级、标签和词典。
- `01_工作报告`：日报、周报、月报、季度复盘、年中/年度总结、老板汇报。
- `02_会议与协同`：部门会议、跨部门协同、销售/研发/包装/品质/生产/财务/供应商/OEM 工厂沟通。
- `03_项目管理`：新品、原料、包材、OEM/ODM、成本优化、重点项目、项目复盘和归档。
- `04_数据台账`：项目、原料、包材、供应商、报价、订单、降本和问题闭环字段口径。
- `05_问题反馈与复盘`：质量、交期、成本、供应商和项目问题闭环。
- `06_经验与模板`：SOP、表格、汇报和谈判话术模板。
- `07_AI工作区`：AI 任务、会话日志、临时处理、提示词和原始资料归档。
- `08_供应商管理`：供应商准入、分级、绩效、异常、淘汰、开发和账期合同管理。
- `09_产品开发管理`：新品立项、打样、测试、产品资料、上市节点和产品复盘。
- `10_采购与成本管理`：原料/包材采购、报价比价、采购订单、成本优化、付款现金流、库存 MOQ。
- `97_待整理`：未分类、待脱敏、待录入、待人工确认资料。
- `98_AI输出暂存区`：AI 生成但未确认的输出。
- `99_归档`：历史报告、历史数据、旧版资料、已关闭项目和原始资料归档。

## 现有目录保留方式

原有 `docs`、`data_schema`、`templates`、`examples`、`使用逻辑文件` 已保留在根目录，作为旧资料入口继续使用；正式工作时优先进入 00-10、97-99 的中枢目录。映射说明见 `00_工作台与规则/旧库入口与说明/现有目录整合说明.md`。

## 使用原则

1. 未确认信息一律标注“待确认”。
2. 示例数据必须写明“示例”，不得伪装成真实业务数据。
3. 报价、账期、质量、交期、MOQ、供应商等级等信息必须记录来源和日期。
4. 给老板看的内容优先讲经营结果，不堆过程。
5. 成本优化必须同时说明毛利、成交、交期、供应风险和可复制性。
