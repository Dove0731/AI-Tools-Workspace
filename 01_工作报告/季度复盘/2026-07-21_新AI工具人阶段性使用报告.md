# 新AI工具人阶段性使用报告

**报告编号：** RPT-202607-007  
**统计周期：** 2026-07-09 至 2026-07-21  
**适用部门：** 采购开发部  
**报告性质：** 阶段性AI应用总结  
**当前状态：** 已形成，管理结论及下一阶段安排待确认

## 一、阶段结论

新AI工具人已从简单问答和文案辅助，扩展到采购数据分析、新品经营复盘、备案进度分析、成本与报价治理、质量异常管理、会议决策支持、知识归档、周报生成及系统操作辅助等业务场景。

本阶段形成的主要价值为：

1. **数据处理：** 将原始Excel、历史资料和分散记录转化为结构化分析、异常清单和管理台账。
2. **管理机制：** 将一次性问题升级为责任节点、质量门禁、异常升级、验收标准和复盘机制。
3. **知识资产：** 建立原件归档、来源记录、版本管理、索引和台账，使经验可以持续检索和复用。
4. **经营支持：** 分析从单纯采购执行扩展到毛利、交付、质量、库存、现金流、客户及供应商风险。

当前已经形成5项核心SOP及多类可复用方案，但多数仍处于“试运行、技术完成或待业务验证”阶段。现阶段不能把“文件已形成”直接等同于“机制已正式上线”，下一阶段重点应从继续增加文件转向真实业务试跑、验收、发布和持续复盘。

## 六、尚不能认定为正式SOP的内容

1. **单款面膜样品成品化：** 缺真实出货、送样、客户反馈及转化数据。
2. **客户资产与产品资产匹配：** 目前为流程设计，具体产品、客户范围、责任人及试跑结果待确认。
3. **金蝶物料及BOM建档：** 优化路线已形成，但正式物料和BOM尚未审核成功。
4. **铝塑管封尾黑线：** 已形成异常验证和关闭框架，但根因、责任及永久改善尚未确认。
5. **包装文案审校：** 属于辅助检查方法，不能替代法规、备案、品质和印刷放行。
6. **SOP草稿目录中的采购询报价、供应商准入与淘汰等文件：** 仍属于草稿，未完成责任人、验收和真实业务验证。

## 七、当前问题和管理风险

| 问题 | 经营影响 | 下一步要求 |
|---|---|---|
| 文件形成速度快于业务验证速度 | 容易把“形成文档”误认为“产生经营结果” | 每项SOP必须绑定真实项目、订单或异常验证 |
| 部分业务数据和责任人缺失 | 无法准确评价毛利、交付、库存、现金流和执行结果 | 补客户、订单、数量、金额、责任人、截止时间和验收证据 |
| 多项方案尚未正式发布 | 使用人员、权限、版本及执行责任不统一 | 明确批准人、正式入口、旧版停用和生效日期 |
| AI系统操作稳定性不足 | 可能产生重复录入、无效等待或错误系统状态 | 优先使用导入模板、单条闭环验证和失败止损规则 |
| 外部资料和培训案例容易与正式制度混淆 | 可能造成经营口径或审批权限误用 | 保留来源状态，未经验证不得升级为公司正式规则 |

## 八、下一阶段建议

### P0：完成三个真实业务闭环

1. **新品开发：** 选取1个真实在研项目跑通Stage-Gate，形成通过、退回、暂停或停止的评审记录。
2. **OEM成本：** 取得真实成本源表和订单，完成错误定位、独立复算、毛利反算和影响订单追溯。
3. **冻干粉报价：** 正式发布V1.1、停用旧版，并抽查首批10笔正式报价或首周全部报价。

### P1：补齐使用治理

1. 明确每项AI方案的业务负责人、数据责任人、批准人和使用范围。
2. 建立AI应用清单，统一记录输入、输出、节省时间、准确率、业务价值、异常和改进项。
3. 对AI生成的报告、台账、报价和系统数据继续执行人工复核及版本留痕。
4. 每月汇总实际形成的降本、毛利保护、交付改善、风险避免和人效提升，不以文件数量作为主要成绩。

## 九、管理层待确认事项

1. 是否批准新品Stage-Gate、OEM成本复核、冻干粉自动核价作为下一阶段三个优先试点。
2. 是否明确上述试点的业务负责人、批准人、试运行周期和验收标准。
3. 是否建立部门AI应用月度复盘机制，统一评价业务结果、人效、准确性和风险。
4. 是否将已完成真实试跑并达到验收标准的SOP升级为正式版本，未通过的继续保留试运行或调整状态。
