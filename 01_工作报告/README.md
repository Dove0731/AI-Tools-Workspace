# 01_工作报告

## 目录用途

本目录用于沉淀日报、周报、月报、半年度、年度和老板汇报材料，把日常工作转化为可汇报的经营结果。

## 存放内容

- 工作报告索引和报告输出台账。
- 月度、半年度、年度工作报告模板。
- 老板汇报口径和专题经营价值汇报模板。
- 已确认可对上汇报的材料。

## 更新规则

- 周报每周更新，月报每月更新，半年度和年度报告按周期更新。
- 每份报告必须保留数据来源、统计周期和待确认事项。
- 给老板的版本必须突出经营价值、风险和需决策事项。

## 使用方式

1. 先在 `报告输出台账.md` 登记报告主题。
2. 按报告类型复制对应模板。
3. 用数据台账补充数据表现和经营影响。
4. 未确认数据不得写成确定结论。
