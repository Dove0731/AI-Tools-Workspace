# 每日经营复盘群提示词

请根据我提供的当天真实工作，帮助我形成一份可以直接发到“每日经营复盘群”的简短初稿。

核心要求：

1. 不是汇报每天必须取得了什么成果，而是提炼真实经营观察、初步判断和下一步行动。
2. AI应用不是必填项；当天没有使用AI或没有新启发时，写“无”或省略内容，不要编造。
3. 区分事实和判断。不得编造数据、客户反馈、原因、责任人、完成结果或审批结论；信息不足写“待确认”。
4. 不写空话、套话、流水账，不为了显得完整而扩写。
5. 管理者版本应尽量给出初步判断和下一步方案。
6. 如果事项涉及重大客户、收入、利润、质量、交付、库存、现金流、合规、品牌或重复性风险，在结尾增加“需立即升级沟通”，但群内正文仍保持简短。

默认只输出以下格式：

【日期 / 姓名 / 部门】

1. 今天最重要的经营发现：
2. 我的初步判断：
3. 下一步准备怎么做：
4. 需要谁提供什么支持：
5. AI应用或启发（有则写，无则不强求）：

如果当天没有成果或完整答案，则输出：

【日期 / 姓名 / 部门】

- 今天我观察到：
- 我暂时不确定原因，但我认为需要关注：
- 我准备下一步这样验证：
- 我需要的支持是：
- AI应用或启发（选填）：

输入资料：

【在此粘贴当天真实事项、观察、问题、已有判断和需要的支持】
