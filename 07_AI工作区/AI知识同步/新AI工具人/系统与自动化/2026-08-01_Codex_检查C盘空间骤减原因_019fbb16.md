## 用户需求

是否可以修改Chrome、腾讯、飞书、Codex/WorkBuddy 等应用的缓存储存空间

## AI输出

可以，但各应用支持程度不同：浏览器通常能改启动缓存目录，腾讯/飞书多半只能在应用设置里迁移“文件保存位置”，程序缓存未必支持改盘；Codex/WorkBuddy还要区分运行时、插件、日志和临时文件。我会结合本机实际目录与官方支持边界，整理成可执行方案，暂不修改。由于涉及 Codex 的存储机制，我会使用 OpenAI 官方文档技能核对。

## AI输出

OpenAI 官方手册读取脚本需要 Node.js，但系统 PATH 中没有；按该技能要求，我会调用工作区自带运行时后重试。这只会读取官方手册缓存，不会改应用配置。

## AI输出

可以修改，但需要区分“迁移缓存位置”和“限制缓存大小”。建议优先迁移到 D 盘；D 盘目前约有 100.6 GB 可用空间。

| 应用 | 改位置 | 限制大小 | 建议 |
|---|---:|---:|---|
| Chrome | 可以 | 可以 | 迁移至 `D:\AppCache\Chrome`，限制 512 MB–1 GB |
| 微信/企业微信 | 部分可以 | 通常不支持统一上限 | 在应用内迁移文件存储；缓存、日志定期清理 |
| 飞书 | 部分可以 | 通常不支持统一上限 | 修改下载/文件目录；程序缓存定期清理 |
| Codex | 可以迁移主要状态目录 | 暂无统一缓存上限 | 将 `CODEX_HOME` 改到 D 盘 |
| WorkBuddy | 未发现官方路径设置 | 未发现统一上限 | 可清安装包；整个目录迁移需使用目录联接 |

具体建议：

1. Chrome 最适合直接调整  
   可以通过 Windows Chrome 策略设置：

   - `DiskCacheDir`：缓存目录，例如 `D:\AppCache\Chrome`
   - `DiskCacheSize`：建议 `1073741824`，约 1 GB

   Google 官方确认 Windows Chrome 支持修改磁盘缓存目录和大小；需要重启 Chrome 生效。[缓存目录政策](https://chromeenterprise.google/intl/en_ca/policies/disk-cache-dir/)、[缓存大小政策](https://chromeenterprise.google/policies/disk-cache-size/)

   注意：这只能控制浏览器网页缓存，当前约 0.49 GB 的 `GoogleUpdater` 更新缓存不受该上限控制。

2. 微信、企业微信和飞书  
   建议优先在应用设置中修改：

   - 文件管理/文件存储位置
   - 下载目录
   - 聊天文件保存位置

   但 `AppData` 下的日志、插件、缩略图和升级缓存通常仍会留在 C 盘，也没有可靠的统一容量上限。当前腾讯数据约 7.16 GB，飞书约 1.34 GB，适合先用应用自带“存储空间管理”清理，再迁移文件目录。

3. Codex  
   当前本机没有设置 `CODEX_HOME`，所以主要状态默认在：

   `C:\Users\Administrator\.codex`

   官方文档确认可以通过 `CODEX_HOME` 修改 Codex 本地状态目录。[Codex 配置与状态位置](https://learn.chatgpt.com/docs/config-file/config-advanced#config-and-state-locations)

   可以迁移至：

   `D:\AppData\CodexHome`

   但它只覆盖 `.codex` 约 1.50 GB，不一定覆盖：

   - `.cache\codex-runtimes`：约 1.02 GB
   - `AppData\Local\OpenAI`：约 0.66 GB

   这两部分如需迁移，通常要用目录联接，不能简单剪切。

4. WorkBuddy  
   当前没有发现 `WORKBUDDY_HOME` 或明确的官方迁移配置。可先安全处理：

   - 已完成更新后的安装包：约 0.51 GB
   - 临时更新目录
   - 过期日志

   `.workbuddy` 主目录约 1.03 GB，如果一定要迁移，可以关闭 WorkBuddy 后复制到 D 盘并建立 Windows 目录联接，但更新兼容性风险高于普通设置迁移。

最稳妥的实施顺序是：Chrome缓存迁移和限额 → 腾讯/飞书应用内迁移文件目录 → Codex设置 `CODEX_HOME` → WorkBuddy仅清理安装缓存。当前我没有修改或删除任何应用数据。
