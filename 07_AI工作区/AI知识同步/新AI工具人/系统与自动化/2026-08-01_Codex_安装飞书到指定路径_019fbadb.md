## 用户需求

codex 如何连接到飞书

## AI输出

我会先按 Codex 官方文档确认目前可用的连接方式，再结合飞书的开放平台给你一条能实际落地的方案。这里需要区分“让 Codex 读取飞书内容”和“让 Codex 主动向飞书发消息/执行操作”。

## AI输出

Codex 连接飞书，推荐使用飞书官方的 **OpenAPI MCP**。刚安装的飞书客户端只是登录和办公软件，本身不会自动把飞书数据开放给 Codex。

最稳妥的连接结构是：

`Codex → 飞书官方 lark-mcp → 飞书开放平台 API → 文档/知识库/多维表格/消息`

## 配置步骤

1. 在[飞书开放平台](https://open.feishu.cn/)创建“企业自建应用”。

2. 在应用后台完成：

   - 保存 App ID 和 App Secret
   - 按需要添加机器人能力
   - 申请最小必要权限
   - 设置重定向地址：`http://localhost:3000/callback`
   - 创建版本并发布应用

3. 安装 Node.js 20 以上版本。

   我刚才检查到当前电脑的系统环境中还不能直接运行 `node`，所以这一步目前需要补齐。飞书官方 MCP 通过 `npx @larksuiteoapi/lark-mcp` 启动。[飞书官方安装说明](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/mcp_integration/mcp_installation?lang=zh-CN)

4. 使用飞书身份授权：

```powershell
npx -y @larksuiteoapi/lark-mcp login -a <App_ID> -s <App_Secret>
```

命令会生成飞书授权网址，需要在约60秒内打开并确认授权。

5. 在 Codex 桌面端进入：

`设置 → MCP servers → Add server → STDIO`

配置的核心启动命令为：

```text
npx -y @larksuiteoapi/lark-mcp mcp -a <App_ID> -s <App_Secret> --token-mode user_access_token -l zh
```

保存后重启 Codex。Codex 官方说明，桌面端、CLI 和 IDE 扩展共用 `config.toml` 中的 MCP 配置，也可以在项目的 `.codex/config.toml` 单独配置。[Codex MCP 配置说明](https://learn.chatgpt.com/docs/extend/mcp#connect-codex-to-an-mcp-server)

## 建议的第一期权限

建议第一期先做只读连接，只允许：

- 读取指定飞书文档
- 搜索指定知识库
- 查询指定多维表格
- 必要时读取指定群聊历史

发送消息、新增或修改多维表格、创建文档应放到第二期，确认时逐条授权。飞书官方 MCP 默认支持消息、群组、知识库、文档和多维表格等工具，但对应权限仍需在应用后台开通。[飞书 MCP 工具说明](https://open.feishu.cn/document/mcp_open_tools/mcp-overview?lang=zh-CN)

特别注意：**不要把 App Secret 发到聊天里，也不要直接写入工作库或 Git 仓库。**正式连接建议用 Windows 当前用户加密凭据和启动脚本保存密钥。

如果你希望我直接继续配置，我可以下一步帮你：

1. 安装 Node.js；
2. 创建安全的飞书 MCP 启动脚本；
3. 配置项目级 `.codex/config.toml`；
4. 做一次只读文档查询验收。

你只需要先在飞书开放平台创建企业自建应用；App ID 可以提供，App Secret 不要发给我，后续在本机授权界面输入。
