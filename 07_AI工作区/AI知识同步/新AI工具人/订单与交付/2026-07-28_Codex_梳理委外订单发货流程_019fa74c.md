# 梳理委外订单发货流程

## AI输出

## AI输出

委外订单发货建议按“订单确认—资料锁定—物料齐套—发货审批—实物交接—到货签收—成品回货—对账闭环”执行。核心原则是：没有有效委外订单、正确 BOM、质量放行和可追溯单据，不发货。

这里的“委外发货”需要分成两段管理：

- 公司把包材、料体等物料发给委外工厂。
- 委外工厂完成生产后，把成品发回公司仓库或直发客户。

## 一、标准流程

### 1. 确认委外模式

先判断属于哪一类：

| 模式 | 处理要求 |
|---|---|
| 完全委外 | 工厂提供料体、包材和生产；原则上建立委外成品主编码，按实际业务下委外订单 |
| 半包委外 | 公司提供部分物料；必须建立 BOM，明确公司提供物料、用量、损耗和货主 |
| 来料加工 | 公司提供主要原料/包材；重点控制发料数量、批次、损耗、余料和成品回收 |
| 委外成品直发客户 | 工厂直接发客户，但系统仍需保留成品入库、销售出库或等效业务闭环 |

### 2. 下达委外订单

订单至少明确：

- 产品名称、物料编码、规格及版本；
- 委外工厂及实际生产地址；
- 委外数量、单位和允许交付差异；
- 加工单价、税率、运费承担方式；
- 公司提供物料清单；
- 计划发料日期、生产日期、交货日期；
- 箱规、包装方式、批号和日期格式；
- 质量标准、验收标准及检测要求；
- 余料、不良品、超耗和报废处理方式；
- 收货组织、仓库和收货联系人。

订单信息不完整时，应标记“待确认”，不得通过微信或口头通知代替正式订单。

### 3. 锁定生产资料

发货前完成以下复核：

- 成品编码及委外订单已经审核；
- 半包委外或来料加工 BOM 已审核；
- 父项、子项、单位、用量、货主、组织、生效日期正确；
- 最新配方、包材文件、印刷稿、色样、工艺要求已确认；
- 纸箱尺寸、箱规、批号和日期格式已确认；
- 临时变更已经形成书面变更记录；
- 旧版资料已经隔离，避免工厂误用。

### 4. 形成发料计划

根据委外订单数量和 BOM 计算应发数量：

`计划发料量 = 委外订单数量 × BOM 单耗 ×（1＋允许损耗率）`

同时核对：

- 可用库存是否足够；
- 物料是否在有效期内；
- 批次是否满足先进先出；
- 包材、料体批次是否适配；
- 是否存在待检、冻结或不合格库存；
- 多发数量是否会形成工厂呆滞库存。

损耗率、备损量没有批准口径时，不得由经办人自行放大。

### 5. 发货审批与仓库出库

建议形成“一单一包”发货资料：

- 委外订单；
- 委外发料单/其他出库单；
- 发货明细或装箱单；
- 物料批次及数量清单；
- 物流单号及车辆信息；
- 特殊储运要求；
- 质量放行或检验状态证明；
- 工厂收货联系人及地址。

仓库按单拣货并进行双人复核，重点核对“物料编码、名称、规格、批次、单位、数量、箱数、质量状态”。

### 6. 实物交接及物流跟踪

装车前应拍照留证，至少包括：

- 整体货物；
- 外箱标签；
- 批次和数量标签；
- 封箱或托盘状态；
- 物流面单或车辆信息。

物流过程中，由采购或供应链经办人跟踪签收状态。涉及料体、易碎包材、温控或防潮要求时，应在运输单据中明确，不得只口头提醒司机。

### 7. 工厂签收及差异处理

工厂收货后原则上应在当日或次日完成签收反馈：

- 实收数量；
- 批次；
- 外观及包装状态；
- 短少、破损、错料情况；
- 签收单或系统收料记录。

出现差异时：

1. 暂停使用争议物料；
2. 保留照片、物流凭证、称重或清点记录；
3. 核对公司出库数量、物流交接数量和工厂实收数量；
4. 明确责任方及补发、退回、索赔或账务调整方案；
5. 同步更新系统单据和异常台账。

不得先让工厂使用、月底再补差异记录。

### 8. 委外生产及成品回货

工厂投产前应确认物料齐套、版本正确和质量要求明确。成品发货前至少检查：

- 生产批次及生产日期；
- 成品数量、合格数量和不良数量；
- 留样、检验报告及必要的放行文件；
- 外观、喷码、标签、箱规和装箱数量；
- 公司供料实际使用量、损耗量和结余量；
- 剩余物料、不良品和报废品处理方案；
- 收货组织、仓库及收料通知是否正确。

直发客户的，必须同步销售、客服、仓库和财务，并保留系统入库及销售出库闭环，不能只有工厂物流单。

### 9. 收货、核销和对账

闭环时核对：

`发出物料 = 实际耗用＋合格成品对应耗用＋不良损耗＋退回余料＋工厂结存`

同时完成：

- 成品收货及质量验收；
- 委外订单入库/收料；
- 公司供料消耗核销；
- 超耗、短少和报废审批；
- 加工费、运费、税费和其他费用对账；
- 工厂余料台账更新；
- 未结委外订单检查。

## 二、四道必设控制门槛

1. 订单门：没有审核后的委外订单，不发货。
2. 资料门：编码、BOM、版本、货主和组织不一致，不发货。
3. 质量门：待检、冻结、不合格或超过有效期的物料，不发货。
4. 交接门：没有出库单、批次清单和签收凭证，不认定交付完成。

## 三、最容易出问题的注意点

- 只在群里通知换厂或换料，没有同步委外订单和 BOM。
- 发货单位与 BOM 单位不一致，又没有换算关系。
- 公司多发备损物料，但未记录工厂余料，最终形成账外库存。
- 料体、内包材和外包材批次无法对应，发生质量问题后不能追溯。
- 新旧版包材混发，造成错版生产。
- 工厂直发客户后未做系统入库、销售出库和财务确认。
- 成品数量已经入库，但公司供料没有核销。
- 工厂报告“生产损耗”，但没有不良品数量、照片和原因证据。
- 跨组织委外时，货主、供应组织、收料组织或仓库选择错误。
- 发货完成被误认为订单闭环，实际上成品验收、余料退回和费用对账尚未完成。

## 四、建议责任分工

| 角色 | 主要责任 |
|---|---|
| 项目/业务负责人 | 确认产品版本、数量、交付节点和客户要求 |
| 采购 | 下达委外订单，协调工厂、物流、费用和异常处理 |
| 计划/供应链 | 核算需求、齐套情况、发料计划和交付进度 |
| 研发/质量 | 确认配方工艺、质量标准、检验和放行 |
| 仓库 | 按单发货、批次复核、留证和系统出库 |
| 委外工厂 | 签收、保管、生产、损耗报告、成品交付及余料管理 |
| 财务 | 加工费、物料核销、超耗扣款及月度对账 |

工作库现行手册已经明确：完全委外原则上按委外成品处理；自带包材委外必须建立 BOM 并检查物料齐套；直发客户也必须保留入库和销售出库闭环。具体可参照[金蝶云星空操作手册](</E:/新AI工具人/10_采购与成本管理/金蝶云星空操作手册.md:249>)。

当前仍需确认的企业内部口径包括：实际审批权限、允许损耗率、发货签收时限、委外仓名称、组织编码、超耗扣款标准及金蝶具体单据类型。在这些信息确认前，上述内容适合作为执行框架，不宜直接宣称为已经正式发布的公司 SOP。
