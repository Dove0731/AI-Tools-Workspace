# CLI调用说明

## 目标流程

```text
飞书CLI → 创建任务 → 写入AI任务中心 → Codex读取 → 读取知识库与事实数据 → 执行分析 → 输出结果 → 用户确认 → 归档沉淀
```

## 调用约定

1. 使用 `任务模板.md` 创建任务。
2. 任务必须包含编号、时间、来源、业务模块、目标、输入和期望输出。
3. 登记到 `待处理任务.md`，初始状态为“待处理”。
4. Codex执行时更新为“处理中”。
5. 先读取 `AGENTS.md` 和 `00_工作台与规则`，再读取对应知识库。
6. 未确认且需要落盘的结果进入 `98_AI输出暂存区`。
7. 完成后更新状态并记录 `Codex执行日志.md`。
8. 用户确认后归档并更新索引或台账。
