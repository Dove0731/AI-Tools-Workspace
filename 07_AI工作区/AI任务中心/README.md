# AI任务中心

本目录是飞书CLI、Codex与GitHub之间的业务任务中转入口，用于统一登记需求、明确输入与输出、跟踪状态和记录自动化任务。

## 职责边界

- 本目录负责业务任务登记、状态跟踪、调用说明和自动化任务清单。
- `../Codex任务` 负责具体执行过程及执行记录。
- 未经确认的分析结果进入 `../../98_AI输出暂存区`。
- 用户确认后的正式成果进入对应业务目录，并同步相关索引或台账。

## 标准流程

```text
飞书CLI/人工提出需求 → 写入待处理任务 → Codex识别业务领域 → 读取规则、知识库和事实数据 → 执行分析 → 输出至任务会话或AI暂存区 → 用户确认 → 正式归档并更新索引/台账
```
