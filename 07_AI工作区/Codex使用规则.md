# Codex 使用规则

## 使用原则

- 让 Codex 处理文件整理、台账生成、报告初稿、数据清洗和模板批量创建。
- 重要资料处理前先明确目标目录、输入资料和输出格式。
- Codex 生成结果必须检查后再入正式目录。

## 指令格式

| 项目 | 写法 |
|---|---|
| 目标 | 请帮我把什么资料整理成什么成果 |
| 输入 | 文件路径、数据范围、统计周期 |
| 输出 | Markdown、Excel、PPT、台账、报告 |
| 口径 | 含税/未税、数量、日期、供应商、项目范围 |
| 限制 | 不编造、缺失标注待确认、保留来源 |

## 输出检查

- 是否结论先行。
- 是否有数据来源。
- 是否标注待确认。
- 是否可直接用于工作。
- 是否进入正确目录。
