# AI 输出质量检查清单

| 检查项 | 通过标准 | 未通过处理 |
|---|---|---|
| 结论先行 | 开头有明确结论 | 要求重写 |
| 经营视角 | 覆盖毛利、成本、成交、交期、质量、现金流或供应风险 | 补充经营影响 |
| 数据来源 | 关键数据有来源 | 标注来源待确认 |
| 缺失提示 | 缺失数据标注待确认 | 不得入库 |
| 无编造 | 没有凭空生成真实数据 | 删除或标注示例 |
| 问题完整 | 包含问题、原因、影响、建议 | 补齐结构 |
| 动作清楚 | 有责任人、截止时间、输出物 | 补充行动清单 |
| 可直接使用 | 能放入报告、台账、邮件或复盘 | 调整格式 |
