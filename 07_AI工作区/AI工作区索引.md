# AI 工作区索引

| 子目录 | 用途 | 入库规则 |
|---|---|---|
| `Codex任务` | 记录让 AI 执行的文件整理、分析、生成任务 | 任务完成后写会话日志 |
| `会话日志` | 记录重要 AI 工作过程和结果 | 重大交付必须留痕 |
| `临时处理` | 临时拆分、清洗、转换资料 | 确认后移入正式目录或归档 |
| `提示词模板` | 采购、供应商、产品开发提示词 | 可复用后沉淀到模板 |
| `原始资料归档` | 处理过的重要原始资料备份 | 保留来源路径 |
| `文件操作记录` | 记录迁移、重命名、归档动作 | 不删除原文件时也要说明位置 |
| `金蝶MCP连接` | 金蝶云星空与 Codex 的只读 WebAPI/MCP 连接器 | 只开放核准查询工具；凭据不得明文入库 |
| `飞书知识问答机器人` | 飞书消息监听、受控知识检索、本人直答、其他会话送审和审计 | 本人双重身份匹配后直答；其他会话仅在本人回复“同意”后发送 |

## 重点入口

- [每日 AI 复盘提示词](./提示词模板/每日经营思考提示词.md)：把当天真实工作整理为1—3句具体反思；重大事项再升级为正式分析。
- [金蝶云星空只读 MCP 连接](./金蝶MCP连接/README.md)：配置连接、权限边界、自检和首次联调入口。
- [飞书知识问答机器人](./飞书知识问答机器人/README.md)：建立知识索引；本人私聊直接回复，其他私聊或群内 @机器人问题送本人审核。
